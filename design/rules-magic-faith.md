# 魔法、信仰、種族

> [power-tiers.md](power-tiers.md) 說「魔法不是獨立系統，是位階的一種來源」。
> 這份把三種來源展開。
> 通用原則見 [principles.md](principles.md)；用詞以 [glossary.md](glossary.md) 為準。

## 共同形狀

三者都是**位階的來源**，所以它們共用同一個接法：

```
提供 tier 加成 + 特殊能力 + 屬性修正 + 可被剝奪的條件
```

差別只在**取得與失去的方式**：

| 來源 | 怎麼得到 | 怎麼失去 |
|---|---|---|
| **武技** | 訓練與實戰累積 | 重傷、年老 |
| **魔法** | 學習、研究、傳承 | 失去媒介、精神受創 |
| **信仰** | 神祇眷顧 | **被剝奪**（違背教義、神祇隕落） |
| **血統** | 出生 | 幾乎不會 |
| **神器** | 取得物品 | 物品易主 |

信仰那條「可被剝奪」是最有戲的：**一個聖騎士可以在一夜之間掉兩階**。
這給了劇情一個機制上的槓桿。

## 魔法

### 學派是資料

`SchoolDef`（[definitions.md](definitions.md)）。初版清單只是資料檔的第一筆內容：

元素、召喚、幻術、死靈、變化、預言。

法師的位階來自**造詣**：主修學派的造詣決定位階，副修提供廣度。

### 施法

```
消耗魔力（心屬性上限）→ 檢定（心 vs 法術難度）→ 效果
```

失敗有代價（反噬、魔力浪費、暴走），否則法師會無限重試。

### 三層都要有表現

這是魔法設計最容易漏的一點——**只做 Local 層的法術，魔法在戰略上就不存在**：

| 層 | 魔法長什麼樣 | 接到哪 |
|---|---|---|
| **L1 Region** | 戰略魔法：改變天氣、降下瘟疫、傳送軍隊、詛咒一整片土地 | 直接改 Region 的快變數，或成為 [combat-formula.md](combat-formula.md) 的修正項 |
| **L2 Site** | 戰術魔法：範圍傷害、增益、召喚、破城 | 影響方陣的修正項與陣型 |
| **L3 Local** | 個體法術：逐次檢定 | [rules-individual.md](rules-individual.md) |

戰略魔法必須**貴且慢**（耗時數旬、需要儀式、需要多名施法者），
否則它會蓋過整個大地圖玩法。它應該是「一場戰役的轉折點」，不是每旬按一次的按鈕。

### 魔素

Region 層的資源之一（[worldmap.md](worldmap.md) 已列）。

- 地脈、遺跡、特殊地物產出
- 戰略魔法消耗
- **分布不均**是刻意的：魔素豐富的土地值得爭奪，這讓魔法接上 4X 的資源競爭

## 信仰

### 神祇是 World 級實體

神祇住在 root zone（[zone-model.md](zone-model.md)），significance 為 `World`
（[significance.md](significance.md)），所以它們在所有層的 tick 都被個別計算。

`DeityDef` 帶：神格、領域、教義、敵對神祇。

### 眷顧與剝奪

- 信徒依虔誠度獲得 tier 加成與領域能力
- **違背教義 → 剝奪**，位階立刻下降，能力消失
- 教義是資料（`TenetDef`），可以互相衝突——
  同時侍奉戰神與和平之神會有代價，這是刻意的

### 神祇會死

古龍會死，神也會。神祇隕落是 `World` 級事件（[events.md](events.md)），
會讓所有信徒同時掉階——這是能撐起一整條主線的機制。

**神祇不直接干預世界。** 它們透過信徒與事件作用，
理由與 [principles.md](principles.md) 原則一同源：
神在 root，世界在 zone，中間必須有中介。

## 種族

`RaceDef`。影響三件事：

| 影響 | 說明 |
|---|---|
| **屬性基礎值** | 矮人體高心低、精靈技心高體低 |
| **位階上限** | 見下 |
| **壽命** | 影響位階累積的時間 |

### 位階上限是種族最重要的欄位

[power-tiers.md](power-tiers.md) 已定：血統影響**位階上限而非起點**。

- 大多數人族的上限是 `Region`（3 英傑）
- 精英血統、龍裔、半神可達 `World`（4 傳奇）
- 普通獸群的上限是 `Local`（1 精銳）

這條讓「為什麼傳奇這麼稀少」有了機制上的答案，
而不是靠數值調參硬壓。

### 壽命與位階累積

精靈活得久 → 有時間把武技與魔法都練上去。
所以長壽種族**平均位階較高**，但**上限不必然更高**——
人類的天才可以在四十年內達到精靈四百年的高度，這是刻意留給敘事的空間。

## 反面清單

以下刻意**不做**，寫下來免得日後有人「順手加一下」：

| 不做 | 理由 |
|---|---|
| 職業系統（戰士／法師／盜賊） | 四屬性 + 三種力量來源已經天然產生原型，再加一層職業是重複 |
| 經驗值與等級 | 位階是身分的改變，不是經驗條（[power-tiers.md](power-tiers.md)）。成長靠事蹟與訓練，不靠刷怪 |
| 法術書與記憶術式（Vancian） | 與回合制三層縮放不合，管理成本高而戰略意義低 |
| 魔法與科技的對立軸 | 本作沒有科技革命，中世紀奇幻的技術樹是緩慢的 |
