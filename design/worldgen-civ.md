# L1 生成：文明、道路與出入口

> 地形長好之後，人怎麼落腳、路怎麼連、大陸怎麼對外連通。
> 前一階段見 [worldgen-terrain.md](worldgen-terrain.md)；共通規矩見 [gen-pipeline.md](gen-pipeline.md)。
> 通用原則見 [principles.md](principles.md)；用詞以 [glossary.md](glossary.md) 為準。

## 管線

```
8 選址 → 9 道路 → 10 出境點 → 11 勢力起始 → 12 歷史層
```

## 8. 城市選址

### 評分函數

對每一格算一個定居分數，**各項權重全部住在資料檔裡**：

| 因子 | 說明 |
|---|---|
| 淡水 | 相鄰的邊有河，或緊鄰湖泊。**權重最高**——沒有水就沒有城 |
| 可耕地 | 周圍半徑 2 內的格子有多少是溫帶／濕潤的平原或丘陵 |
| 海港 | 相鄰海格，且該海格連通到外海（不是內陸湖） |
| 防禦 | 周圍的山地／丘陵占比，河流環繞加成 |
| 資源 | 周圍的礦脈、特殊地物 |
| 交通 | 位於山口、河流匯流處、半島頸部這類**地形瓶頸**上 |
| 懲罰 | 極端氣候（沙漠深處、凍原）、高海拔、沼澤 |

「交通瓶頸」那條是讓地圖有戰略感的關鍵：**兵家必爭之地應該是地形算出來的，不是手工擺的**。
實作上是看該格是否位於兩塊可通行區域之間的最小割上——
簡化做法是算「移除此格後，周圍連通性下降多少」。

### 選址

貪婪 + 最小間距：

1. 全圖算分，排序
2. 取最高分者設為城市
3. **抹除半徑 R 內的所有候選**（`R` 依城市等級，大城 6～8 格、小鎮 3～4 格）
4. 重複，直到達到目標城市數或無候選超過門檻

最小間距是必要的，否則所有城市會擠在同一條大河沿岸。

### 規模分級

依最終得分分成三級，寫進 Region tile 的快變數（人口、建設等級）：

| 級 | 數量級 | 展開成的 Site 種類 |
|---|---|---|
| 大城 | 每個勢力 1～2 個 | `City` |
| 城鎮 | 十幾個 | `Town` |
| 村莊 | 幾十個 | `Town`（低建設等級） |

要塞（`Fortress`）不走選址，走第 9 步之後的**隘口補點**：
在主要道路穿越山口、渡河點的地方補設要塞。這讓要塞永遠在它該在的地方。

## 9. 道路

### 骨架：最小生成樹 + 補環路

1. 以城市為節點建完全圖，邊權 = 兩城之間的**實際地形移動成本**（用 A* 算，不是直線距離）
2. 跑最小生成樹（Kruskal），得到一棵連通所有城市的樹
3. **補幾條環路**：從落選邊中挑「權重低但在樹上繞遠路」的（即 `樹上距離 / 直接距離` 比值最大者），加回去 10～20%

純 MST 的路網是樹狀的，看起來假、玩起來也差（斷一條路就切斷半個大陸）。
補環路讓路網有替代路徑，同時保留樹狀骨架的層次感。

### 落到格子上

每條道路用 A* 求路徑，成本函數與部隊移動**不同**：

- 道路偏好平緩：坡度成本加重（修路要考慮工程量）
- 道路偏好沿河谷、繞開沼澤
- **道路傾向重用既有道路**：已鋪路的邊成本大減，讓路網自然收束成幹道 + 支線
  （這一條讓生成順序有影響，所以城市對必須按**固定順序**處理——依 canonical id 排序）

路徑寫進 `edges`：路徑經過的每一對相鄰格之間的邊，寫上道路類的 `EdgeId`。
等級依該邊被多少條路線重用而定（幹道 > 支線 > 小徑）。

### 渡河與橋

道路路徑跨越有河的邊時，該邊要同時是河也是路——但一條邊只能存一個 `EdgeId`。

解法：資料檔裡有**複合 def**（`edge.bridge_stone_over_river`、`edge.ford`），
由「河的等級 × 路的等級 × 該處的技術水準」查表決定。
淺水小溪出淺灘、大河出橋樑、無力建橋處出渡口（渡口是需要時間的通行點，戰略上是瓶頸）。

## 10. 出境點

Region 邊界上綁定 WorldGraph 邊的格子（見 [worldmap.md](worldmap.md)）。

| 通道類型 | 出境點該在哪 |
|---|---|
| 海路 | 沿海的港口城市；沒有就在最佳海港候選處補一個 |
| 山口 | 邊界山脈上移動成本最低的鞍部 |
| 地下通道 | 山地或廢墟中，通常隱藏（需探索或劇情解鎖） |
| 傳送門 | 由劇情資料指定座標，或放在特殊地標上 |

出境點確定後，**倒回去補一條道路連到最近的城市**——
否則會出現「大陸的唯一港口沒有路可以到」這種蠢事。

## 11. 勢力起始

1. 每個勢力分到一個大城作為首都，首都之間用**最遠點採樣**盡量分散
2. 從首都做**影響力擴散**（洪水填充，成本用移動成本，遇山海衰減），
   把周圍的城鎮村莊與 tile 的 `owner` 分配出去
3. 影響力相遇處形成邊界——**這些天然邊界就是初始的外交摩擦點**
4. 無主區留給中立勢力、蠻族或空白

擴散法比「畫圈分配」好的地方是：勢力的疆域會自然沿著山脈與河流走，
因為那些地方移動成本高、影響力衰減快。**國界長得像真的國界。**

## 12. 歷史層（可選但便宜）

在世界開始之前，先跑一段**簡化的歷史模擬**，成本很低但回報極高：

1. 從當前地形跑一次「上古文明」的選址（用同一個評分函數，但不同 seed）
2. 讓它們興盛若干個世代，連出一套**古道**
3. 然後降下一場災變：讓其中大部分崩毀

留下的痕跡：

- 崩毀的城市 → `feature = 廢墟`，且廢墟的規模對應它當年的等級
- 古道 → 低等級的道路 `EdgeId`，穿過現在無人的荒野
- 上古文明的高分選址中，仍然宜居的那些 → 現代城市**優先落在那裡**（文明會回到好地方）

成本是把已有的評分與 MST 演算法多跑一輪。回報是整張地圖有了時間深度：
玩家會看到荒野中一條通往廢墟的古道，而那個廢墟正好在一個水源充足的河谷——
不需要任何手寫劇本，玩家自己就會腦補出一個故事。

## 與 L2 的銜接

這一階段的所有產物都是 **Region 的慢變數或快變數**，
因此自動成為 Site 生成的輸入（見 [interface-world-mid.md](interface-world-mid.md)）：

| L1 產物 | L2 怎麼用 |
|---|---|
| `edges` 的道路與河流 | Site 邊界的 crossing，見 [edge-consistency.md](edge-consistency.md) |
| 城市等級與人口 | Site 的規模與填充密度，見 [sitegen-city.md](sitegen-city.md) |
| `feature = 廢墟` | Site 種類為 `Ruin`，L3 入口密度提高 |
| `owner` | Site 內的守軍歸屬、建築風格 |
