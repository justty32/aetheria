# 世界觀與敘事

> 這個世界怎麼來的、故事怎麼長出來。
> **多數敘事不是寫出來的，是模擬出來的**——這是本作敘事設計的核心賭注。
> 通用原則見 [principles.md](principles.md)；用詞以 [glossary.md](glossary.md) 為準。

## 三層敘事

| 層 | 誰產生 | 量 |
|---|---|---|
| **世界觀骨架** | 人工，寫死在資料檔 | 很少 |
| **歷史與地誌** | **程序生成**（[worldgen-civ.md](worldgen-civ.md) 的歷史層） | 大量，每局不同 |
| **當下的故事** | **模擬產生**（事件 + 獨特物件 + 命運判定） | 無限 |

人工只寫第一層。第二、三層讓系統長，而系統已經全部就位了。

## 世界觀骨架（人工，且要少）

只定**不會因局而異**的東西：

| 定什麼 | 為什麼 |
|---|---|
| 諸神與神話（[rules-magic-faith.md](rules-magic-faith.md)） | 神是 `World` 級實體，跨局存在 |
| 種族與其文化基調 | 影響 `RaceDef` 與建築風格 |
| 魔法的來源與禁忌 | 決定魔法在世界裡的位置 |
| 一場「上古災變」 | 見下 |
| 大陸的性格（各 Region 一句話） | 給生成器風格參數 |

**刻意不定**：具體國家、具體人物、具體地名——那些每局都該不一樣。

### 上古災變是骨架裡最有用的一條

[worldgen-civ.md](worldgen-civ.md) 的歷史層會生成「上古文明興盛→崩毀」，
留下廢墟、古道、遺跡。**世界觀只要給那場崩毀一個名字與原因**，
程序生成的每一處廢墟就自動有了意義。

一句話的設定，換來滿地圖的可解釋性。這是人工與程序的最佳分工比例。

## 模擬即敘事

四個既有機制合起來就是一台故事機器，**不需要額外的敘事系統**：

| 機制 | 產生什麼故事 |
|---|---|
| [worldgen-civ.md](worldgen-civ.md) 歷史層 | 荒野中的古道通往河谷裡的廢墟——玩家自己會腦補 |
| [significance-fate.md](significance-fate.md) | 「雜貨店的瑪莎倖存，但鋪子已空」 |
| [unique-objects.md](unique-objects.md) | 一個無名老人因劇情而獲得名字與命運線 |
| [diplomacy.md](diplomacy.md) 積怨與均勢 | 兩國三代人的世仇；玩家坐大時的反霸權同盟 |

**最好的敘事時刻不會出現在劇本裡。** 它出現在
「饑荒的死亡配額分配到那個你認識的人身上」的瞬間。

## 劇情系統：三種任務

| 種類 | 誰寫 | 特徵 |
|---|---|---|
| **主線** | 人工，`QuestDef` + Lua | 少而長，跨大陸，World 級事件 |
| **支線** | 人工，但可掛在程序生成的位置上 | 中等，模板 + 實際填空 |
| **湧現任務** | **完全程序**：從世界狀態生成 | 無限，短 |

### 湧現任務怎麼長

不是「隨機組合模板」，而是**從世界的實際狀態讀出需求**：

```
某城 food_yield < 需求      → 「運糧」
某格治安低（[sitegen-wild.md]）→ 「清剿盜匪」
某具名 NPC 失蹤（沒被 mark 但玩家認識）→ 「尋人」
某勢力積怨高且國力接近      → 「戰前情報」
地城 cleared = false 且深   → 「探索」
```

因為需求是真的，**完成任務會真的改變世界狀態**——
運糧真的補上糧食缺口，清剿真的提高治安。這比「殺 10 隻狼換錢」有份量得多，
而且完全走既有的歸約通道（[interface-world-mid.md](interface-world-mid.md)）。

### 主線用 Lua

主線需要條件判斷與分支，走 [rules-extensibility.md](rules-extensibility.md)
的 L-Script 層。六條決定論鐵律照樣適用——
**劇情腳本不得持有跨回合狀態**，要記的一律進持久層的劇情旗標。

## 劇情與觀察點

劇情事件會**產生子觀察點**（[observer.md](observer.md)），
而那個觀察點**持有因它而獨特的人事物**（[unique-objects.md](unique-objects.md)）。

所以一條主線在資料上長這樣：

```
劇情「勇者覺醒」（子觀察點）
├─ 老人格伐  ·  XX 洲 XX 國 XX 村  ·  安好，年邁  ·  最後觀測：第 142 旬
├─ 聖劍（獨特物品，significance = World）
└─ 那座村子（獨特地點）
```

玩家打開劇情面板看到的就是這張表。而表上的狀態是**惰性補算**的——
不打開就不算。

## 文本量與 i18n

| 類 | 量 | 誰寫 |
|---|---|---|
| 世界觀與神話 | 少 | 人工 |
| 主線劇情 | 中 | 人工 |
| 支線模板 | 中 | 人工 |
| 湧現任務的敘述 | **由模板 + 填空生成** | 系統 |
| 事件戰報 | 由模板生成 | 系統 |

**所有面向玩家的文字都走 i18n key**，不寫死字串
（[definitions.md](definitions.md) 的 `name_key`）。
填空式模板要小心語言差異——中文與日文的語序不同，
模板要以**具名參數**而非位置參數表達。

## 這個賭注可能會輸

誠實記下風險：**程序生成的敘事容易「有結構但無靈魂」**。

系統能保證「這條古道通往那座廢墟」是自洽的，
但保證不了玩家會**在意**。緩解手段：

- 人工寫的主線提供情感錨點
- [unique-objects.md](unique-objects.md) 的自動 mark 讓玩家的實際行為決定他在乎誰
- 命運判定的敘事輸出要寫得好——**同一個機制，文案差一級，體驗差三級**

若實測下來玩家對程序敘事無感，退路是**加重人工支線的比例**，
把湧現任務降級成背景噪音。這條退路不影響任何機制，只是內容配比。
