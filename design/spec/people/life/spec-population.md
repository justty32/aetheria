# S5a：人口、人物身分與生命週期

## 範圍與完成定義

草案，承接 [人物藍圖](../../../../wf/workflows/plan/living-world/systems/world-systems-people.md)、[S0 交接](../../common/continuity/spec-world-handoff.md) 與 [significance](../../../simulation/significance.md)。穩定身分不等於常駐逐人運算；本檔不解除 mark 擱置，也不裁定新增 ID 的位元格式。

**Done when：**無名居民能遷徙、從軍、成名、退伍或死亡，三層沒有憑空增人；已存在的人物、家庭與承諾不因降格重抽。災害配額的既有例外必須明列，不能假裝已解決。

## 三層責任與最小狀態

Region 保存人口群組的組成、分布、流入流出及事件配額；Site 配置住民、家庭、人力與名冊；Local 展開本場人物及動作。人口規則更新群組歸屬與數量，人物規則更新身分及經歷；健康、旅行、政治仍各自寫所屬狀態。

群組至少可區分年齡帶、文化／信仰、生活位置、勞動能力與必要技能分布；這些是可查分布，不要求所有維度做全笛卡兒積。家庭、軍籍、職業與文化是可重疊關係，不能把四份名冊加成總人口。

人物持久資料包括身分、出生／年齡依據、已確定姓名、群組歸屬、家庭引用、重要經歷及生命狀態。位置讀旅行，傷勢讀健康，財產讀資產關係，不另存第三份副本。未知生日可保存「年齡區間與來源」，不能每次見面重抽年齡。

## 無名到具名，不是生成新居民

1. 在既有群組可用配額中選取符合條件的一份成員；條件不能超過已知分布，例如普通農民不能被抽成不存在的唯一大師。
2. 依確定性來源生成尚未承諾的細節，發出持久人物紀錄並將其計入群組具名子集。總人口不變，詳算時另依 S0 領出推進責任。
3. 與他人建立婚姻、雇用、欠款等持久承諾前，參與者需有可延續的辨識；純背景外觀無需全部持久化。
4. 降格只停詳細行為器，保留身分及承諾。不能把已具名成員重新放進「可另抽成新人」的無名配額。

來源是群組、抽取事件與穩定序列，不只使用可被下一人重用的顯示槽位。人物搬遷時更新定位關係，舊 `EntityRef` 失效不等於人物消失。

## 生命與歸屬事件

| 事件 | 前提與提交 | 禁止事項 |
|---|---|---|
| 出生／加入世界 | 合法生育或具名內容來源，出生地與照護關係可追查 | 空屋直接生人口；同一出生事件提交兩次 |
| 年齡／勞動能力變化 | 從時戳及健康推進，影響未來排班 | 改步長多長一歲；生日令所有能力瞬間滿級 |
| 遷出／到達 | 先進在途名冊，到達再入當地居民配額 | 旅途期間同時享兩城完整住民產出 |
| 徵募／退伍 | 角色關係與勞動安排轉換；軍隊引用同一批人 | 把徵兵當人口新生；退伍重生裝備 |
| 死亡 | 健康或合法命運判定確認；停止未來行動，通知工作／家庭／政治 | 延至重載才停止領薪、任職或生育 |

失蹤是他人的知識／查找狀態，不直接等於世界判死。俘虜、流民和逃兵仍在世界人口內，位置與保管可不同於法律住所。死亡的遺產、職缺與照護責任是後續案件，不由人口規則一口氣分完。

人物如何形成養育打算、安排照護與回應成長，見 [家庭延續](../family/spec-family-formation.md)。意願不是出生事件；出生、收養與具名化分別沿自己的來源，不互相代替。

## 災害配額：保留裁定，明列尚存矛盾

[命運判定](../../../simulation/significance-fate.md) 已裁定「具名死亡超配額時記持久赤字、下次扣抵」，本批不改成截斷死亡或擴張當期配額。它是 S0 普通逐段對帳以外的既有統計例外，不能被新 spec 無聲覆蓋。

需要再裁定的接口是：當期模型配額與已確認實際生存人數如何同時對外呈現。**建議**分列模型損失預算、實際生命事實、待扣抵赤字；實際可排班／徵募人數只讀存活者，不能用預算推導出幽靈工人。此建議尚未替代舊文的當期權威總量語意。

必推演配額 1、實際具名死亡 3、赤字 2，下一事件配額不足 2、群組又遷移／解散的情境。赤字不得因拆群組、換層或存讀消失；如何分攤與何時清帳須先裁定，不能宣稱本案已逐事件完全守恆。

舊文「離場後重載才補擲」也需限縮：會影響領袖繼承、雇用或在途參與者的命運，須於對外依賴需要前確定。可延後的是不改先前外界結果的細節與演出，而非延後死亡的世界效果。精確排程沿 S1 草案，待與舊文協調。

## 保存、AI 與驗收

保存群組分布、具名子集、轉移收據、未完生命事件、赤字及必要的抽取來源。AI 依可用人力提出招聘／徵募／遷徙，不直接改人口；正式介面只揭露有情報依據的名冊和死亡消息。

夾具：100 名居民內已有具名者 4 名，再具名化 1 名後仍為 100。20 人遷出後是本地 80、在途 20；到達新城後在途歸零，新城增加 20。從這 20 人徵募 5 人不再令世界人口增加 5。

同一紀錄經 Local／離場／存讀回來，姓名、年齡、家屬、歸屬與已確定生死一致。負向案例包含重複出生、重用身分、死者上工、清除赤字和群組重疊計人。
