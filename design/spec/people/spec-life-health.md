# S5c：需求、健康、照護與日常節奏

## 範圍與完成定義

草案，承接 [生活藍圖](../../../wf/workflows/plan/living-world/systems/world-systems-life.md)、[地方工作](../site/spec-site-work.md)、[人物](spec-population.md)。本檔是遊戲規則，不採現實醫療數值。部位數、疾病庫與生理細節尚未定。

**Done when：**人物會因飢餓、睡眠不足、受傷和環境失去工作能力，也能依真實資源獲得照護；離場不治癒，細算不多扣一份食物。日常委任能減少重複操作，而不免除代價。

## 三層輸入與效果

Region 算人口風險分布、糧食需求與疾病等事件總體條件；Site 配住房、食物、床位、照護工時與環境服務；Local 算實際暴露、取用、休息及治療步驟。健康／需求規則寫狀態，帳本寫食藥消耗，工作規則寫照護預約，人物接收死亡及經歷。

持久輸入至少能重建需求負擔、有效休息、傷病原因、嚴重度、進展、處置、暴露區間與下一到期點。HP 若只作現場呈現可重建；不能因標成易失而丟掉無法還原的失血、疲勞或藥效。

## 需求不只是多條量表

建議先用營養／飲水、休息、安全、住所／環境與社會支持等可組合需求。種族可不用某需求或有替代來源，但必須有對應 def 與代價，不靠專屬程式旁路。

一般不足影響選擇權重與工作效率；危急可中斷當前工作；失能禁止特定動作。警示門檻與解除門檻應有間隔，避免人物每回合在吃飯與工作間反覆切換。

需求滿足查「實際取用及有效服務」：買到食物不等於已吃，預約床位不等於已睡，待在屋內不保證安全或舒適。文化偏好可改滿意度，不在無資源時自動生成替代品。

## 傷病與照護流程

| 階段 | 條件與更新 | 失敗出口 |
|---|---|---|
| 暴露／受傷 | 合法戰鬥、環境或生活事件，來源與區間可追查 | 同一效果重送不再受傷 |
| 進展 | 已有狀態、時間、抵抗／照護及新暴露 | 不能按載入次數重擲發病 |
| 求助／分診 | 患者可行動或有人發現，服務有路可達 | 未被發現不自動占全知醫療床位 |
| 處置 | 人員、技能、工具、耗材、場所和患者條件符合 | 缺藥／中斷保留已耗時間與既有效果 |
| 恢復／後遺症 | 累積有效恢復條件達成，由健康規則提交 | 完成工作單不保證疾病立刻治好 |
| 失能／死亡 | 狀態條件成立，在合法時點禁止後續非法行動 | 結構移除等回合尾；死亡通知不能等重載 |

治療「完成處置」與病人「康復」是兩個結果。醫師受傷可換人，前一段已施處置與費用不倒轉。醫療／消防優先序是制度與委任政策，不能隱藏成隨機容器順序。

## 暴露、群體與環境

擁擠、通風、污染、飲水與接觸可作疾病風險輸入；本批不定逐病原粒子模擬。遠方依群體暴露摘要推進，Local 領出的接觸份額排除於同段粗算，不能既擲群體感染又獨立多加一次。

疾病引起缺工，缺工使供水／清潔服務不足，形成跨時段回饋；不得在同一提交點遞迴到無限疫情。火與煙影響通行、健康及設施，各領域收各自效果，不把同一火災的死亡在兩份人口報表相加。

## 委任、保存與介面

玩家可委任一般飲食、休息、取暖、照護；政策列可用物資、支出上限、保留物品、危急中斷與回報條件。AI 也受相同可達性與帳本限制，找不到服務時回報、改計畫或求助，不瞬移到床。

保存實際負擔、進展游標、未完照護及處置收據。離場由粗算接手已授權區間，重返不重做治療抽樣。UI 顯示症狀、已知診斷、功能限制、照護缺口與下一可做行動；隱藏病因不因玩家打開面板就曝光。

## 驗收與待裁定

夾具：工匠受傷停止工作，兩名傷者競爭一張床，醫師只有一份處置材料。依已選分診政策只一人取得該床／材料；另一人可候診或接受不同處置，不能兩人都獲完整資源效果。處置後離場，病程按有效照護繼續，不能讀檔滿血。

相同暴露及服務路徑比較分段／不分段推進，精確消耗一致；粗細病程分布另依校準驗證。負向案例：回合變短加速飢餓、工作與睡眠同時全額計時、重載重抽疾病、無藥完成治療、死亡後仍參戰。

待細化：需求軸、身體部位粒度、病程與抗性模型、分診政策、玩家自動求生邊界、群體相關風險及誤差預算。復活／不死屬力量與政治後續規格，不能在此默認所有死亡可逆。
