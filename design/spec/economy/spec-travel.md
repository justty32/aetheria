# S6c：旅行、運輸、通行與遭遇

## 範圍與目標

草案，依 [旅行藍圖](../../../wf/workflows/plan/living-world/systems/world-systems-travel.md)、[S0](../common/spec-world-handoff.md)、[S1](../common/spec-world-time.md) 及 [物資](spec-goods.md)。人、軍隊與貨物共用交通約束，不代表它們有相同速度、隱蔽性與通行權。

**Done when：**同一商隊可規劃、出發、排隊、改道、遭遇、紮營、拆隊及交貨；玩家上下切層不刷新路程、補給或敵人。地城內容與飛行／傳送完整能力留 S9。

## 旅程與位置

旅程記身分、隊伍／乘員、貨物與載具引用、目的、已知路線、允許通路、風險姿態、補給／支出限制、遭遇處置政策。狀態記當前邊或地點、已走進度、上一提交點、下一到期點、疲勞、容量預約及未完命令。

旅行規則寫世界位置與進度；環境提供地形／道路條件；政治驗通行權與徵稅；帳本寫補給及保管；戰鬥處理遭遇效果。地圖切換不直接改法律住所，也不自動令貨物所有權改變。

移動中的隊伍有唯一在途表示。粗層邊進度展開到 Site 走廊、再到 Local 位置必須保留剩餘路程與邊界出口；不能每次下沉都放到最近城門以縮短旅程。

## 命令轉移

**暫行操作方向：**普通旅行先用「到目的地，遇到大事才停」。沿既有預算與風險設定處理例行紮營、補給及一般改道，不要求逐路段確認；會錯過重要期限、超出授權風險或找不到安全出口時再停下說明。這省的是重複操作，實際時間與耗用仍計算。

| 轉移 | 條件與結果 | 失敗出口 |
|---|---|---|
| 規劃 → 待出發 | 已知路線、隊伍同意／指揮權、初始載重及補給可行 | 未知路況是估計，不保證可通行 |
| 待出發 → 在途 | 參與者集合、貨物保管、載具與合法出口成立 | 缺員／超載不留下半隊瞬移成功 |
| 在途 → 排隊／受阻 | 到達容量瓶頸、關卡或失效路段 | 停在實際位置，繼續消耗必要補給 |
| 受阻 → 改道／折返 | 有可知候選與相應授權，重新估代價 | 無可行路就等候、求援或回報，不穿牆 |
| 在途 → 紮營／遭遇 | 需求、環境或交戰中斷生效 | 保留已走區間，交出局部詳算責任 |
| 在途 → 到達 | 真正抵達合法入口，接收地容量／條件成立 | 到城外不等於入倉或入籍 |
| 到達 → 結束 | 移交保管／參與者與旅程結果 | 合約交貨由市場驗收，不由旅行直接判付款 |

改目的與拆隊需重驗權限及承載能力。拆出傷員／護衛／貨物有原始份額，不能讓每支子隊繼承全部糧食。取消旅程只取消未來目標，不倒轉已走位置。

## 路網與運能

**奇幻玩法接點：**已知且可用的暫時渡路、傳送端點或探知路線，可以作為規劃候選，顯示主要條件與有效窗口。提出方案不代表路已存在；建立、供能或施術完成後才依真實通行條件使用。窗口結束或環境改變時，按既有受阻／改道規則接續，不把進度倒帶。見 [不同手段的比較](../spec-play-fantasy.md)。

路線成本由地形、路況、季節、載重、載具、隊伍能力及安全條件形成。速度瓶頸與容量分開：窄橋可能可快速通過但同時只能過少量貨，不能用單一「移動減速」取代排隊。

建議只預約近期瓶頸區間，避免一支遠征隊鎖住整條道路數月。仲裁需有優先政策、期限與穩定鍵；軍事優先若存在須有政治授權並留下民用延誤後果，不能天然搶占所有商隊。

隊伍抵達前發生斷橋／封關，權威排程在適當時點更新合法性；舊情報可令隊伍走到才發現，但不能令世界允許其穿過已不存在的橋。跨 Site 由共同上層中介，不直接修改鄰居。

海運需港口／登陸條件與載具；飛行、地下路、傳送走各自能力與容量約束，不因普通陸路封鎖就全禁，也不因超常就免補給和時距。詳細例外待力量規格。

## 遭遇與玩家介入

遭遇候選來自實際巡邏、野獸、戰線、治安、天候或有來源的事件生成，不只從每次載圖擲骰。保存事件來源、參與者、觸發區間和已確認結果；尚未決定的結果依規則與確定性亂數推進，不能把未戰先定勝敗誤當「不重抽」。

選擇粗算或親自下沉，領同一批人、貨、地點與時間責任。Local 探索／紮營耗光源、糧食與有效工時；未展開部分繼續前進。玩家離場不解除敵人追擊或抹掉足跡，追蹤細則仍待定。

## AI、保存及驗收

AI 依可知安全／速度／成本與任務期限選路，可設定不得離散隊伍、保底口糧及求援條件。搜尋有界，找不到路保留實際位置、受阻原因與再議條件；停下不保證安全，暴露及必要消耗照常推進。不消耗真實亂數作無限預演。UI 顯示預估到達與不確定因素，不承諾精確未來。

保存路段進度、在途參與者與貨、到期工作、未完遭遇、預約、已耗量和移交收據；可重建路徑快取不替代持久位置。

夾具：商隊領糧 30 袋，途中自用 2、遭遇失去 3，到貨最多 25；若另有補貨需有來源。途中拆隊後兩隊攜糧加總仍是當時餘量。上下切層、過旬與存讀均不得再領 30。

反例：下沉跳到出口、改道恢復疲勞、進城即判交貨、封橋但未載圖仍穿越、讀檔重抽伏擊、取消旅程退全糧、同一載具同時運兩隊。

待裁定：排隊優先、路線重算頻率、隊伍協議、速度與容量模型、遭遇密度、追蹤／迷路及中斷偏好。粗細校準需同策略與外界輸入，不能把玩家改道造成的差異當數值偏差。
