## 原框架的其他部分沒有漏掉

已重讀 [十二系統框架](../../wf/workflows/plan/living-world/world-framework.md) 與 [原需求對照](../../wf/workflows/plan/living-world/roadmap-coverage.md)。上表涵蓋政治、人物、生活、戰爭與 AI；其餘接點如下。

- **環境與生態：**[環境](spec-environment.md)讓工程改變通水與地貌；[生態](spec-ecology.md)由棲地、覓食與避險接到獸群遷移，再改牧人安排；[災害](spec-disasters.md)把預警、實際損失、疏散和重建分開。水退、驅離和離場都不自動復原。
- **經濟與旅行：**[市場](economy/spec-markets.md)把需求、訂單、真實交貨、部分履約和欠款串起；[旅行](economy/spec-travel.md)有集合、受阻、改道、拆隊、到達與交接。承諾不等於到貨，受阻仍有消耗。
- **力量、信仰與知識：**[奇幻手段](common/spec-world-magic.md)比較傳送、感知、治療、召喚與造糧如何改供應及部署；[教團](spec-faith.md)有神力失效後的合作、縮減和轉送；[知識](spec-knowledge.md)把發現、理解、使用、教學與失傳分開，導師或設備失去後能重議。
- **探索、歷史與故事：**[探索](spec-exploration.md)讓居民持續生活、發現物實際運出、離場保留改變；[生成史](spec-history.md)從初始來源接年代、遺跡及日常；[故事](spec-stories.md)由真需求形成可失敗的委託，文字不替世界發獎或保人物不死。
- **內容與續存：**[內容追加](spec-content.md)保留全 def 類型、整批驗證、回合尾提交、舊規則與歷史，新人物接第一個合法決策點；[腳本](spec-scripting.md)保留 M11 的受限效果、階段、失敗與重放。M10 與 M11 不合併縮水。
- **呈現與原開發驗收：**M0 純核心／Godot 分工保留；M1–M11 的實跑、主線、美術、音景、全 def 使用矩陣和校準仍是開發要求。當前未被授權實作，玩家呈現依最新指示後置。mark 與 root 的擱置也沒有解除。

## 審閱結論與證據界線

本輪以正文中的行為與正反情境審閱，並分別核對勢力／軍隊／城區及人物行為。文件大小、內部連結與差異另作機械檢查；這只能驗文件完整性，不替代上面的行為判斷。

完整運作草案與典型行為已具備；具體制度、職業表、數值、算法及更多故事可以在需要時再選。這項結論只對應使用者目前要的世界規劃，不表示遊戲已能運行、經濟已平衡或所有想像得到的例外都已窮舉。
