# 目前先規劃世界本身

← [本層入口](README.md)

## 使用者方向（2026-09-10，後續更正優先）

先不要考慮玩家的實際遊玩體驗。先把大地圖、中地圖、小地圖串成大概完整的奇幻世界模擬，知道 NPC 在各類情況下怎麼行動；再把玩家當成「由使用者提供 AI 的 NPC」。

先前「不要太細、太早訂死」「這只是遊戲，有些東西不要太認真」仍適用：要的是完整運作流程，不是現實社會百科，也不先訂完所有數值與例外。一般規劃取捨交 agent，沒有授權開始實作。世界存檔與人物存檔分開已定。

## 現在要先說清楚的事

**世界觀先以《勇者鬥惡龍》為背景參照**（2026-09-10 使用者建議），後續人物、場所與情境依 [背景草案](../world/spec-world-background.md) 展開，具體內容保持可調整。

- 沒有人類下令時，環境、人口、組織與 NPC 如何繼續推進。
- 大地圖形成哪些需要與安排，中地圖如何調度，小地圖的人物如何行動，再把結果交回去。
- NPC 知道什麼、在意什麼、能做什麼；缺料、受傷、被阻擋、收到新消息或失敗後怎麼換方法。
- 每件事由誰處理、要花什麼、改變誰的處境；同一批人貨與同一段時間不能三層各算一次。
- 粗算與詳算接得上；同一歷史可以保存、恢復與重放，不依賴有沒有打開畫面。

入口是 [共用流程](../common/README.md)，再接各領域既有規格。先用普通情況與典型中斷串成閉環，只有阻礙世界繼續運作的缺口才往下拆。

## 玩家之後怎麼接

先有世界人物及共同命令。NPC 的決策由 AI 提供；玩家接入時，改由使用者提供選擇，行動資格、資源、時間與結果仍走同一規則。角色不因由人控制就另有一份世界狀態，也不要求模仿 AI 的性格偏好。

玩家引導、通知節奏、人生篇章與操作便利性後置。先前 `spec-play-*` 文件保留作備考，不繼續展開，也不拿它們作目前世界流程的完成條件；其中一致性要求仍依所屬領域規則保留。

## 留到需要時再定

先保留可替換的時間粒度、預算算法、人物動機權重與制度選項。法律爭議可用簡單狀態和事件，遠方人口可用群組與摘要；不要求全世界每個人逐秒模擬。省略細節不代表可以憑空生資源或讓失敗工作永久卡住。

mark／獨特物件與 root 成長仍擱置；不要為了無玩家推進，就偷偷改成每個 NPC 都有自己的 observer。C++ 玩法、Godot 呈現分工不變。

## 完成到什麼程度

**Done when：**主要日常、短缺、危險、衝突、成長與權力變動，都能說清楚「誰察覺 → 誰決定 → 誰行動 → 結果改到哪裡 → 下一輪怎麼接」，三層拼起來沒有等玩家補命令才會動的空洞。這是規劃完成條件，文件不能代替實作、校準或效能驗證。


使用者後續補充：繼續勢力變化、軍隊調度、城區發展與人物行為。責任鏈完整只是起點；還要能說明各方為何如此選、何時換主意，以及選擇如何互相影響。只找到「可以回報失敗」不代表該 NPC 的行為已規劃充分。

使用者在收斂後另要求補國家差異、中小勢力興衰、神明自身行為，以及大災難與紀元變革。這些是目前共同流程上的行為深化；入口見 [本層索引](../README.md)，不以先前流程已完成為由省略，也不改成完整國家名冊或神話百科。

使用者另定四時代的文明與主角，並要求生物種類、起源、生活範圍和族群來歷；對應正文由 [背景](../world/spec-world-background.md) 導讀。DQ 保留生活氣氛，D&D 補奇幻取材，歷史以使用者指定的部落、城邦、希臘式世界及羅馬式第一帝國為骨架。人類與凡人早已存在，到黑鐵才成為主角；具體事件與血緣不因時代對應而全部定案。
