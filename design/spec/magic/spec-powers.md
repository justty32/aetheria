# S9a：力量、修行與超常效果

← [本層入口](README.md)｜[既有力量](../../rules/rules-magic-faith.md)｜[個體規則](../../rules/rules-individual.md)

## 範圍與完成條件

草案。Done when：取得、訓練、施用、維持、反制及失去力量都能跨三層接續；魔法改變社會條件，不成為免費改帳入口。不新增職業／殺怪經驗等級、Vancian 記憶術式或科技革命；不解除神器追蹤的擱置。

## 三層與狀態責任

| 層 | 輸入與行動 | 輸出 |
|---|---|---|
| Region | 魔素來源、學派人力、戰略儀式、長期維持 | 環境／交通／戰役效果請求、供需與風險 |
| Site | 法陣設施、參與者排工、陣地與施法窗口 | 儀式進度、方陣效果、設施損耗 |
| Local | 知識、媒介、身體狀態、逐次施用與反制 | 個人耗用、檢定、傷勢及目標效果 |

力量領域唯一寫入能力資格、修行進度、眷顧引用與施用紀錄；物資、健康、地形、位置仍由各領域寫入。解析度只領走同一施法／儀式的配額與區間，不各自判一次成功。

能力定義列來源、前置知識、可用目標、時距、分段代價、維持、冷卻、失敗、解除及效果類型；能力實例記取得原因、有效來源、剩餘資源或重建遊標、效果關聯。魔素存量、地脈產率、個人魔力不能混成一個無限共享池。

## 取得與成長

1. 訓練、實踐、反思是佔用真實工時的工作；疲勞、照護、授課、服役共享人物時間。重複零難度動作不能無限推高造詣。
2. 進度按有效練習與瓶頸要求累積；突破需具名的考驗、導師、場所或材料，不由「收到升階事件」憑空完成。事蹟核對既有結果，不重複領取。
3. 血統影響上限而非出生即滿階；長壽增加可用歲月，不免除學習、衰老、失能與資源限制。文化不由種族固定決定。
4. 多來源分開保留。建議有效位階由來源規則組合並受上限約束，禁止一律把武技、魔法、信仰各階數相加；具體組合法待裁定。失去媒介只撤該媒介效果，不抹除已學知識。
5. 一般裝備仍只走既有 quality 範圍；神器跨階屬明示例外。破階手段另列資格與作用範圍，不將所有增益偷偷乘入 quality。

## 施用、失敗與時序

候選 → 驗證資格／位置／資源 → 預約 → 分段準備 → 釋放檢定 → 維持／結束。準備被打斷保留已耗工時及材料；尚未消耗的預約可釋放。失敗的浪費、反噬、暴走須由定義選定，不能每種失敗都生成同一災害。

執行前重驗目標及來源；施法者死亡、失去眷顧、媒介被奪各有中止規則。釋放後獨立飛行／持續的效果不因施法者死亡自動撤回；需維持者則在下一個具名維持點失效。反制命中既有施法或效果 ID，不刪其歷史代價。

冷卻用絕對到期時戳；恢復用實際有效休息／供能區間與上限，切層不重置。護盾吸收量、燃燒傷害、召喚物負擔只在一處結算。戰略魔法沿用貴且慢、可被偵察破壞的儀式方向；不讓大層按鈕略過準備。

需維持的召喚物在來源失效後，依定義於維持點停止相應能力；若因此消失或無法繼續行動，通知它正承擔的工作、旅行、部隊及服務重驗。已搬到的貨、已花的時間與既有傷亡保留，未完成部分回到 [受阻與重議](../common/decision/spec-ai.md)，粗層不能繼續把它算成工人、載具或守軍。它攜帶的既有物品由失效／返回規則交代去向，不隨召喚者取消命令就抹去或複製。已成為不依賴維持的新生命，不因施術者死亡而一律消失。

## 能力如何改變文明

**世界行為接點：**已知且可用的能力應進入旅行、探索、工作等相關選擇，雇來的專家也可提供手段。先讓少量能力改變方法，不必每個法術附帶完整經濟模擬。採用、依賴與對方回應見 [奇幻手段推演](../common/cases/fantasy/spec-world-magic.md)；玩家體驗仍後置。

| 能力族（候選） | 必填限制與反制 | 社會後果與領域接口 |
|---|---|---|
| 傳送 | 端點、開啟窗口、載重、排隊、供能、阻斷；通道失效時落點規則 | 走旅行交接；轉移同一人貨。關稅可改由端點徵收，邊境牆不再保證封鎖 |
| 治療／延壽 | 可治損害、療程、施術人力、耗材、再發；不默認治一切 | 健康寫恢復，照護需求與繼承時距真的改變；壟斷可引起制度衝突 |
| 造糧／召雨 | 轉化或明示超常來源、產率、品質、範圍、維持 | 物資／水文入帳；農業可被替代，停供後按現存庫存承受後果 |
| 召喚／死靈 | 異地轉移、臨時構造或新生命三選一；維持與自主性 | 前者扣原地；後兩者登記來源。是否算人口／勞動由生命性質決定 |
| 預言／幻術 | 可查命題、觀測時間、誤差或偽裝、識破條件 | 產生情報而非改寫真相；預測不是鎖死未來 |

不強迫每個強力法術附帶任意災禍來維持舊經濟；若設定真的消除某種稀缺，社會就應改變。復活不屬基線能力，若選用須另定同一身分、遺產、繼任與人口政策，不能回滾死亡後的世界。

世界自行運作時，施術者與機構依已知需求安排能力，其他組織依供應結果調整生產、交通與照護。來源失效先停止不可能的供應，已造出的糧、已完成的旅行與已治好的損害不一律撤回；只有定義本來需要持續維持的部分才依規則失效。依賴供應的 NPC／組織得知停供後，可換施術者、走普通方法、減量、求援或放棄，不等待人類玩家處理。

## 保存、AI 與反例

AI 依已知媒介、代價及目標選能力，不能知道隱藏抗性或免費維持。保存工作、來源、已耗、效果、到期點、規則版本與去重鍵；詳算收回的是剩餘能力與後果，不是重新投影滿魔力。

- 儀式預約 10 魔素，準備耗 4 後取消：6 解鎖，4 不返還；重送取消不再增加 6。
- 傳送容量 8、隊伍 10：只准 8 過境或整隊等待，依已選隊形政策；不能兩端各留 10。
- 治療減少失能後才釋出勞動時間；健康與工作不能各加一次產能。
- 臨時召喚搬運者中途失效：已交貨保留，在手貨按規則落地或隨返回轉移，餘程停止；粗層不得繼續交貨或計入守軍。找不到接手者也留下真實受阻結果。
- 神器移交後前持有人失去該來源，新持有人是否可用仍驗認主／資格；不因觀看層級改位階。

## 舊文衝突與待裁定

[power-tiers](../../rules/power-tiers.md) 同時寫「位階＝significance」及羣體重要性不等於戰力；本案建議共用級名但分開語意，任職不授予武力。這是待裁定的收斂，不聲稱原文已如此。

舊個體規則允許多數 buff 離場丟棄，與 S0 的代價／後果連續存在衝突：建議可丟顯示緩存，玩法持續量須保留或可重建。成本曲線、來源組合法、恢復、反制序與各能力清單交 [裁定清單](../overview/foundations/spec-decisions.md)；數值表留後續平衡，不阻礙契約審閱。
