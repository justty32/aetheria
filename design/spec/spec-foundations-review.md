# 五個根本問題：先守住底線

## 目前採用的規劃方向

2026-09-10 使用者將一般取捨交由 agent 判斷，並要求不要太早訂死、以好玩為重。這五題先採以下簡單方向；具體算法仍可替換，不把之前的數字與制度樣例整批定案，也不要求使用者逐題批准。

**Done when：**基本結果不穿幫，能用簡單規則接回主要玩法即可。罕見例外在真的會用到時處理；本輪不開始實作。

| 問題 | 先守住什麼 | 先不訂死什麼 |
|---|---|---|
| D01 人口 | 已確認死亡者不再工作，人物與總人口不能重複計算；模型預算不能冒充活人 | 跨期補帳、拆群比例、全員具名等罕見出口，留人口玩法需要時選簡單方案 |
| D02 同刻事件 | 已做完的事不倒帶；新行動看有效條件；結果不依電腦偶然的處理順序改變 | 全領域精密順位、每種修橋與破壞的組合，不預先列完 |
| D03 消息與責任 | 世界照常動，角色可以晚知道；保留情報與誤判的玩法 | 撤權、善意交易、送達與追償可先用簡單事件處理，不先建完整司法模擬 |
| D04 強弱與重要性 | 當城主不會忽然增加武力；值得記住的人不必一直逐秒模擬 | 顯示叫法、分級閾值及每類人物的精細計算方式 |
| D05 離場效果 | 切地圖不應憑空補盾、解咒或重領代價；重要效果能接續 | 不要求所有效果逐秒永久保存；按玩法選摘要、到期時間或可重建資料 |

## 簡化怎麼用

停火後部隊尚未知情，可以用一次誤戰事件與簡單後果表達，不必先模擬整套責任追究。人口先確保活人數和可用人力合理，不讓玩家看到或操作內部補帳。護盾只要回來時剩餘效果合理，不必保留每一幀光效。

這些簡化要對玩家與 AI 一致、可說明、可重現。若更細的規則不能增加有趣選擇，就先不做。
