## 狀態與用途

2026-09-10 使用者授權 agent 處理一般取捨，要求保留彈性、以好玩為重；依 [規劃尺度](spec-planning-scope.md) 續作。下表保留比較材料，不是二十題使用者必答清單，也不是首版全做的承諾。明確舊裁定的改動仍須說清楚。

D01–D05 採 [簡單方向](spec-foundations-review.md) 繼續規劃；數字、精細制度與罕見出口留到需要時選，以下詳細建議不因此整批定案。

Done when：每個重大分歧有建議、替代代價、牽動規格與判別情境。材料數值、初始內容清單、效能門檻可在選定規則後再填，不把調參當設計衝突。

## A：共用底線；細則按需收斂

| 編號／問題 | 建議與理由 | 替代及代價 | 判別／規格 |
|---|---|---|---|
| D01 生命真值與命運赤字 | 分開實際存活、模型死亡預算、跨期赤字；死者不能供勞動／簽約 | 舊文當期高層總數不變若仍代表實活，會與具名死亡矛盾；需明定總數語意 | 死亡預算 1、具名死 3，赤字 2；下一期預算 1 僅抵 1、餘 1，不復活。羣組分裂／消失也不能丟赤字；[人口](people/spec-population.md) |
| D02 同時點因果序 | 已算區間先結束；再處理到期失效／環境變更，重驗依賴命令，提交，最後通知及結構尾處理 | 純 ID 排序可確定卻缺語意；只凍結回合起點會允許死者新行動 | 橋斷與進橋、眷顧失效與釋放、死訊與簽約逐對驗；[S1](common/spec-world-time.md) |
| D03 真效力與知情責任 | 物理／能力資格按真時點；法律分內部撤權、對第三方公告與善意救濟；停火義務與不知情責任分開 | 全部立即全知破壞情報；全部等通知又可讓死人簽約、毀橋通車 | 已撤職者在他地交易：真實資格、契約效力與補償分別判，不用全局布林；S7／[情報](spec-information.md) |
| D04 位階與重要性 | 共用五級名稱，分開力量與個別模擬資格，舊權重／quality 不變 | 強制相同會讓無武力君主因任職升武力；全面重做力量公式超出本輪 | 一名凡人被任命城主後應更重要但不忽然抗刀；[力量](spec-powers.md) |
| D05 離場後效果 | 可丟呈現快取；任何會改未來結果的剩餘量／時戳須保存或可重建 | 直接清 buff 可用離場解詛咒或回魔；逐幀全存成本太高 | 護盾用去一半、冷卻未完切層仍延續；S0／S9a |

D01 中「下一期抵赤字」是具體建議測例，不默認原文已定羣組轉移算法。若舊總數必須原封保留，應改稱模型帳並禁止拿它當實活，相關玩法選用時須明列這項語意變更，不要求現在定完算法。

D02 不能靠單一全球階段表解決全部競爭：同一橋同時修復／炸毀、同一資源多人領用，要先有領域仲裁。依賴環必須拆階段／時段或拒絕，不能排序後碰巧成功。

## B：對應玩法的候選方案

| 編號／問題 | 建議 | 替代及需要比較的情境 |
|---|---|---|
| D06 Site 出手序 | 首輪比較整側交替＋有限反應，沿既有方陣命令／AP，易讀且符合明確下令 | 單位速度輪替更細但割裂戰線；WEGO 更像同時戰場但承諾、衝突與提示成本高。均非即時制，不能混用 |
| D07 預約與搶佔 | 分階段預約、有限租期、緊急搶佔留下中止收據，禁止奪走已耗料 | 全工單一次鎖定易死鎖；完全無預約使長工單反覆搶不到料；測救災和建造同搶 6 石 |
| D08 市場撮合 | 先用明示交付地點的限價／定向交易；批次清算留比較 | 持續撮合敏感於先後；同時批次能公平但要訂價／分配法。兩者皆需實物及信用分帳 |
| D09 通道容量分配 | 任務優先級＋等待時間＋穩定鍵，重要政策可改優先，不能自動偏袒玩家 | 純先到先得可能救援排不進；純穩定 ID 造成飢餓。測商隊與難民同搶渡口 |
| D10 多年代歷史 | 與既有一次災變模式並列新 preset，版本化時距／預算 | 原地替換破壞舊 seed／地形承諾；全世界逐日細算成本未證；[歷史](spec-history.md) |
| D11 魔法社會邊界 | 保留慢貴戰略儀式，允許真實替代稀缺；每能力明寫來源、端點、產率及失效 | 只給百分比 buff 不足活世界；無限制傳送／造物會改全部經濟，須接受後果而非隱藏削弱 |
| D12 復活與新生命 | 基線不含復活；召喚先明定轉移／構造／生命 | 復活若加入需另定同一人、身分、遺產、繼任、靈魂及人口；不能僅加 heal effect |
| D13 地城耗竭 | cleared 作摘要，敵人／寶物回補必有移入、生長或具名生成來源 | 舊密度重生可能造成無限資源；永久空城又禁止合理再佔據；[探索](spec-exploration.md) |
| D14 遠方 AI | 粗算減候選與細節，但真實工作／代價不省；統計模型需校準 | 舊國力曲線若無來源便違反守恆；完整全個體過貴；[AI](spec-ai.md) |

**D06 固定比較盤面：**兩軍各有槍、騎、弓一隊，同一渡口、同一補給與已知敵情；弓手先暴露側面，騎兵可衝、槍隊可轉向。逐一記誰何時能反應、AP／世界時間、互相佔格、撤退與轉 Local 的交接。

- 整側交替：先手可連續配合，守方需明示已預備的反應，不能事後免費轉向。
- 單位輪替：速度可拆散攻方配合，不能每輪順序變化重置已耗 AP。
- WEGO：同時進渡口須衝突仲裁，展示預計而非保證路線；讀檔不能看對手未公開命令。

未做互動原型與數值驗證前，不宣稱哪種手感最好。三者均須讓本段世界時間只走一次，而非每支部隊各加一個 Site 回合。

## C：呈現、內容與長局的候選方案

| 編號／問題 | 建議及影響 |
|---|---|
| D15 玩家不是必然國家 | 角色透過職位代表組織；未操控人物走明示代理策略。死亡後續玩不自動附身繼承人，控制綁定需定案；S10d |
| D16 消息與全球異象 | 普通重大事件不自動全球得知；真正全球感知是超常規則。史實依賴不能等開面板才補算；S10a／e |
| D17 素材缺失 | 建議製作／發行驗證嚴格，玩家讀檔可用明示替代圖音；舊正式版拒啟動仍待改判，不能混說已定；S11c |
| D18 包／腳本相容 | 世界自帶基底與實際追加內容；版本不明停止，不能只靠 semver 猜相容。正式世界禁覆寫，開發熱重載另隔離；S11a／b |
| D19 成本與校準 | 精確帳零誤差、近似分佈先定統計量／容差、玩家介入另測 δ；預算按工作量而非牆鐘改結果。效能數字由量測填；[驗證矩陣](spec-verification.md) |
| D20 世界完結 | 建議篇章可完結、世界可續玩；競技勝利另作模式。失敗可留下新故事，不保證每條人工主線永遠通關；S10e |

## 不構成本輪未寫完的項目

每個領域的初始種族、法術、教義、任務與美術清單屬內容製作；成本、概率、效能門檻屬平衡／量測；資料結構與 API 屬動工前 plan。功能契約已指明其欄位、責任和驗收，未假造這些數值為定案。

mark／獨特物件追蹤與 root 成長軸仍維持擱置；要靠它們實現的自動遠方細模擬、專屬音樂提示等不能列入無依賴的首輪承諾。既有待裁定不因使用者要求完成文件而變成批准。
