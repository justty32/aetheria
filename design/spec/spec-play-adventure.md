# 冒險、旅行、修行與日常的遊玩循環

← [本層入口](README.md)｜[共用玩法循環](spec-play-loop.md)｜[玩家人生](spec-player-agency.md)｜[探索](spec-exploration.md)｜[力量](spec-powers.md)

## 這篇要解決什麼

草案。**Done when：**冒險者的目的、選擇、代價、回饋與失敗出口能用一段實際遊玩說清楚。這篇不列公式、完整職業與事件表，也不解除 mark／獨特物件和 root 成長的擱置。

核心樂趣的**暫行方向**：玩家在有限時間下挑一段值得冒險的人生，選擇親自投入哪件事，又願意放棄什麼。

## 冒險者怎麼過日子

沿用[共用循環](spec-play-loop.md)的「目標 → 參與方式 → 行動 → 結果 → 新機會」。以下是常見節奏，不是每趟都得依序走完；在城內拜師可以沒有 Region 旅行，護送商隊也可以不進 Local。

### 挑一個此刻在意的目的

目的可以是賺旅費、尋人、解開傳聞、拜師、救村落，或只是去沒見過的地方。它應回答「為什麼現在去」，並露出幾條不同路：快但危險、慢但穩、欠人情換幫助。任務可以提供方向；玩家也能從地圖、關係與自己的野心出發。

季節會變、別人會先到，同伴也有自己的安排，讓「先做哪一件」有意思。

### 準備到自己敢出發

玩家在 Site 找同伴、買補給、打聽消息、安排住處與工作。準備越多通常越安全，卻會花錢、花時間，也可能讓機會溜走。資訊可以不完整，但玩家要看得懂已知風險，不必把背包整理成會計工作。

**暫行方向：**日常沿用[玩家人生](spec-player-agency.md)的委任與摘要。玩家只訂花費和底線；缺錢、受傷或需要改目標時才被叫回。省操作不省時間與物資。

### 旅行時決定什麼值得插手

長途旅行先選路線、步調與遇事方針，然後快速推進。天候、封路、追兵或求救可能改變計畫；只有牽動目的、重大代價或人物關係的事才中斷。其餘按方針處理，以短報告交代花費與結果。

玩家可親自處理，也可接受延誤、繞路或放棄。帶什麼、是否停下救人、能否趕上期限，本身就是冒險。

### 親自下場時決定做到哪裡

若需要深入，玩家在 Site 找入口、紮營、接觸居民、安排留守與退路，再到 Local 用線索、交涉、潛行、工具或戰鬥解題；答案不一定是殺光敵人。有些目的在 Region 或 Site 已完成，不硬塞一段下層冒險。

越深入，發現可能越好，也越難帶走。看見、讀懂、取得、運回及說服別人相信是不同成果；只完成幾段，故事仍成立。

### 把經歷變成下一段人生

回城後，玩家處理傷勢、分配所得、履行承諾、分享或隱瞞發現。回饋可以是錢、新關係、通行機會、老師收徒，或下一個問題；世界也留下被救的人、被激怒的勢力和錯過的時機。

修行嵌在循環裡。玩家先選「最近想學會什麼」，再找老師、場所、材料與實踐機會。**暫行方向：**練習能穩定累積，突破來自有意義的準備或考驗，不靠重複安全動作刷滿。修行會擠掉賺錢、旅行與陪伴的時間；改目標仍保留已學部分。

## 一段具體遊玩故事

藥師學徒米菈聽說北方荒村的井水開始發藍。她想找到病因，也想藉此取得水術師的指點。Region 上有三條路：官道安全但可能趕不上病情惡化；翻山較快但初雪將至；搭商隊能分攤補給，代價是答應沿途護送。

她選商隊，把採藥和房租交給師兄代管，保留最後一包解毒草。前幾天只是看風景、採到一株沒見過的香草，晚上和車夫聊天。後來遇到受傷的信使：救人會耗藥並延誤，不救便不知道山口已塌。米菈救了他，信使送她一枚沿途驛站可用的通行章；她也因此及時改道。

在 Site，她發現腳印通向廢棄神殿。村長要封井，礦工卻怕停水失業。她安排商隊運水，自己和礦工下到 Local。兩人沒擊敗守護者，只從排水道取得污染的祭壇碎片；撤退時礦工摔傷，護送期限也過了。

回城後，商隊只付部分酬勞，礦工家屬卻願意作證；水術師也因她帶回真線索，爽快教了第一個淨水技巧。她還能把新香草做成一款普通但好賣的茶。神殿仍在，村水只暫時解決。下一輪可修行後重返、護送淨水物資，或把線索賣給別人。三層地圖只是這次經歷的遠行選擇、地方安排與親身行動；這只是一種可能，不是世界上限或預定主線。

## 失敗後還有什麼可玩

失敗先改變處境，再產生選擇，不把玩家送回接任務前。

- **沒找到：**保留已探過的路；可換線索、找嚮導、追別的目標或讓競爭者接手。
- **沒帶回成果：**證據可能留在現場；可救援、贖回、重做載體或憑口述承擔可信度。
- **受傷、破產或失約：**養傷、工作、借貸、賠罪或過低風險生活，但不能只剩連按睡覺。
- **錯過期限或別人先完成：**需求結束，關係與新消息仍留下；可收拾後果、加入下一段局勢或換目標。
- **角色死亡或失去行動能力：**這段人生可以收尾，世界仍往前；接續方式沿用玩家人生規格，本文不替玩家指定繼承人。

若暫時無力遠征，城鎮內仍應有短工作、交往、學習、交易、調查與準備下次出發的玩法。

## 暫行方向與未來試玩

以上取捨皆為**暫行方向**，試玩若拖沓或太省略就調整，不定死粒度。

未來只需優先試三件事：

1. 一趟遠征中，多少次旅行中斷會讓玩家覺得世界活著，又不嫌被打擾？
2. 委任日常後，玩家是否仍能理解錢、時間與健康為何改變，並在必要時願意接手？
3. 一次失敗能否在很短時間內露出兩個真正不同、都想繼續玩的方向？

## 與既有規格的關係

本文不改既有世界帳、旅行、探索、力量、任務與玩家身分規則，只把它們排成玩家能反覆經歷的節奏。沒有發現硬衝突。需留意的張力是：[玩家人生](spec-player-agency.md)仍把「未操控策略的預設」列為待裁定；本文只提出日常可委任的暫行體驗方向，未把某套代理行為定為正式預設。
