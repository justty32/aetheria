## 範圍與權威

草案。Done when：世界事實、目擊、推測、說法與通知可以不同步且不串角色；AI 和 UI 只能用被授權知道的資料。私人信念與知識記錄由 core 持有，角色檔是保存邊界，不是 Godot 自行維護的真相。

| 層 | 獲知方式 | 允許的摘要 |
|---|---|---|
| Region | 信使、外交文書、組織彙報、遠方偵察 | 已知疆界、估計軍力、報告時間及可信範圍 |
| Site | 哨站、商會、酒館、官署、巡邏 | 地方事件、服務可用性、可接觸人物 |
| Local | 感官、對話、閱讀、搜證、魔法觀測 | 眼前現象、人物辨識、取得的主張與物證 |

各事件領域擁有事實；情報領域擁有觀測／主張、傳播及接收記錄。沒有全域「大家知道」布林。地圖迷霧包含從未見過、已見但陳舊、目前可見，不以失去視野抹去曾經看到的橋。

## 主張與傳播契約

主張記命題、對象穩定引用或尚未辨識描述、來源、原始觀測時點、轉述鏈、聲稱有效區間、位置／數量精度、可信度與保密範圍。來源不明可成立，不得偽造為權威確認。

形成 → 編碼／攜帶 → 在途 → 接收 → 採信／存疑／駁回 → 更正／過期。消息由人、物品或具名超常通道運送，有容量、時距與攔截風險；內容存在不代表收件人已看。通路共用報告可批次傳播，不能每個人各算一趟運輸。

同一目擊經十人轉述不算十份獨立證據；合併保留共源關係。新報告不一律覆寫舊報告：時間較新但來源較差時可並存矛盾。信任估計屬知者，不把資料真偽直接暴露給接收者。

系統追蹤的真實來源鏈，和人物能辨認的來源分開。人物只按可見署名、引用與已知往來判斷是否共源；來源被隱藏或冒充時可以誤信，查證後再更正。不能讓 NPC 免費讀出所有匿名傳聞其實出自同一個人。

組織情報依職位、任務與保密授權分發。離職失去繼續查檔權，不自動刪腦中記憶；保密義務與違反後果走法律。玩家切角色只換視圖，不自動將前角色祕密傳給後角色或 NPC。

## 偵察、欺騙與反情報

偵察指定要查的命題、路線、投入、風險與報告方式。搜索可沒結果；「沒看到軍隊」不等於「確定沒有軍隊」。間諜必須有接觸路徑，賄賂扣真錢，偷文件改保管／證據，抓捕走司法／戰爭，不另設瞬間成功按鈕。

偽造是新增錯誤主張，不修改底層事實；偽裝影響識別與估計。更正保存曾經誤信的記錄，責任與仇怨不因真相揭露自動清零。預言若成立也只提供其定義允許的觀測，不免費解鎖全圖。

命令預覽依已知條件估計；核心實際驗證可拒絕，但理由須經可見性過濾。遠方遭遇未知封鎖，可回「尚未取得通行確認」，不能以 API 錯誤回傳隱藏敵軍精確人數。嘗試行動造成的新觀測須花相應時間／接觸代價。

## 時序、保存與容量

物理效果準時發生，消息到達才更新知者；同時點到信與下令依 S1 的已選階段處理。過期表示不確定增加，不一定徹底忘記。對象死亡後穩定引用可保留墓誌，不解析成重用槽位的新人物。

保存主張、知者或具同等知情範圍的羣組、在途消息、已收版本、轉述來源及到期點；壓縮可併同源摘要，不可跨保密範圍合併。低重要消息可限額排序延後，不能吞掉影響當前決策的法令或危險；溢出策略須可追查。

## 驗收與舊案衝突

- t0 橋毀、t1 商隊實際到橋、t2 都城收信：商隊不能穿橋；都城 t1 的計畫仍可因舊知識誤判。
- A 目擊 20 人，B 轉述成 200，C 收到兩封明示引用 B 的信：C 不得把它當兩份獨立觀測。若共源被隱藏，C 可誤判，系統仍保留真實傳播來源供後續查證。
- 玩家先用間諜再切國王，無正式報告時國王視圖不更新；人的記憶無法消除，但核心不能替玩家角色免費傳訊。
- 開 UI、重新排序清單、被拒命令，不增加情報或推進世界時間；真正偵察另算。

舊 [重要性](../../../simulation/significance.md) 寫神器出土所有勢力收到消息，舊敘事有「打開纔算」：本篇建議重要性決定處理／呈現優先，獲知仍需傳播；有外部依賴的事實不可延到打開面板。全球異象例外須資料明訂，待裁定。

待裁定：可信度合併／老化、未辨識對象追蹤、反情報檢定、通知與法律效力、訊息容量。無需精算每人口的每句閒話，但必須保留關鍵知情差異。
