# 消息未明時的選擇與河谷報告

[本層入口](README.md)｜[規則主文](spec-information.md)

先讀情報主文的主張、傳播與知情邊界；本篇展開尚未查清時的行動及矛盾報告情境，時序、保存與驗收仍見主文。

## 還沒查清楚，也要選下一步

草案判斷：先問矛盾會不會改變眼前安排，再比較查證所需時間、能否接觸來源，以及猜錯或拖延的代價。查證只提高所知，不保證查到答案；既定等待與改案沿 [AI](spec-ai.md)。

| 處境 | 可採取的安排 | 何時重議 |
|---|---|---|
| 消息矛盾但不影響眼前工作 | 維持原案，保留疑點；不必為每則傳聞停工 | 相關決策將到、來源補充或現場條件改變 |
| 猜錯代價大，尚有時間查問 | 派斥候、問實際承辦者、找不同可接觸來源；先少量試運或保留預備 | 新證據到達，或查問仍無結果而期限將至 |
| 等待本身會錯過救援或吃光糧 | 按目前判斷行動，可縮短行程、分批或帶替代方案 | 實際路況、供應或傷病推翻原估計 |
| 已有可靠現場危險，舊報仍說平安 | 先按眼前危險避險、回報或改現場安排 | 有權者收到結果後再調整其他地方，不讓一處觀測直接替全國改令 |

人物仍可因信任某人、固執、恐懼或職責而選不同辦法；這些要有自身經歷與所知依據，不把「最保守」定成唯一正解。

## 河谷兩封矛盾報告

商人說渡口通暢，斥候說附近有武裝隊伍。兩封信可能描述不同時間，也可能同時為真；有武裝不直接證明封路。地方為趕運歉收後的援糧，可詢問是否攔車、派人探路或先送小批；軍官保留護路力量，勢力先談通行而不立即全面動員。缺糧家庭可先找本地食物，不必等軍方查清整件事。

若對方故意散布「渡口已封」來把商隊引向收費路線，也須先讓消息經可接觸的人或通道到達；商人可能相信、懷疑或另行查問。說謊者只能按收到的車流或回報判斷是否奏效，不直接看所有人的信念，更不能靠造謠真的封橋。

後來護送隊實際通過，接報者可改判、恢復較大貨量，卻不能退回已付繞路費、補回錯過的交期或立即修好關係。已在途中者須收到新安排並確認路線可行，才改走法；謠言仍可能在其他地方流傳。

核對時只改報告送達順序或來源是否可辨，查看選擇理由、實際路線及代價。若兩案最後仍走同一路，也可能是替代路更差；不能為了展示分支，強迫每次消息不同就改令。
