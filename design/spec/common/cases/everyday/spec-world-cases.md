# 用日常與變故檢查 NPC 世界

← [本層入口](README.md)｜[完整循環](../../flow/spec-world-operation.md)｜[原七情境](../../../../../wf/workflows/plan/living-world/world-scenarios.md)

## 怎麼讀

這是原情境的純 NPC 推演，不新增固定劇本。**Done when：**每條能指出誰得知、誰選擇、誰執行、留下什麼及下一輪怎麼接；沒有人類輸入也不缺一個決策者。文中的選擇只是可行分支，不要求每個 NPC 都這樣做。

本輪只檢查流程。具體數值、成功率和個性權重保留彈性，沒有宣稱遊戲已執行通過。人物可在 Local 詳算或由原責任層粗算；無玩家不代表全世界逐人展開。

## 一、工匠要交貨，但家人突然生病

承接原情境五。工匠有工具訂單，家庭本來有吃住與照護安排。

1. 病情先由健康規則發生；家人或工匠察覺後，才形成求醫或照護需求。遠方雇主不會立即得知。
2. 工匠衡量家人、交期、收入和可求助的人，可以請人照護、請假或繼續工作。家庭成員也能主動求助，不必等官署派任務。
3. 地方收到請假或缺工回報，才重排工作。接手者需有能力、工具和空檔；不能把原工匠同時算在病床旁和工作臺。
4. 已做成的零件留下，照護與醫療按真實服務進行；缺藥或無人接手時，可延期、改治療方式或承認無法處理。
5. 下一輪依病情、收入與交貨狀況繼續安排。照護成功不會自動完成訂單，交貨成功也不表示家人痊癒。

**流程核對：**沒有玩家接單仍有人工作與照護；取消只釋放未耗部分。依據是 [地方流程](../../flow/spec-world-place-flow.md)、[家庭](../../../people/family/spec-households.md) 與 [人物立場](../../../people/behavior/spec-motives.md)。

## 二、缺糧求援，但援糧沒有抵達

承接原情境一及整合 A。居民先感到食物短缺，地方從收成與庫存察覺供應問題；遠方政府和商人透過報告先後得知。

1. 家戶可減少其他支出、找工作、求助或準備離鄉；地方可採買、配給或求援。不同人的選擇不必一致。
2. 供應方接受後才安排庫存、車隊和護送。承諾送糧不是已到貨，也不停止收件地的日常消耗。
3. 道路中斷或車隊遇襲，現場依所知改道、等待、撤退或求救；實際留下貨物位置、消耗、傷亡及消息。
4. 收件方尚未知道原因時，可因約定到貨時間已過而查問、找第二來源或縮減計畫；不能直接知道伏兵位置，也不能永遠當糧食明天必到。
5. 若仍無法維生，家戶可遷徙，地方可疏散或繼續求援。傷病、死亡和人口流出照實發生；遷徙途中仍有食物、通路及照護問題。

**流程核對：**求援失敗有下一步，世界也容許惡化。依據是 [大地圖流程](../../flow/spec-world-region-flow.md)、[情報](../../decision/spec-information.md) 與 [整合 A](../../../review/spec-integration.md)。

## 三、城牆未修好，敵軍已到

承接原情境三；原文玩家曾修牆的起點，這裡先改由地方 NPC 決策者安排，建造與戰鬥仍用同一規則。

1. 地方依已知風險修牆；材料、生產與施工逐段留下真實進度。偵察報告到達後，指揮者重新估計時間。
2. 可以趕修要點、守現有缺口、求援、疏散或談判。未完成的牆仍有缺口，不能因進入戰鬥就補成完整城防。
3. 抽人守城會減少施工和民用工作；部隊領用的糧械不能再供工坊。現場人物執行搬運、警戒、修補、交戰或救援。
4. 守住、撤退、投降都把真實傷亡與控制變化交回；有人拒令或失能，指揮者改案，不能補出另一個滿員單位。
5. 戰後地方依現況安排救治、食物、清路和修繕。安全與供應尚未恢復，流亡居民可繼續留在外地；戰鬥結束不等於地方恢復正常。

**流程核對：**建造、守城和恢復接的是同一座城、同一批居民。依據是 [地方平戰流程](../../flow/spec-world-place-flow.md) 與 [驗證矩陣 S3／S4](../../../review/validation/spec-verification.md)。

## 四、帶回新知識的人失去導師

承接原情境四及整合 B。探索者因已知線索、組織委派或個人目標出行，並非等玩家接任務才有人探索。

1. 探索者安排旅行、工具和風險處理；取得文獻後才有搬運、保管與研究工作。發現物不會同時出現在各城書庫。
2. 學院安排具備基礎的人研究，理解後才能教或用；缺設備時可籌措、合作或先停在已理解的程度。
3. 導師死亡停止其未來授課。學徒保留已學內容，學院盤點仍能接觸的師資與文獻；不知道外城副本，就不能自動前往那裡。
4. 學徒可查問、求其他教師、自己研究、轉學別技或放棄。線索與資源不足時，研究可停滯，完整方法也可能失傳。
5. 成功恢復教學後，新知識沿實際接觸擴散；不同地方依需要和能力採用，帶來新的工作、材料需求與利益變化。

**流程核對：**取得、理解、教學、實用各有承接者，失去一人不把所有進度清空。依據是 [知識](../../../magic/spec-knowledge.md)、[大地圖流程](../../flow/spec-world-region-flow.md) 與 [整合 B](../../../review/spec-integration.md)。

## 五、領袖死亡，前線尚未收到消息

承接原情境二及整合 C。死亡是真實事件，各地何時知道另走消息途徑。

1. 死者不再作決定；生前有效的工作與行軍不因死亡全部歸零。
2. 得知的人依現有制度找代理、接任者或協商安排。權位有爭議，可以暫時維持必要工作；不假設必定爆發內戰。
3. 前線沿仍有效的舊命令行動。新命令必須出自仍有相應權限的人；傳令者不能冒用死者繼續產生命令。
4. 軍官得知爭議後，可接受、查證、延後爭議行動或選擇效忠。分隊、衝突與談判都用原有人員及資源。
5. 新安排成立或衝突持續，都把命令權、控制、人貨和未完工作交入下一輪。換領袖不會重新生成國庫或抹去地方生活。

**流程核對：**人物死亡、職位變更、消息送達和部隊行動分開；沒有玩家裁決也有和平、僵持或衝突出口。依據是 [整合 C](../../../review/spec-integration.md) 與 [大地圖流程](../../flow/spec-world-region-flow.md)。

## 六、新文明與新技藝進入既有世界

承接原情境六。追加先驗來源與相容性，成功後才有新實體；人物與組織帶著符合來源的認知、承諾和生活需求，接入合法決策點。缺糧就採買或求援，不因新文明標籤而自給自足。

新技藝先由具備相應知識與條件者使用，舊居民透過接觸、教學或報告認識它，再決定採用。反例是全世界瞬間學會、或新人物生成後永遠不行動。依據與全 def／腳本驗證仍在 [內容追加](../../../content/spec-content.md)，本例不縮小其範圍。

## 七、等待很久，世界仍要繼續

承接原情境七。工坊等援料時，上游供應被取消；執行層重驗直接依賴，遠方工坊仍可能不知道原因。到了約定檢查點，它可查問、換來源或縮減工作；居民吃住和傷病照常推進。收到真實消息後再改案，不能永遠只等成功通知。

換層或讀檔保留等待理由與檢查時點；已取消目標的舊提醒不重開工作。依據是 [時間](../../continuity/spec-world-time.md) 與 [AI](../../decision/spec-ai.md)。多輪比較仍須按 [驗證要求](../../../review/validation/spec-verification.md) 追人口、資源、知識與世界變化，短例不能代替長局校準。

以上只證明草案能指出行為承接者；NPC 選擇、等待喚醒、追加使用與長期結果，仍待實作測試。
