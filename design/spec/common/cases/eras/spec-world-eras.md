# 大災難過後，世界怎麼走進另一個時代

← [本層入口](README.md)｜[災害](../../../nature/spec-disasters.md)｜[歷史](../../../world/history/spec-history.md)｜[國家差異](../../../politics/factions/spec-country-patterns.md)

## 本輪要接什麼

草案。**Done when：**正在運作的世界遇到廣泛變故後，各方能阻止、減輕、適應或利用它，形成不同的長期格局；人物仍能生活，世界不重置，也不必等勇者通關。這裡不定災難週期、紀元清單、傷亡公式或完整神話史。

本篇接開局之後的變化；生成史的舊模式仍沿原規則。紀元不是第四層地圖或新時鐘，也不預設中世紀必須一路走向科技革命。

## 先分開三件事

- **實際變化：**道路消失、神力來源失效、魔物遷移、統治者倒下，或新的可用方法逐步傳開。由相應領域生效，各有範圍與時間。
- **新格局：**各方因變化而遷居、改行、結盟、接管服務或建立新安排。可能維持很久，也可能很快被推翻。
- **紀元的叫法：**史官、教團或民間把某段歷史稱為「失路之年」「諸神沉寂之世」等。不同地方可用不同名稱、不同起點；名稱不會再扣人口、換國王或關閉法術。

不需要全世界同時承認換時代。核心記已發生的事件、影響範圍與必要因果；各方按實際見聞形成自己的說法。若內容有真正遍及世界的異象，另依能力與傳播規則明示，不讓「世界大事」自帶全知通知。

## 什麼會形成轉折

| 起因示例 | 先改變什麼 | 各方接下來有什麼選擇 |
|---|---|---|
| 大河改道、連年歉收或多地疫病 | 地方的通行、收成、健康與供應 | 修復、轉運、移居、改用土地、相互救援或爭奪可用地方 |
| 某個封印逐步失效 | 被約束的既存危害開始影響相連地區 | 查因、加固、另找限制方法、撤離或與其中可交涉者談條件 |
| 神祇沉默、隕落或失去某項能力 | 新請求可能無回應；既有眷顧依來源與維持條件變化 | 查證、求其他幫助、維持普通服務、改變合作；神明也按自身所知行動 |
| 魔王敗亡、帝國失去統合能力 | 舊命令、保護及公共安排面臨承接問題 | 地方自保、另立領袖、聯合、分離或延續舊承諾，不要求天下即刻和平 |
| 通路重開、失傳方法恢復 | 一些地方出現可用的新機會 | 學習、試做、貿易、移居與合作；舊行業也可調整，不只有災難能形成新時代 |

這些是可用的起因，不是必輪到的事件表。封印、神力、災源和人口都要有本局來源；不因太久沒大事就補一場末日。預兆可能被忽略、誤解，也可能被及早處理，使轉折根本沒有擴大。

## 一次轉折怎麼延續

1. **已有條件發生變化。** 自然過程、人物行動或具名超常事件觸發實際效果。預警另行傳播，世界不等所有人都知道才生效。
2. **各方先處理眼前問題。** 保命、保住供應與未完承諾，也可觀望、否認或冒險。受影響地方與未受影響地方可能做完全不同的事。
3. **應對改變其他人的選擇。** 王國抽船救援會減少商運，商會另開航路可能讓舊城失去生意；神殿求助另一教團可能促成合作，也可能引起內部分歧。
4. **反覆結果促成較長安排。** 有持續需求與可用人手才值得新建港口、遷移學院或長期結盟。一次高價或勝仗不足以宣布整個新時代已成立。
5. **各地延續或再改案。** 災害可被控制，新航路仍可能留下；神力可恢復，已遷走的人不一定回來。若新安排也撐不住，能再縮減、分合或離開。

危機來源結束、恢復生活、新秩序形成是不同進度。有人獲益也不表示受災者已被安置；不能以「進入復興紀元」跳過缺糧、照護和重建。

## 時間、保存與核對

沿同一世界時鐘推進災源、在途、工作和決策。大地圖保存跨地影響，中地圖接地方安排，小地圖接現場行動；遠方用原粗算責任，不要求全世界展開。超常條件改變走既有能力／環境效果，不用改寫全部內容定義來假裝換紀元。

保存尚存危害、作用範圍、實際後果、未完應對、各方目標及已知消息；歷史另記各地的紀元稱呼和依據。壓縮普通過程可以，不能刪掉仍影響封印、權利、追查或義務的來源。換人物檔、離場或讀檔都接同一個世界，不再觸發一次災難。

核對四個改動：無冒險隊來、神明沉默、替代航路不足、封印提早恢復。每個分支都要找得到仍在行動的各方、代價與後續；允許平穩、改善和惡化。這是文字推演，尚未驗證實際長局模擬或平衡。
