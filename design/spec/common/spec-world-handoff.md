# S0：身分、責任範圍與交接

## 範圍與不變量

草案；細化 [模擬契約](../../../wf/workflows/plan/living-world/world-simulation-contracts.md) 與 [領域權責](../../../wf/workflows/plan/living-world/world-state-ownership.md)。不新增地圖層、不裁定持久 ID 的編碼，也不開發 mark。

**Done when：**一支部隊與一張工作單可以逐級展開、部分提交、轉場及收回；人數、物資、時間無重疊責任，也無漏算區間。

「高層權威」負責持久總帳與授權；「主場」負責指定範圍的推進；「領域寫入者」驗證並套用各領域效果。三者不能合併為任何模組都能直接改全部狀態。

## 身分資料語意

| 對象 | 持久辨識與可變關係 | 禁止混用 |
|---|---|---|
| 地點 | 既有世界識別與 `ZoneKey`，細格位置另記尺度 | 不另發 `SiteId` |
| 人物 | 穩定人物身分；所在世界、位置、職位、群組是關係 | 不用 registry 的 `EntityId` 當終身身分 |
| 勢力／職位 | 各自身分；任職與效忠有起訖 | 統治者死亡不刪除國家 |
| 人群／軍隊 | 群組身分與組成；戰術方陣引用來源配額 | 投影不是新增人口 |
| 物資／物品 | 批次及數量；必要時拆出物品實例；保管與所有權分列 | 裝備引用不額外增加庫存 |
| 工作／事件 | 穩定紀錄、參與者與結果引用 | Local 面孔不另領一次報酬 |

跨 zone 現場存取仍遵守 `EntityRef` 弱引用可失敗的原契約；找不到現場物件不等於人物死亡。持久身分如何定位當前 `EntityRef`，留人物／旅行規格，不在此發明全域常駐 registry。

## 交接紀錄（語意，不是 C++ API）

| 欄位群 | 必須能回答 |
|---|---|
| 辨識 | 世界、交接識別、父交接、來源／目的主場、規則版本 |
| 範圍 | 哪些對象、領域量、空間範圍與配額被委派；不能只記整張地圖旗標 |
| 時間 | 起點、已提交游標、授權終點；所有區間採左閉右開 `[a,b)` |
| 基線 | 交出時的領域版本、人數、庫存與可消耗預算 |
| 延續 | 未完命令、工作、預約、到期工作與持久改變 |
| 收據 | 提交序號、前一收據、區間、效果集合、已接受結果 |

同一對象的同一領域量／配額在同一區間，只能有一條有效推進責任。不同領域可同時工作，但各自只能寫所屬欄位。父交接領出子交接後，父方扣除子範圍；子結果沿父鏈彙整，不能再直送祖先加一次。

## 生命週期

1. 申請：observer 提出解析度需求；協調器查來源版本與未交出額度。
2. 準備：在合法邊界結算到交接起點，建立投影與續作資料。此時新主場尚無寫入權。
3. 啟用：原主場停止該範圍的粗算，新主場取得責任；兩者同一提交點生效。準備失敗保留原主場。
4. 分段提交：提交從已確認游標開始的連續區間與效果。全部領域預驗證成功才接受該段；已發生的代價和產物一同入帳。
5. 收回：先結清子交接，再結清本交接到收回時點，移交未完工作及到期點，最後才卸載。粗算從收回點開始，不從上次旬界重跑。

跨地點移動由旅行規則交接位置與保管，不是新生一個副本。新地點未能接管時保持可保存的在途／等待狀態，不讓人物同時在兩城工作。

## 重送、失敗與保存

- 同交接、同序號、同內容重送：回傳原收據，不再套效果。同序號不同內容：拒絕並標衝突。
- 跳號、區間重疊／留洞、已關閉交接、版本失配：拒絕本段，保留最後一致狀態；不能自行捏造補算結果。
- 保存責任鏈、游標、預約、未完工作與已提交收據的必要資訊。壓縮歷史須仍可辨識重送；不能只剩一個「戰鬥完成」旗標。
- 健康、疲勞、損毀與世界位置保存不可再生原因及必要狀態；路徑、動畫與可重建姿態可丟棄。若重建不足以保持結果，該份資料不能分類為易失。
- AI／UI 看到自己的可知摘要、剩餘授權與拒絕原因，不能直接持有帳本容器。除錯可全知，正式觀測不可洩漏隱藏敵方範圍。

## 可手算驗收

軍隊 100 人，Site 領 40 人，Local 再從這 40 人領 10 人。粗層保留 60，Site 自算 30，Local 算 10。Local 死亡 2 人、交回 8 人，Site 共剩 38，最後 Region 共剩 98；死亡事件傳播不再次扣兵。此例刻意不含新徵兵或逃兵。

同一工作領木材 12 份，Local 消耗 5、退回未耗 7；Site 不得再依原定整單用量扣 12。重送交付、收回後再送舊結果、讀檔後再領材料都須保持相同餘額。

精確守恆與粗細校準分開驗：同模式同歷史必須重放一致；不同解析度的近似分布遵守原校準界限，不要求每個種子戰損相同。

上述一般配額例不覆蓋既有命運赤字裁定；具名損失超過模型配額時的例外、實際人力與赤字移交，見 [S5a](../people/spec-population.md)。尚待裁定的接口不能冒稱已滿足逐事件人口相等。

待細化：交接範圍的最小可切單位、收據壓縮與崩潰恢復格式。這些阻擋實作定案，不阻擋其他系統描述需要交出的量。
