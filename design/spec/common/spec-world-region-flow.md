# Region 如何持續運作

## 範圍

暫行草案。**Done when：**沒有玩家時，環境、商隊、組織與國家仍沿同一時間線行動；生產、災害、戰爭、領袖死亡與新知識都進入同一循環，留下供下一段決策使用的結果。

本文說明 L1 `Region` 怎麼串接既有領域，不新增全知中央 AI，也不重寫各領域規則。不定公式與完整政策；mark／獨特物件及 root 成長仍擱置，不授權實作。

## 一條共通循環

每一段時間大致依下列順序前進。實際遇到洪水、交戰、死亡或貨物抵達等到期事件，仍按 [S1](spec-world-time.md) 切到正確時點，不必硬等整旬。

1. **先把已發生的事算到現在。** 天氣、作物、工作、旅程、戰鬥和合約各由所屬領域推進。已委派給 Site／Local 的份額由其主場計算，再依 [S0](spec-world-handoff.md) 交回，Region 不重算。
2. **消息沿真實途徑送達。** 地方官收到災情，商會收到價格與通路報告，軍隊收到命令，家庭收到親人消息。不同人可在不同時間知道同一件事，也可能只得到傳聞；世界真值不直接灌進所有 AI。
3. **決策者更新目標。** 各方依自己的職責、承諾、資源與已知風險行動。受阻目標保留原因；小波動不推翻長期方向，生存危險可插隊。
4. **分配真資源並委派。** 決策者在權限內選少量可行動作，把預算、人力、物資、期限、底線與退出條件交給地方或旅隊。接受委派不等於成果已發生，地方仍需排工作、取得材料並面對途中變化。
5. **跨區行動實際上路。** 旅行、交易、文書、援軍與移民都占時間、容量與通路。相鄰 Site 不直接互扣庫存，由 Region 中介。
6. **結果回來，成為下一輪的起點。** 完工、部分交貨、拒令、戰損、通路中斷、研究成果或領袖死亡各由權威領域提交。組織接到可知結果後，維持、改案、求援、談判、撤退或放棄；不把失敗洗掉再重跑原命令。

## 誰協調，誰作決定

**世界協調只管共同事實與秩序。** 它推進時鐘、切分到期事件、仲裁同一資源的合法競爭、提交各領域結果，並確保同一批人貨不被算兩次。它不替國王選敵人、不替商人選市場，也不因知道真實敵軍位置就提醒守軍。

**國家與組織 AI 才持有目標。** 國家可想守邊或救荒，行會可想保住交易，家庭可想活下來。它們依自己的制度和知情範圍產生委派；領袖的個人願望不能冒充整個組織的意志與權限。

**地方與人物把意圖變成行動。** Region 交「保住北路、最多動用這批資源」；Site 決定修哪段、在哪集結、如何配給；Local 執行搬運、交涉、偵查或戰鬥。下層可因現場危險、缺料或人物拒絕而回報偏離，不是只會服從到成功。

玩家日後只是接手一名 NPC 的使用者，取得其既有身分、知識與合法命令。沒有玩家時，所有決策者照常自治。

## 不同局勢仍走同一條路

### 平時生產與勢力發展

農地、工坊、學校與商路按既有工作和供應推進。收穫經勞動與運輸入倉；市場成交要有貨、支付與履約。國家發展來自人口、土地、設施、人才、知識與通路的累積，不是每旬自動增加「國力」。

修路、培育人才或建立聚落等目標可跨段保留，成本過高時可分期或暫緩。聚落興衰接 [歷史](../spec-history.md)。

### 缺糧與災害

旱災、洪水或火災先由 [環境](../spec-environment.md)、[生態](../spec-ecology.md) 與 [災害](../spec-disasters.md) 產生影響，再由目擊、官署或商旅傳出消息。各組織先後得知，選擇釋糧、採買、修路、撤離或求援。

救援仍使用真實人貨與道路。誤信舊路仍通的商隊可在斷橋受阻，再把新情報帶回。

### 戰爭與外交

戰爭把目標換成動員、保路、攻城、護送與談判，仍走同一循環。徵兵抽走原有勞動，補給來自真實庫存與運輸；戰事接 [戰役](../spec-campaigns.md)，承諾與停戰接 [外交](../spec-diplomacy.md)。

勝仗不直接令整國投降。AI 可因補給、目標或新情報而撤退、議和或改守。

### 領袖或關鍵人物死亡

死亡先停止死者的未來行動，再讓職位、家庭與契約接收後果。國家不隨人物刪除，依代理、空缺或繼任維持工作；細節由 [政體](../spec-government.md) 與 [繼承](../spec-succession.md) 決定。

消息未送達前，遠方單位可依舊命令行動，但死者不能產生新命令。導師死亡中止未教課程，已學內容仍在。

### 新知識、能力與勢力變化

新方法、法術或技藝先屬於理解它的人與載體。組織得知後才投入驗證、教學與設備；不因某處發現就全國解鎖。流程接 [知識](../spec-knowledge.md)，超常能力仍須有來源與代價。

新能力可帶來新候選，但不保證有資源採用。勢力建立、分裂與滅亡也由人物、資產、控制和義務形成，不只看國力門檻。

## 粗算的底線

遠方 Region 可以少算人物細節、合併同類工作、降低決策頻率，但不能省略來源。糧來自生產、庫存或交易；士兵來自人口與動員；能力來自人物、知識、設備或超常來源。

粗算與細算可有不同個別故事，但長期產量、耗時與損失要能校準。玩家靠近只改變展開程度，不補庫存、不改目標。處理預算不足就保留合法舊計畫或等待，不能憑空增國力。

## 短推演與反例

上游暴雨沖斷北路。農村先看到水患，商會稍後收到車隊失聯，王都再收到官署報告。農村停工救人；商會改走水路；國家因邊境緊張，只撥部分石料並派兵護送。橋先恢復輕車通行，糧價仍上漲；下一輪各方依新庫存、道路和消息改目標。

穿幫反例：旬末由 Region 看見洪水真值，自動替所有商隊改路、替城鎮補一批糧，再讓國家 AI 用同一批物資修橋與養軍。這把世界協調誤作全知統治者，也讓粗算憑空創造資源；應分別由消息、決策、委派、旅行和領域提交完成。
