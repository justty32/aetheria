# 魔法生物有哪些種類

← [本層入口](README.md)｜[起源與生活](magical/spec-magical-creatures.md)｜[生活範例](magical/spec-magical-creature-examples.md)｜[D&D 參考](../references/spec-dnd-reference.md)

## 先有能用的種類表

草案。**Done when：**森林、山地、地底、海洋、聚落和異境都有不同生活方式的生物可選；每類有具體例子，也能接回起源、棲地與世界歷史。先不定完整圖鑑、能力數值或稀有度。

參考 D&D 的生物類型來補齊視野，再按本案生活需要整理。下表是本案候選內容；普通動物和智慧居民也列入，方便看清魔法生物住在誰旁邊。分類不等於敵我、職業或國籍。

## 十四個大類與候選住民

| 大類 | 可以有哪些 | 在本案世界怎麼生活、為何在此 |
|---|---|---|
| 野獸與魔化野獸 | 鹿、巨蛾、角紋魔獸、雷羽鳥 | 森林和草原的食物鏈底子；雷羽鳥在高地風暴季築巢，羽毛的用途會帶來採集與保育爭議 |
| 黏液生物 | 露珠黏液、鹽灘膠團、藥坊黏液 | 潮地、鹽田或舊水渠各有支系；有的分解廢料，有的會腐蝕器物，搬進城的來由可能只是一次運貨失誤 |
| 奇獸 | 獅鷲、蛇冠獸、擬態箱、拼接獸 | 可有穩定繁衍的古老物種，也有被造出的個體；城堡養大的獅鷲與野巢親族未必熟悉同一片獵場 |
| 龍類 | 古龍、谷地小龍、海龍、地穴龍 | 分支各自有食物、巢與成長方式；古龍可能記得舊盟約，小龍也可以只忙著養幼，不按顏色分善惡 |
| 巨人與巨型族裔 | 岩嶺巨人、霜原牧民、雲台巨人 | 舊山道、牧場與高臺聚落留下祖先工程；體型影響住屋、食量和旅行，並不使全族共用一位首領 |
| 精類與地方精怪 | 花妖、樹靈、泉精、灶邊小妖 | 有些由異境遷來，有些在本地形成；古林、泉眼與有人照料的老屋能養活不同住民，也有自己的節慶和禁忌 |
| 元素生命 | 風窪元素團、火蜥、石核行者、潮汐靈 | 火山、風口、深潮或工坊供能處各有來源；有的只是短命聚合，有的能繁衍或建立聚落，不能一律當耗材 |
| 活植物與菌類 | 行走灌木、燈籠菌、食肉藤、菌人 | 根、水與孢子傳播決定住處；燈籠菌可與礦村互利，會移動的樹也未必是精類或有語言 |
| 不死存在 | 守鐘幽魂、白骨行者、食屍者、古墓術士 | 墓園、戰地、廢城只是常見來歷；執念、術式、身體和維持來源各異，不能用同一種解咒解決所有問題 |
| 魔法造物 | 窯心魔像、活甲冑、紙鳥、巡河銅偶 | 來自工坊、神殿或舊工程；用途可以是送信、灌溉或照護，也會有停用設施留下的失業守衛 |
| 天界生物 | 羽翼使者、晨光馬、星羽蛇 | 可作神明代理或自有群體；來凡世的理由可能是送信、尋人、守約或避難，留下者要有維持生活的條件 |
| 下界生物 | 契約魔、裂隙獵犬、灰燼翼群 | 不同群體可能依契約、獵食或軍令活動；有人建立秩序，有人掠奪，也有逃離主君的個體，不能合成一國 |
| 異質生命 | 夢潮水母、晶巢群體、回聲蠕群 | 感知和維持方式與本地差很多；舊裂隙、墜落物或實驗遺址可解釋來歷，先交代能接觸的需求與痕跡 |
| 智慧族群 | 人類、精靈、矮人、獸人、河殼人等 | 有家庭、職涯、聚落與跨族社會；詳見 [種族來歷](peoples/spec-peoples-origins.md)。某族擁有魔法天賦，不表示每個人都會施法 |

「奇獸」暫收不容易放進其他類的生物，出現穩定共通生活方式才另拆。巨人、精類、元素或造物也可能是智慧居民；最後一列是閱讀上的集合，不再多算一份人口。

## 上古存在與黃金時代的巨型住民

[四時代歷史](../history/spec-world-history.md) 已定：神話由神明、上古神獸、上古神龍、上古泰坦居於主舞台；黃金則由巨人、巨龍、巨獸接棒。這些存在需要自己的生活與來歷，不能全當成普通生物放大後的戰鬥版本。

上古神龍與巨龍、上古泰坦與巨人、上古神獸與巨獸，先分開記其時代身分和個體來歷。哪些是祖裔、分支、受造或另有來源，仍待展開；不把相似稱呼直接當成已確定的親子關係。神明的自主行動沿 [神明行為](../../magic/faith/spec-deity-behavior.md)。

同一上古存在可以活到後世，巨型住民也可留在黑鐵。後世巨獸不自動都是黃金時代的原個體；要分清古老倖存者、後來出生的族群與居民傳說。時代主角不是新增一份生物數量，也不表示各類在同一天誕生或消失。

## 同一生物可以從幾個方向看

種類回答「大致是什麼」，來源回答「怎麼形成」，生活回答「怎麼過日子」。另看是否有自主判斷、能否溝通、是否依附某種力量，以及目前加入哪個群體。

- 一隻被召來的海龍仍是龍，召喚只交代如何抵達。
- 一位住王城的菌人可以是活菌類、智慧居民、藥師公會成員與王國國民，這些說法互不排斥。
- 村民叫作「魔族」的人群可能包含下界來客、受其影響的後裔與政治敵手；世界記錄要分清，不能拿外號直接套生理或敵意。
- 變成骸骨的舊人物要記變化過程與目前存在方式；分類變化不能洗掉既有歷史，也不等於原人物已復活。

## 分布要看地方的歷史

一個地方只選幾種主要住民，再留下少量旅客或罕見個體。山地不必集齊所有龍與巨人；廢城也不必全是亡靈。

例如山口原有上古泰坦盟誓保留的水源，黃金時代巨人城邦建成水道，白銀時代由精靈與巫師拓展學院和商路，黑鐵時代第一帝國再擴建供水。被新渠取代的舊地渠可住進黏液與菌群；城中仍有人修橋、做生意，各批居民都有來歷。

四時代的連續背景見 [世界歷史](../history/spec-world-history.md)。上述配置是候選開局，之後由棲地、繁衍、遷徙、製作和各方行動改變，不能換個時代標籤就重新抽怪物。
