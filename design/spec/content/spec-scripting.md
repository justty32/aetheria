# S11b：腳本、效果與內容製作契約

## 範圍

草案。Done when：作者能組合條件、效果及事件階段，錯誤不污染世界，玩家／AI／腳本不各自有特權入口。沿用 Lua 5.4／sol2 的既有方向；本篇不選新引擎，不寫 API 或作者工具。

## 三層掛鉤與權限

Region 的政策／事件、Site 的工作／戰術、Local 的能力／對話各在固定合法階段呼叫。三層共用條件與效果語意，但可讀範圍、目標和配額不同；Local hook 不能拿「全世界上下文」改遠方國庫。

**條件**只查詢、**評估**回候選分數、**效果編排**回具名請求、**生成掛鉤**依種子與已授權範圍產生受約束內容。實際寫入交核心領域；舊 `effect(ctx)->void`／`ctx:set_owner` 只可解讀成請求，不能繞過 S7 奪取領土。

Context 明列視圖版本、時點、主體、角色／組織權限、目標集合、工作配額與 RNG 子流。AI／對話用知識視圖；世界規則 hook 若需真值需顯式機制權限，不能把其真值輸出直接給玩家。

## 作者必填的語意

| 積木 | 必填 | 典型拒絕 |
|---|---|---|
| 條件／選擇 | 參數型別、未知值行為、適用範圍 | 引用型別錯、讀未授權欄位 |
| 消耗／轉移 | 來源、數量、單位、接收方、保管／產權差別 | 不足、目標失效、重複消耗 |
| 能力／狀態 | 資格、時距、疊加、代價、失敗、持久性 | 沒媒介、超配額、持續條件不符 |
| 任務／對話圖 | 起點、條件、選項、階段保存、結束與失效路徑 | 永久無出口、目標死亡無分支 |
| 世界創設 | origin、初始資源來源、位置、合法提交階段 | 無主地不足、重複 ID、非法覆寫 |

可表達送貨、護送、調查、教學、研究、建造、外交、祭典等組合，不硬寫固定十八種任務。自由擴展不等於任意腳本可以增加核心不認識的玩法欄位；需要新領域機制時明確歸 L-Core。

## 沙箱、預算與錯誤

禁檔案／網路／系統時間／原生亂數與不穩定迭代；只用注入 RNG、穩定次序與明確數值範圍。禁止跨回合 coroutine 或 Lua 私有可變狀態；所有能改未來結果的變量進 core 的版本化狀態。

每個 hook 有確定性的指令／分配／效果數量上限；上限屬規則版本，不能按 CPU 快慢截出不同結果。圖循環要有時間推進或有界次數；同時點互觸發無限鏈在提交前拒絕，不套一半才停。

hook 預先產生效果清單，核心整批預驗證；腳本異常或效果不合法，該最小原子提交零生效，保留診斷。前一已提交工作階段的材料不回滾；遊戲內施法失敗仍可有明示代價，不能與腳本崩潰混用。

若自動事件反覆在同時點失敗，停止推進於一致點並報錯，不默默跳過永久壞事件。要跳過／修復必有正式恢復政策或新內容版本，不能 UI 隨手忽略。

## 製作、預覽與保存

作者流程：選已支援原語 → 宣告內容及來源 → 靜態檢查 → 固定 seed 隔離預覽 → 正反測例 → 包驗證。預覽走同一 core 但用獨立試驗世界，不向正式存檔注入；不在 Godot 重寫一套效果模擬。

文字 key、具名參數、圖像／音效引用與玩法定義分離；翻譯不得更改條件。明示資料／腳本／素材原作者與可用範圍，參考遊戲的設計不授權複製其素材。

保存階段、已選分支、效果收據、規則／腳本版本及 RNG 重建資訊，並記注入時點。載入不用序列化 Lua VM，也不重跑已成功一次的 on_complete。

## 驗收

- 支付 5 並給物品 1，物品目標不存在：原子效果全部不套用；不是先扣款後無聲失物。
- 研究第一階段已耗 3，第二階段 hook 崩潰：保留 3 的歷史，第二階段零生效並停在一致點。
- 腳本嘗試讀檔、用牆鐘或列全世界祕密：沙箱／權限拒絕，不能得到部分結果。
- 同一 on_complete 重送、換角色、重載：只發一次報酬；翻譯換語言世界 hash 不變。
- 無限遞迴與過量創設在可重現預算點失敗；合法跨日生產循環不因存在環就被拒絕。

待裁定：具體 Context 與原語清單、腳本預算、診斷保留與隔離預覽形式。M11 才落地腳本追加；M10 全 def 通道不等待本篇纔算其既有範圍。
