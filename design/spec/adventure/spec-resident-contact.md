# 探索者與原有居民的接觸

← [本層入口](README.md)｜[主文](spec-exploration.md)

## 開拓者遇上原有居民

草案案例：河城想向林地延伸採木路，附近遺跡住著有自身組織的非人居民，林間另有普通獸群。這些居民可能在意水源、通道、住處或守護職責；具體需求由設定決定，不因外形就預先敵對。探索者不知道有人居住，不代表土地真的無人使用。

各方可能不承認對方的土地權利，交 [法律](../politics/institutions/spec-law.md) 保留主張與爭議；居民仍能保護生計或交涉，不必等全世界先有共同法律。

| 接觸中的選擇 | 對方可能如何回應 | 回到城鎮與勢力的結果 |
|---|---|---|
| 先觀察、查問，暫緩穿過住處 | 居民可避開、警告、找人接觸或隱藏入口 | 報告新增已知使用者與風險，地方可改路、縮小伐區或嘗試交涉 |
| 提出繞開水源，以工具換通行協助 | 對方衡量真正用途、可信度與自身分歧，接受部分、改條件或拒絕 | 實際改線、交貨與引路才改運能；協議不自動代表讓出土地或接受統治 |
| 不理警告繼續施工 | 居民可阻擋、拆除設施、求援、防守或搬離；工人也可拒絕冒險 | 受阻、傷亡和耗費使地方重議，勢力可調停、護送、縮案或用兵，非必然全面戰爭 |

語言不通時，可依可察覺的手勢、界標與行動試探，找熟悉雙方的人協助或保持距離；不把沉默當同意，也不保證魔法能解決。個別居民答應引路，只能承諾自己的行動，未必代表整個聚落。一次受襲只能證明已知襲擊，不直接把所有同種族居民判為敵人。

合作分支也會繼續變化：採木車增加後，原本可接受的通道可能變得擁堵；居民要求改時段，商號可接受、另找路或停止擴張。居民也能主動到河城換工具或提出共同防護，不只是等待外來者選選項。獸群仍依自身需要活動，不因雙方談成協議就停止覓食或攻擊家畜。

若居民離開，保留真實旅行、帶走物資、留下設施與往後去向；勝方還要投入人力維持道路及供應。以「接受改路」和「繼續穿越住處」比較後續通行、供應、關係與部署，才看得出選擇的差異。遭遇結果回原人物、地方、政治及生態領域，探索只留下發現；目前是桌上推演。
