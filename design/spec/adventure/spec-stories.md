## 範圍與參考

草案。Done when：主線、支線與湧現任務都可被世界改變、可失敗且留下後果；文字不成為另一個玩法權威。LDE3 借任務階段與文本分離，其 18 類模板及未解命令槽不足以證明通用腳本引擎；見 [既有盤點](../../../wf/workflows/investigation/roadmap-reference-pas-status.md)。鬼谷借關係選文，CK2／太閤借條件事件；不照搬未驗證公式。

## 三層與責任

Region 編年史／跨國篇章、Site 地方委託／組織案件、Local 對話／調查／選擇，是同一事件的不同面孔。事件領域擁有原因、階段、參與者及待提交效果；任務領域擁有契約、完成判準、報酬請求；各領域仍唯一提交貨物、死亡、權限與關係。

對話說「把錢給你」不能直接改 UI 錢數；先提交支付效果，成功才顯示付款成功。官方說「大捷」可以是錯誤宣傳，不影響真傷亡。

## 任務契約

每份任務列真實需求／人工內容來源、委託者及代理權、受益者、已知目標、期限、接受條件、驗收證據、報酬來源、競爭／合作方式、取消與失敗責任。沒有支付能力者可提出信用委託，但須標信用風險，不用虛空獎勵。

需求出現 → 發布 → 接受／協商 → 執行 → 提交證據 → 驗收／爭議 → 結清／欠付。接受前世界可變；目標已被他人救出時改為已解決／重新議約，不再生成另一個囚犯。

運糧驗收的是實際交付，不是打開箱子；除害需核對真實威脅與範圍，不以最後一下傷害獨佔全部功勞。共同完成按約定貢獻或分成，獎勵總額不得每人全領。任務轉讓須轉移義務、材料保管和委託者同意，不只改接任者 ID。

委託者死亡：機構任務由繼任／代理承接，私人任務進遺產／合同處理；無履約主體則可失效，但已耗成本不全自動退回。未結清義務與敘事「完成」分開。

## 主線、支線與自由世界

**找到事情做的暫行方向：**從角色已知的人、場所、消息與未完承諾，整理少量近期可做的事；推薦不等於接下任務，也不憑空生成需求。玩家能略過、換目標或自己探索，不以完成教學解鎖正常的世界操作。目標已被別人完成時更新原因與可知後續，不因還在引導就讓世界等玩家。開局呈現見 [進入世界](../player/spec-play-entry.md)。

主線少量人工錨點，支線模板綁真實人物／場所，湧現任務由真需求發起。人工新增危機需明示來源、代價或沙盒創設事件並入史，不暗補敵方兵糧。故事選材只排呈現，不控制事件必然成功。

關鍵人物死亡、城市毀滅、未達期限必有停滯、轉接、失敗或替代路徑；不是保證每條主線永遠可通關。作者要列終止狀態與收尾後果，不能靠隱藏不死或回溯復活維持劇本。

對話條件讀人物可知內容、關係、制度與已提交事實；玩家可說謊或保密，但說出祕密是具名消息傳播。文本模板採具名參數和 i18n key，未知真名不能從 formatter 穿透。

## 時序、循環與保存

到期／條件成立 → 產生候選事件 → 穩定排序及有界選取 → 驗證 → 提交效果 → 發消息。事件子鏈去重；跨時間有代價的復仇循環可以持續，零時距無限觸發須拒絕或拆到合法後續點，不默默截斷一半結果。

Lua 僅讀受限 Context 並請求效果；跨回合階段、選項、參與者、承諾與 RNG 遊標進 core 持久狀態。對象弱引用失效有墓誌／失落／替代分支，不能讀已回收實體。實際任務狀態共享世界，角色認知與日誌分開；另一角色完成也真改世界。

保存事件／任務 ID、因果、腳本／定義版本、結果、已領報酬與未結義務。可重新產生文句，不重擲選項效果；歷史不同觀點另留說話者與時點，不拿最新政權立場改寫舊話。

## 驗收與舊文衝突

- 報酬池 12，兩人依約 7／5：只支 12；讀檔、重送完成、換角色均不能再領。
- NPC 已先送足 8 糧，玩家持 5 後到：原需求可關閉，另買糧需新交易；不強收或再發完整任務獎勵。
- 導師死亡後對話不能以原導師繼續講課；弟子可提供已知片段，且不能透露未知副本所在地。
- 拒絕主線仍能經營／旅行；世界續玩模式的篇章完結不停止所有自治。

舊文「系統已就位」「不需額外敘事系統」不可作實作證據；此處補契約與呈現，不建立第二套世界模擬。自動 mark／劇情 observer 仍擱置，本批用穩定引用及到期事件，不靠永久載入所有任務地點。

待裁定：競爭／分成方式、驗收證據、分支失效、首條主線骨架、篇章終局模式、事件密度與人工比例；腳本追加屬 M11，非 M10.3b。
