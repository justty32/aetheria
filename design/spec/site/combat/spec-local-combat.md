# S3b：個體交戰、潛行與現場互動

## 範圍

草案補篇。Done when：Local 的移動、交戰、施法、救援與脫離有明確代價及結果，能交回同一場 Site／Region 事件。不取代既有四屬性、d100、傷害型別與抗性上限，也不私選 Site 出手序。

## 三層、身分與回合

Region 提供實際人員、裝備、補給及戰役背景；Site 提供地點、參戰配額、戰線、合法進出方向與本段任務；Local 展開領出的少數人物、障礙和行動。非戰役中的鬥毆、追捕也可有 Local 事件，不必先造一個國戰。

動作狀態由交戰領域寫，傷勢由健康、裝備／彈藥由物資、位置由移動領域唯一提交。每位領出人物同時從上層相應詳算責任扣除，但仍在原編制名冊；未領出的戰線繼續粗算。

Local 沿既有探索／交戰 stride，共享一條時鐘；單位順序是本地行動窗口，不能每一人動一次就替全世界各加一次完整回合。建議行動耗時／恢復到期持久化，不因切模式再得一次行動。具體本地先後與反應額度沿既有規則核對後裁定。

## 命令及失敗

| 行動 | 執行必查 | 結果與中斷 |
|---|---|---|
| 移動／追逐／退開 | 可通邊、佔地、負重、姿態與行動時間 | 實走到合法位置；受阻不瞬移，不偷看未知陷阱 |
| 近擊／遠射 | 目標或指定格、接觸／射程、視線、武器、彈藥 | 命中檢定、真耗用、健康與裝備後果；失手也耗合法代價 |
| 防守／掩護 | 姿態、保護對象、可反應事件與剩餘額度 | 每次反應扣同一額度；不能無限格擋／借上層再反擊 |
| 施法／使用物品 | 知識、媒介、目標、準備及剩餘資源 | 走 S9a 分段釋放／失敗，不免費取消已耗材料 |
| 換裝／裝填／拾取 | 真正位置、可用手段、保管權與時間 | 物品轉移一次；戰中整理背包不是免費停止世界 |
| 救援／搬運／急救 | 接觸、可搬負重、工具、路線、時間 | 暫時穩定不等於治癒；傷者持續有暴露及照護需求 |
| 投降／逃離 | 可溝通、對方接受、撤出路徑 | 投降成立後進保管，逃離後進旅行；不能按鍵直接消失 |

拒絕是未開始；失手是已執行但未達目的。指定格射擊可盲射但不保證打中未知者；追蹤人物在視野消失後只能追已知位置／線索。

## 傷害、狀態與潛行

沿既有一次 d100 與餘量，不另多擲免費暴擊骰。施加傷害前驗位階門檻／破階條件，抗性走原型別及上限；健康再處理失能、出血、死亡，不能傷害系統與健康系統各殺一次。

護甲、盾與地形如同時修正，須列在哪個公式位置，不能都揉入 quality 超出跨階約束。暫時 HP／防護值可重建，已受傷害與恢復時距不可忘。失能、昏迷、死亡分開；擊倒不等於取得俘虜保管權。

潛行以姿態、聲響、光照、遮蔽、距離及觀察者能力形成偵測；偵測後才更新情報。看見可疑影子、辨識人物、知道其陣營是不同結果。規則聲響由核心算，耳機音量不影響敵方感知。

建物破壞、點火、開門與挖掘走原工作／環境效果；燒糧倉需真燃料、暴露和時間，不能「潛入成功」直接扣全城糧。普通暴力可引發犯罪、仇怨或自衛，不自動升為兩國宣戰。

## 離場、保存、AI 與驗收

回傳人物位置、健康、已耗行動／材料、控制狀態、環境改動、觀測與因果 receipt。正在接敵時上提只改解析度與代理控制，不給免費安全撤離。詳算剩餘窗口與上層未算區間交接，不能補算一整回合再扣同批人。

保存參與者、當前行動階段、恢復／狀態到期、反應額度、目標最後已知及效果去重。AI 同命令，能救人、撤退、藏身或求援，不僅選最大傷害；成本及失敗規則與玩家相同。

## 人物在現場怎麼改變做法

人物把眼前任務、能力、身體、同伴與退路一起考慮：接近敵人前可觀察或找掩護；射界不合可移位、等待或換可行目標；受傷或彈藥不足可退開、換手段、求助。救人、傳令、守住門口與避免暴露也能達成任務，不要求每個行動都造成傷害。

同一危險下，士兵可能優先守令，搬運者可能保住貨物或先逃，熟識傷者的人可能選擇救援；差別來自既有責任、關係與所知，不能只依職業固定決定。敵人脫離視野後，追蹤者可沿線索找、停下查證或回原任務，不跟著隱藏座標追。

個人的發現和偏離要有實際後果：斥候找到斷路，可回報改變側翼方案；搬運者拒走火場，傷員撤出就受阻；有人打開通道，相關隊伍仍需得知、到達並驗證能否通過。世界先收位置、傷勢和環境結果，指揮者再依送達消息改部署，不能因 Local 完成一次行動就全軍同步轉向或加士氣。

- 5 箭射 2、命中 1：餘 3；失手那箭不返還，拾回需真實可回收物。
- 方陣領出 4 人，Local 1 死、1 傷：上層不再對這 4 人同區間抽死亡；傷者不能作滿額可戰。
- 預備一次格擋遇兩次攻擊：只第一次符合反應條件者用額度；重載不能多一次。
- 玩家救起軍官但未撤出火場：健康暫時改善，後續仍可受傷；事件不固定為營救成功。
- 只改攝影機、語言或聲音，不改命中／偵測；同策略粗細戰損與耗用分佈另校準。

待裁定：本地行動窗口、友軍射界／誤傷、脫離反應、大型個體佔地、垂直射程與首批潛行公式。不能把需要測的反應政策藏進動畫。
