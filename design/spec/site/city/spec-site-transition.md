# S4：同一城市的平戰連續性

## 範圍與完成定義

草案；組合 [地方工作](spec-site-work.md)、[方陣命令](../combat/spec-site-battle.md) 與 [平戰藍圖](../../../../wf/workflows/plan/living-world/site/world-site-conflict.md)。戰爭改變同一個地方的運作，不換一張沒有原住民、工程與產權的新戰場。

**Done when：**港城從預警到動員、封鎖、交戰、占領／解圍與恢復，能逐步交代每份人力、庫存、工作及政治關係。不先定占領數值和全套法律。

## 四條獨立狀態軸

| 狀態軸 | 寫入責任 | 不可推導的捷徑 |
|---|---|---|
| 威脅與警戒 | 安全評估／有權者的措施；情報來源另記 | 警報不等於已宣戰 |
| 通行與封鎖 | 環境／旅行的邊與通路約束，戰爭交控制證據 | 被圍不等於所有海空地下出口全封 |
| 接觸與交戰 | 戰場規則與事件主場 | 有一場巷戰不等於全城停產 |
| 政治控制與爭議 | 政治規則 | 城門破不等於地權、忠誠、貨權全改 |

交戰步長按既有規則切換；工作仍按真實時距與安全／可達條件進行。四軸狀態不是四個 LOD 決定者，解析度仍由 observer 決定。

## 轉變契約

| 觸發 | 要驗證與提交 | 尚未完成的活動 |
|---|---|---|
| 收到警報 | 訊息來源、可信度與措施權限 | 巡邏／盤點形成工作，不瞬間補滿防備 |
| 徵募／徵用 | 制度授權、對象、人數／數量、補償或侵害紀錄 | 民用排班扣未來人力，材料改保管需實際轉運 |
| 敵方控制通路 | 位置、容量、有效時間與可用替代路 | 在途貨等候、改道、退回或被奪，不直接刪除 |
| 局部開戰 | 事件範圍、參與者、交接與下一合法邊界 | 危險區工作暫停／護送，安全區依條件續作 |
| 停火／脫離 | 命令權、接觸狀態與協議適用方 | 不自動放俘、退貨、治傷或重開全部出口 |
| 政治接管 | 戰果、制度／主張、有效行政與競爭者 | 原工作待新授權檢查，不抹去欠薪或私產 |
| 恢復 | 通路、安全、住所與服務逐項可用 | 清障、醫療、安葬、返鄉和重建各有工期 |

未獲授權的武力徵用若允許作為玩法，須走明確違法／敵對行動與後果，不把授權失敗當成功徵用的旁路。具體制度留政治 spec。

## 人與物的競爭

同一居民不能同時列入碼頭滿班、城牆民兵和已離城難民。動員／疏散先取得人力責任，再更新排程；已開始的工作保留進度及在製品。疏散需出口吞吐、移動時間、載具與收容容量，失敗者仍在實際位置。

封鎖是通路約束，不是「城內每回合扣固定糧食」的額外傷害。口糧消耗依人口與制度走帳本，短缺再交健康、士氣與政治後果。攻方也有補給；傳送或飛行若可救援，須有能力、成本及運量來源。

火災、疾病、供水與醫療在戰時持續。兵力不足時行政官可選先救倉庫或先救居民，但需記政策和可知依據；敘事不能暗中回補被燒物資以維持劇情。

## 玩家介入、離場與保存

玩家在 Local 修門只交門的耐久／通路與材料成本；上層不再另扣一次圍城損失。守門效果若改變進軍或談判，由相關規則讀新事實。玩家在屋內不阻止外城牆失守。

保存四軸狀態與生效時間、受損資產、所有／保管／控制關係、未完工作、在途人口貨物、交接與收據。離場保留委任及到期事件；重新進入不重生戰利品、不重抽火勢、不刷新警戒預算。

AI 依職責與情報續作：行政官維持服務、軍官守退路、商隊評估改道；共同搶資源仍經同一預約。介面分開顯示「已知威脅、實際可達、行政控制、服務缺口」，未知部分不能假裝安全。

## 整合桌上驗收

夾具：港城碼頭有 20 名可工作者，動員 6、疏散 4 後最多剩 10 名從事碼頭工作；這不表示吞吐必定線性減半，實際由設備／通路瓶頸決定。

1. 收警報後徵募，卸貨延誤，原貨主與保管者仍可查。
2. 橋被封，船道仍開；陸路商隊等候，海運不被無故一併判失敗。
3. 北門交戰，安全區麵包坊仍耗真實麵粉生產，傷員競爭可用床位。
4. 玩家下沉修門，消耗同一工程材料；其他戰線照常推進。
5. 敵人撤離但倉庫仍燒毀：停戰不補倉，通行、復產、返鄉各自恢復。
6. 對上述每個提交點存讀並重送上一收據：人數、庫存、工作與控制不再套一次。

另測占領分支：同一城中有私產、俘虜與多方主張，不能只改一個 owner 欄位宣稱處理完成。

待裁定：警報可信度、徵用補償、占領成立／結束條件、多方停火、疏散優先序與海空地下封鎖。未裁定時保留可比較政策，不給 AI 無限制徵用權。
