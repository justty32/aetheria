# 中層軍隊如何判斷與調度

## 範圍與完成條件

草案。本文補的是 Region 交下戰略任務後，軍隊與地方軍官怎麼形成可執行、可改變的安排。**Done when：**同一批兵依守路、威懾、保村或尋戰而有不同的集結、路線、警戒、掩護、駐防、補給、預備與撤退選擇；分清接敵前行軍與接敵後部署；情報改變或人物拒令時，軍隊能有理由地改案並把結果交回世界。

本文不選方陣出手序、固定比例、距離門檻或評分公式。它是既有責任鏈的行為展開；責任能交接，不表示軍隊已知道該怎麼行動。

## 從任務變成一套安排

Region 的委派交代目的、期限、損失底線、可用人糧、權限、禁區與退出條件。軍隊收到意圖與邊界，不是「往最近敵人走」的永久命令。指揮者只用已知敵情、道路、倉儲和友軍消息；傳聞可查證，不能偷讀真實敵軍位置。

方案要回答在哪集結、走哪條路、警戒何方、誰掩護與留守、糧怎麼送、保留多少力量、失敗往哪退。分兵保村會削弱主力，帶糧會增加車隊負擔。未知太多時可先到橋西、查明東岸再決定；等待、查證、縮程或求援都是選擇。

| 選擇 | 主要依據 | 代價或出口 |
|---|---|---|
| 集結、路線 | 期限、通路、暴露與水糧 | 等齊會失機；可分段、停、改道或回頭 |
| 警戒、掩護 | 威脅、必守處、被護人貨與退路 | 抽走休息與主力；事畢可回收或改守 |
| 駐防 | 地方價值、居民風險、工事與交接能力 | 分兵削弱野戰；無力全守就選疏散或放棄何處 |
| 補給 | 庫存、消耗、車船容量與取得方式 | 徵用傷民；不足可減員、縮程、停留或撤退 |
| 預備、撤退 | 未知威脅、救援距離、傷員、退路與任務底線 | 預備投入後不再可用；撤退可能失序、棄物或遭追擊 |

預備隊有真人、位置和補給，不是臨時加成。同一人不能既駐村又隨主力走，同袋糧也不能留給兩隊。抽調農民、車夫、船與糧會留下缺工、貨運和關係後果。

## 行軍與接敵後部署

**行軍安排**處理接觸前的移動與維持：縱隊或分路、前後衛、宿營、哨戒、補給會合、橋口次序、掉隊與傷病。它使用通路真容量；判斷安全不保證沒有伏兵。

**接敵後部署**才把實到部隊編成方陣，選正面、縱深、掩護、預備位置與撤出口，交方陣規則檢查占地、傳令和剩餘行動。行軍前衛不會自動出現在敵後，後方隊伍也不會瞬間入戰或共享視野。

軍隊可遮斷、觀察、談判或脫離，不必一見敵人就決戰。調度沿回合制，在合法決策點重驗命令，保存已耗時間與行動窗口；誰先出手仍待方陣出手序裁定。

## 何時不照原案

出發、到會合點、收到重要消息、補給惡化、接敵或退路改變時重驗原案。任務已失效、授權中止、敵情不同、道路不通、兵力因傷病或拒令不足、繼續會越過損失底線，或眼前有來不及請示的生存危險，都可改案。

改案不抹掉已發生的事。指揮者保留何時知道什麼、原案做到哪、改成什麼及何時回報；來得及便求准或求援，來不及則依既有職責縮減、轉守或撤退。未送達的新令不能倒算成現場早已知道。

軍官可因職責衝突拒絕放空城鎮，斥候可能因傷停探，士兵可能失控，運糧者也可能因欠薪或家人危急拒走。這些都留下人物結果；只能換人、改任務或接受缺口。指揮者也能依授權與已知危險自行撤退，之後承擔制度後果。

## 河谷同局勢的四種任務

共同情況：河谷新商路剛開通，鄰國傳出調兵消息，沿線村落因商隊與築路缺工。消息只證明對方曾集結，不知道目的與完整位置；四案使用同一批軍隊、存糧、車隊和地方人力。

**守路：**先讓橋、渡口、驛站與糧運互相支援，分段駐防，斥候查岔路，機動隊作預備並保留商旅通行。缺工時可借驛站少建營地，但防備較薄；敵軍繞路也不代表主力必須追。

**威懾：**在有補給的要點公開集結、演練並傳遞交涉訊息，保留退路，避免誤越境引戰。持續供應與可見的預備力量比立刻接敵重要；若調兵證實是救災，可降警戒、復員人力。

**保村：**分隊靠近聚落，護送撤離與收成，主力停在能支援數村之處。這會分散兵力並抽走車夫與糧；無法全保時，要依任務選人口、倉庫或橋，不能用追敵掩蓋放棄村落。

**尋戰：**較積極查找敵主力，仍保留前衛、側翼警戒、糧路、留守與退出條件，可分路迫敵表態。發現敵強、補給暴露或村落遭襲時可避戰、回護或退往有利處；沒打成決戰不必算失敗。

改任務不會重設資源。已耗的糧與疲勞會限制之後可用力量。

## 下到人物、結果回世界

方案拆給具名軍官、分隊、斥候與車隊，各領目標、人貨、風險和退出條件。依既有觀察與粗細規則展開 Local 時，才詳算人物走位或交戰；其餘用同一批人糧與位置粗算。粗細切換不重建人貨。

人物交回人數、見聞、耗糧、傷病、拒令與位置。Site 更新部署；Region 收道路、村落、軍隊狀態與任務偏離。人口接傷亡，經濟接缺工與延誤，外交按送達證據反應；報告不重算戰果。

## 保存與驗收

保存任務、情報版本、方案階段、人貨份額、路線、各隊責任、補給、撤退條件與偏離原因。讀檔延續原位置、消耗和等待。

用河谷四案驗收：配置須可解釋地不同；敵情未明不全軍衝敵；投入預備後不再重用；運糧人拒令會降低運量；行軍遇伏只部署實到部隊；撤退後傷員、遺失物與留守者各有去向；地方缺工與勢力判斷成為下一輪原因。粗細可有不同小插曲，但總人貨、時距、戰損與位置須可對帳並可校準。

待裁定：多久重議方案、何種情報提前喚醒、分兵與預備如何評估、拒令和自行撤退的制度後果、粗細校準範圍。先保留可比較政策，不提早鎖定數值。
