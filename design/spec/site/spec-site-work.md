## 範圍與目標

草案，承接 [地方運作藍圖](../../../wf/workflows/plan/living-world/site/world-site-operations.md)、[S0](../common/spec-world-handoff.md) 與 [S1](../common/spec-world-time.md)。平時經營是配置地方資產、勞動和服務，不是全城共用的免費資源池。

**Done when：**修橋工作可從委託到通行恢復，能遇到搶料、缺工、受傷、取消、離場與戰時徵用而保持同一份帳。不在本檔定完整價格、建築庫或勞動制度。

## 最小資料與權責

工作單需記：身分、發起／核准者、受益者、資產與地點引用、目標／驗收條件、優先序、期限、預算、承辦者、依賴、進度、在製品、已耗成本、預約引用、下一檢查點及結果收據。

工作規則寫進度與承辦狀態；帳本寫材料及支付；人物規則寫雇用關係／經歷；環境／建築所屬規則啟用設施；健康規則處理工傷。工作完成通知不是直接改全部領域的通行證。

## 狀態轉移（草案語意）

| 目前狀態 → 目標 | 條件與效果 | 失敗出口 |
|---|---|---|
| 提案 → 核准 | 查職權、地權、預算來源與目標合法性 | 拒絕提案，不先扣材料 |
| 核准 → 等待 | 建立所需人力、物資、工具與通路需求 | 缺口有種類，不能只顯示「失敗」 |
| 等待 → 執行 | 當前步驟所需條件均成立，取得有效預約 | 失效預約釋放或重排，不無限占用 |
| 執行 → 暫停 | 工傷、危險、斷路、缺料或授權暫停 | 留已耗成本、進度、在製品與原因 |
| 暫停 → 等待／執行 | 原因消除或合法換人／改方案 | 不重新領取已用材料 |
| 執行 → 待驗收 → 完成 | 核對目標、品質、實際產物與去向，提交交付 | 次品返工／降級依契約，不直接領全額成果 |
| 未完成 → 取消／失敗 | 有權取消或已不可達成；處置剩料與在製品 | 已發生代價不倒轉；後續重開有新紀錄及來源引用 |

預約不是領料，領料不是消耗：庫存可仍在倉庫但已不可另約；領出後由承辦者或工地保管；只有合法步驟消耗才記耗損。薪資可按工時／交付結算，契約必須先選，不能用「未完工」取消已應付工資。

## 預約、搶占與勞動

建議按下一可執行步驟預約，不一次鎖住十年工程全部材料。預約須有數量、用途、持有人、期限、撤銷條件；到期只釋放尚未消耗的承諾，不把工地材料瞬移回倉。

多工作搶同一資源，由明訂優先政策與穩定鍵仲裁。缺料時不得持有其他全部稀缺資源永久互等；等待依賴成環須回退可釋放預約或回報衝突。優先級老化、搶占門檻與租期仍待定。

人力配額包含工作、搬運、休息、照護、訓練與軍役；同一區間不能重複指派。徵召從民用可用工時扣除，死亡／失能後由人物與健康結果撤銷未來排程，不抹掉過去工時。

## 空間與服務交付

服務輸出是「在何時、對哪些可達需求提供多少容量」，不是建築存在就全城受益。水、床位、醫療、消防、教育各自定必要消耗與容量；交通查真實門、路、載具及安全限制。

滿意度與健康可受服務影響，但由各自規則計算，不能再當成無來源人口生成。住宅是容量，居民來自出生、遷入或既有人口重新配置。跨 Site 調貨經 Region 中介與旅行時距，不直接扣鄰城倉庫。

## 三層、AI 與保存

Region 算對外需求、運輸及未委派份；Site 排空間、工作與服務容量；Local 領工作步驟、工時與材料，交回實際代價／成果。沒有領到責任的純畫面工人不產出。

委任列支出上限、最低存量、資產範圍、禁止事項與例外回報。AI 讀可知缺口，用相同命令競爭同一資源；無解時維持安全待命或回報，不憑空生工人。畫面至少顯示負責人、卡住原因、已花與剩餘資源、可用下一步。

保存進度、承諾、在製品、保管、已交付收據與下一到期點；離場換成粗算承辦，不取消委任。工程破壞留下損毀事實，重建不是回滾付款。

## 驗收例

測試夾具：橋需 12 份石材、8 有效工時，投入 5 份與 3 工時後工匠受傷。暫停時帳上有耗料 5、未耗 7；接替者完成剩餘合法步驟後總耗料 12、總工時 8。此數字只用驗證，不是遊戲平衡值。

同樣起點分別全程 Site、途中 Local、離場與存讀，應得同一守恆帳。若受傷造成額外運送或返工，必須有新成本來源，不強求耗時仍為 8。

反例：兩單各預約同一份石材、撤倉清除他人產權、取消全額回補耗料、換步長加速產出、重送驗收啟用兩座橋，均應被拒絕或測試抓到。
