# S8b：生態、土地利用、農牧林礦與耗竭

← [本層入口](README.md)｜[規格總覽](spec-world.md)｜[自然環境](spec-environment.md)｜[物資](economy/spec-goods.md)

## 範圍與完成條件

草案；將 [地理藍圖](../../wf/workflows/plan/living-world/systems/world-systems-geography.md) 的群落與土地回饋接到工作、食物與人物生活。目標是可推演的世界生態，不是承諾逐棵樹、逐隻昆蟲常駐模擬。

**Done when：**森林被砍、礦脈被採、農田被棄置後，實際產物、剩餘資源、棲地與恢復進度三層一致；玩家靠近不補滿獵物或成熟作物。物種清單與生長公式另定。

## 群落和資源存量

棲地保存面積／覆蓋、土壤適宜度、可用水、擾動與連通；群落保存功能群／物種、階段分布、可採生物量、繁殖條件、遷入遷出與採捕壓力。承載量是環境約束，不是每旬自動補到的目標庫存。

礦藏保存初始藏量的可重建來源、已採／已知／可達份額、品位及必要空間約束；「發現礦」只改知識，不新增藏量。不可再生礦沒有預設刷新；魔法再生須接 S9 的明示來源與代價。

具名動物、家畜與被照護個體從既存群體拆出責任；野生生物量、個體數與經濟庫存不是可直接相加的同一單位。只在規定產物轉換時，由生態扣來源、物資收產物／殘餘；死亡不保證全部可食用或被回收。

## 作業及土地利用

| 活動 | 必要來源／過程 | 中斷與後果 |
|---|---|---|
| 種植／採收 | 種苗、地塊、水土、季節、工時；生長與收穫分開 | 錯過採收可腐敗／落籽，不直接入倉 |
| 牧養／繁殖 | 真實動物、飼料／草場、照護與生育條件 | 缺料影響健康與繁殖；新生不是無成本補員 |
| 伐木／採集 | 可達且未被領走的資源量、工具與工時 | 已砍不因取消重生；殘根、枝葉及棲地改變保留 |
| 狩獵／捕魚 | 已知棲地、搜索、捕獲能力與可捕份額 | 搜索不保證捕獲；逃逸不算死亡或戰利品 |
| 採礦 | 可達礦體、開挖、支護與運輸 | 原礦、尾礦／棄石分開；礦難不重置已採額 |
| 休耕／復育 | 時間、種源、水土與實際維護 | 無種源或持續擾動可能無法恢復 |

地理寫地表改造，生態寫群落／資源，工作寫作業進度，帳本寫入倉與保管，政治寫使用權。生長提高田間存量，不等於糧倉收入；收穫後運輸、腐敗和徵收仍依 S6／S7。

地塊主用途面積不得重疊滿額；林下放牧、輪作與複合利用可有規則允許，但需競爭相同水、養分與面積容量。荒廢後經演替改變，不立即重設成原始 biome。永久土地變化與短期覆蓋分開，避免長一季草就重生整張地形。

## 生態流與回饋

出生、生長、死亡、捕食、採集與遷移各有來源時段及限制。捕食對獵物和捕食者是同一來源事件，不能一邊吃到、另一邊沒被扣。生物量增加可用太陽能／養分等簡化外部輸入，須明示模型邊界，不宣稱已做全元素循環。

動物遷徙讀棲地連通、食物、繁殖與危險，出發扣原群、在途保留、抵達加目的群。人造圍欄、道路、火災和水污染能改連通／適宜度；不是所有物種都受同一阻擋規則。

砍伐對逕流／土壤的影響由環境規則讀實際覆蓋變化；不直接加一個「必然洪水」事件。過獵造成短缺，再沿市場、生活、遷徙和政治鏈傳播，不在生態額外扣一次居民生命。

## 三層、時間與知識

Region 推進未委派群落的階段分布與遷移；Site 展開田林牧礦斑塊和作業；Local 展開已領份額中的生物／資源點與採捕。地方展開需符合季節、已採位置及承諾的個體歷史，不能另抽滿地成年動物。

模型按實際時距／季節推進，跨播種、出生、成熟或耗竭閾值切段。粗算與詳算不必每次收成相同，但種苗、實際採走量與庫存必須對帳；分布校準需固定策略和環境，不能把玩家額外灌溉的差異算成模型偏差。

AI 用已知地力、價格、風險和生存需求安排作業；勘查提高估計，不直接讀剩餘總藏量。過度採掘可作短期策略，但不能享有 NPC 專用無限資源。

魔法生物的形成方式、地方來歷與棲地見 [生物生活](spec-magical-creatures.md)。

## 野外生物也有下一步

生物行為依其生命方式與感知能力決定。普通動物可用覓食、飲水、休息、繁殖、護幼、避險或守域等少量需求，不需要套人類的職位、金錢和契約。具有社會組織的非人居民則可使用人物、家庭及組織規則；需求和能力由設定決定，不因被稱為「怪物」就固定敵對。

野外循環是：棲地與自身狀態改變 → 察覺食物或危險 → 搜尋、移動、休息、追逐或逃離 → 留下消耗、捕食、傷亡與位置變化 → 再選下一步。搜尋可以落空，找不到食物也可能衰弱或死亡；不保證每次飢餓都能生成獵物。群體粗算可概括這些過程，但不能讓詳算動物之外再多出一份群體捕食量。

未領出的普通野獸由生態行為方針粗算；Local 領出的個體依自身感知、需求與可用動作決策。同一份額、同一時段退出群落粗算，進食、死亡或遷徙結果交回原群落責任，不能具名後沒人推進，也不能兩邊各吃一次。

例如森林縮小，獸群可移向別處，沿途也可能接近牧場。牧人察覺後可轉移牲畜、設防、驅離或請求捕獵；結果反過來改獸群風險、地方食物和工作。動物沒有收到人類公文也能感知圍欄或追捕，但不能知道遠方所有安全棲地。無人觀看時仍走這條鏈，不以開地圖觸發一批襲村怪。

非自然生命若靠魔素、召喚或其他來源維持，沿 [力量](spec-powers.md) 的明示來源處理，不能硬塞成需要普通食物，也不能因不吃飯而推定不需任何維持。粗細切換仍領同一份生物與時間責任。

## 驅離之後，問題去了哪裡

牧場把獸群趕離後，動物仍按已能感知的食物、通路、同伴與危險選方向；不能由牧人指定牠們自動搬到遠方無人區。可通往合適棲地時可能繞開聚落；退路受阻或護幼時也可能停留、反抗，並非必然逃跑。

若獸群沿路接近另一村，當地牧人要在察覺後才調整放牧、圍護或求助。第一村不因成功驅離就知道牠們後來去了哪裡；接到鄰村消息後，可協調通道、輪流看守、改放牧地或選擇不理會。結果可能保住兩地生計，也可能增加捕獵與地方爭議。各方的應對改變下一輪棲地和風險，不把野獸當無限刷新的襲村事件。

智慧居民與開拓者的交涉另見 [林地接觸案例](spec-exploration.md)；他們談成的地界不直接控制普通動物。

## 保存與驗收

保存群落階段、已採差額、地塊用途、成熟／恢復游標、具名份額、遷徙及物資交付收據。可重建的裝飾植株不能攜帶額外可採資源。

夾具：可採木質量 100，伐取 20，剩餘 80；指定配方產木材 15、殘餘 5。重送採伐不再生 15。下一季若環境允許淨生長 4，才成 84，不能因離場回到 100。另測礦藏 50 採 12 後剩 38，即使重新勘查亦同。

負向情境：兩隊採同一林班、採收後再讀田間成熟量、野生動物馴化雙計、牧場同時作滿額農田、跨界遷徙丟失、焚林後立即復育。待裁定：功能群粒度、生育與成長、土壤退化、土地複用、產物轉換、群落分裂合併及誤差帶。
