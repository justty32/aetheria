# S11c：三層操作、可理解性與感官呈現

## 範圍與完成條件

草案。Done when：玩家只靠正式介面就能知道在哪、能做什麼、為何受阻及接下來可選什麼；三層保留同一地點與後果。Godot 僅呈現、音效、UI 與輸入轉發；不建立玩法狀態或用動畫完成交易。不在本輪產生素材／畫面原型。

## 三層的資訊焦點

| 層 | 地圖與主操作 | 必須顯示的後果 |
|---|---|---|
| Region | 已知地理、勢力、軍隊、交通；旅行、政策、外交與委任 | 在途與阻塞、供需、消息時間、合法權限、未完承諾 |
| Site 平時 | 同一聚落的道路、街區、設施；建造、工作、服務 | 誰在工作、缺什麼、預約者、實際庫存及服務可達性 |
| Site 戰時 | 同一地方的方陣、面向、陣線、工事；命令式指揮 | 行動代價、接敵條件、士氣、補給、撤退與平民暴露 |
| Local | 人物、物件、室內外／地下、感知；生活與親身行動 | 身體、負重、時間、可互動對象、持續效果與退路 |

這是三層、四種資訊情境，不是新增第四張地圖。Site 戰爭仍回合制，動畫中的士兵只是編制的表現，不等於核心逐兵或即時戰鬥。

## 查詢與命令循環

**初次進入的暫行方向：**先說明角色、所在地方、手邊資源與已知機會，其他說明在用到時再展開。讀既有說明、切面板或略過教學不耗世界時間、不算完成工作；真正移動、交談取新消息與執行命令仍走原規則。引導不用另開一條凍結的角色時間線。見 [進入世界](spec-play-entry.md)。

core 發不可變 snapshot：world／revision／tick、角色知識版本、駐留與可見地圖、語意對象 ID、命令候選、事件差分。Godot 只可暫存呈現快取、面板展開、鏡頭與輸入草稿；已接受命令／預約住 core。

選對象 → 查可知條件／成本區間 → 編輯意圖 → 提交 → 顯示接受／拒絕 → 等待實際結果。確認視窗不是世界暫停權限；本地單人是否繼續推進由 core session 控制。收到較新版本須重驗舊預覽，不能把估價當永久承諾。

每個錯誤給「已知原因、已耗多少、目前在哪、可選替代」；未知原因明示未確認，不能洩露敵方真值。交易待交、工作待料、命令被拒、存檔排隊等不可都用同一個綠勾。

## 縮放與控制

三層各一套場景及鏡頭，轉場保留父子格與世界位置。下沉先驗範圍／提交舊主場，再準備新投影；失敗留在原一致視圖，不顯示半個新世界。上提要先交回實際狀態，不能動畫一播就視為歸約成功。

Region 直接跳 Local 若採用，只省鏡頭路程，不省 S0 的中間責任交接；目前仍待裁定。選中遠方部隊可看其授權報告，不能把控制人物瞬移過去。

核心暫停於中斷點時顯示原因與可用選擇；通知設定只決定提示／授權代理，不屏蔽死亡及到期效果。多事件按因果合併：同一城破的戰報、傷員、缺糧可展開查閱，不彈三次互不相干勝敗畫面。

## 「為什麼」與資訊分級

**暫行顯示方向：**平時先給「發生什麼、和你有什麼關係、現在能怎麼辦」的短摘要，再由玩家展開原因、帳目與工作明細。例行完工合併報告；同一受阻在條件沒變時不反覆催。未知風險仍明示，會越過委任範圍的重要選擇仍要停，不靠藏掉必要資訊讓畫面變簡單。見 [核心循環](../loops/spec-play-loop.md)。

普通界面能沿「需求 → 決定 → 工作 → 結果」追到可知來源：缺糧可能是未到貨、被預約、腐敗、無運能，不能只顯示負數。人物面板分自己說法、已知經歷、正式職責與可見關係，不暴露完整隱藏性格權重。

讀史、看物品來源、查看工作單皆為唯讀；不得因開面板觸發任務成功或免費偵察。除錯 inspector 另有全知權限，明示不屬正式遊玩；讀日誌和重放不改原世界。

## 日式表現與無障礙

沿用既有 tile／角色規格、明亮奇幻色調、統一打光與紙娃娃方向；不以「戰亂」把全部世界變成灰褐。地理與文化用可組合建築／服裝／地物語彙，混居不是全城瞬間換皮。

地圖標記同時用形狀、圖案與文字，不只紅綠。提供文字縮放、鍵盤可達操作、重綁方向、少動畫／關閉震動、音量分流及重要聲響文字提示；具體配置待 UI 規格驗證，不能讓聲音成為唯一必要資訊。

音景沿氣候、地方活動、個別聲源、事件和 UI 分層；聽覺可知範圍由 core 提供，不能因 BGM 提前洩漏伏兵。淡入、粒子與紙娃娃動畫可用呈現時鐘，但不能影響回合或 gameplay RNG。重開前端重建當下氛圍，不重播所有已發生的一次性獎勵音。

## 缺素材政策、保存與驗收

舊美術／音訊規格正式版缺檔拒啟動，roadmap 建議 fallback，兩者衝突：建議作者／發行驗證嚴格阻擋，玩家讀檔允許明示替代圖音且玩法不變，待裁定，未默改舊規則。

保存世界的是 core；畫面快取全部刪掉後仍可重建。素材引用缺失不能讀成另一種兵、少渲染不能少算傷害。效能預算與驗證見下一篇，不將舊毫秒估計當量測。

- 從正常 UI 完成旅行、工作、交易、外交、Site 指揮、Local 探索、保存與切角色，不需除錯命令。
- 同一部隊三層顯示人數、位置、傷勢、補給與事件一致；切層失敗不扣第二次資源。
- 兩角色看同一災害，資訊時間不同且原因可查；未獲知者不從音樂／錯誤文字偷得消息。
- 刪呈現快取、停動畫、換語言或關聲音，世界 hash 與命令結果不變。
- 缺素材依最終政策阻擋或明示替代，不靜默；長清單、事件高峯、縮放與鍵盤流程另做視覺／互動驗證。
