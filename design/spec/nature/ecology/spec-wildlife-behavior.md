# 野外生物與驅離後續

← [本層入口](README.md)｜[主文](spec-ecology.md)

## 野外生物也有下一步

生物行為依其生命方式與感知能力決定。普通動物可用覓食、飲水、休息、繁殖、護幼、避險或守域等少量需求，不需要套人類的職位、金錢和契約。具有社會組織的非人居民則可使用人物、家庭及組織規則；需求和能力由設定決定，不因被稱為「怪物」就固定敵對。

野外循環是：棲地與自身狀態改變 → 察覺食物或危險 → 搜尋、移動、休息、追逐或逃離 → 留下消耗、捕食、傷亡與位置變化 → 再選下一步。搜尋可以落空，找不到食物也可能衰弱或死亡；不保證每次飢餓都能生成獵物。群體粗算可概括這些過程，但不能讓詳算動物之外再多出一份群體捕食量。

未領出的普通野獸由生態行為方針粗算；Local 領出的個體依自身感知、需求與可用動作決策。同一份額、同一時段退出群落粗算，進食、死亡或遷徙結果交回原群落責任，不能具名後沒人推進，也不能兩邊各吃一次。

例如森林縮小，獸群可移向別處，沿途也可能接近牧場。牧人察覺後可轉移牲畜、設防、驅離或請求捕獵；結果反過來改獸群風險、地方食物和工作。動物沒有收到人類公文也能感知圍欄或追捕，但不能知道遠方所有安全棲地。無人觀看時仍走這條鏈，不以開地圖觸發一批襲村怪。

非自然生命若靠魔素、召喚或其他來源維持，沿 [力量](../../magic/spec-powers.md) 的明示來源處理，不能硬塞成需要普通食物，也不能因不吃飯而推定不需任何維持。粗細切換仍領同一份生物與時間責任。

## 驅離之後，問題去了哪裡

牧場把獸群趕離後，動物仍按已能感知的食物、通路、同伴與危險選方向；不能由牧人指定牠們自動搬到遠方無人區。可通往合適棲地時可能繞開聚落；退路受阻或護幼時也可能停留、反抗，並非必然逃跑。

若獸群沿路接近另一村，當地牧人要在察覺後才調整放牧、圍護或求助。第一村不因成功驅離就知道牠們後來去了哪裡；接到鄰村消息後，可協調通道、輪流看守、改放牧地或選擇不理會。結果可能保住兩地生計，也可能增加捕獵與地方爭議。各方的應對改變下一輪棲地和風險，不把野獸當無限刷新的襲村事件。

智慧居民與開拓者的交涉另見 [林地接觸案例](../../adventure/spec-exploration.md)；他們談成的地界不直接控制普通動物。
