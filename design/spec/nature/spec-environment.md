## 範圍與完成條件

草案；沿用 [生成契約](../../generation/gen-pipeline.md)、[接邊](../../generation/edge-consistency.md)、[時間](../common/spec-world-time.md)。參考 Endless／Freeciv 的生成分階段與 Veloren 的水文選址線索，證據限度見 [總盤點](../../../wf/workflows/investigation/roadmap-reference-overview-status.md)；以下動態水量帳是本案建議，不聲稱原作已提供。

**Done when：**上游取水、築壩與污染能沿同一條流域影響下游；玩家挖渠、離場、再入場不重置水位或地貌。先定守恆和責任，不選流體求解器、河道改道算法或天氣數值。

## 狀態分型

| 狀態 | 語意與來源 | 不得混用 |
|---|---|---|
| 生成底圖 | seed、生成器／規則版本可重建的基岩、高程與初始水系 | 重生底圖不能覆蓋後來工程 |
| 氣候常態 | 緯度、地形與長期條件形成的氣候指標 | 指標不是一桶可抽走的水 |
| 動態自然存量 | 地表／土壤／地下儲水、雪冰、污染負荷及必要沉積量 | 水位、濃度、流率不是存量 |
| 天氣過程 | 有來源、範圍、時段與強度的降水、風、溫度偏移 | 查詢或載入不能重新抽天氣 |
| 改造與損傷 | 開挖、堤壩、渠、封堵、永久地形差額及版本 | 工程意圖不等於已完成地貌 |

既有 [氣候文](../../generation/worldgen-climate.md) 的 `moisture` 是由空氣含水量導出的生成指標；新增降雨量、土壤含水和可用水需分欄位／單位，不偷換舊定義。相同體積的水可有不同污染負荷；稀釋降低濃度，不等於污染質量消失。

## 自然帳與邊界

每個責任範圍於 `[a,b)` 記期初存量、降水／邊界入流、出流、蒸散、取用、回流及轉化。期末由這些已承認的通量求得；雪融是雪冰轉水，滲透是地表轉地下，不是新增總水量。海洋／大氣可作外部庫，但必須明示輸入輸出，不假裝封閉系統守恆。

跨邊界傳輸用唯一通量紀錄、方向、來源／目的、區間、量與到達條件；若有行程延遲，水／負荷保留在途份額。來源扣除與目的／在途接收同一提交，不能兩側各估一次。不得用四捨五入後的負存量補造水；取整餘量保存，競爭取水要先分配可用額度。

靜態 BoundaryProfile 仍是兩側共同輸入。動態築壩／決堤提交給上層邊界權威，產生帶生效時間的新版本；兩側在同一合法邊界讀新版本，不互問鄰圖，也不由 Local 生成器改寫共用邊。舊版本的未完通量先按時間結清。

跨大陸 WorldGraph 的交通邊不自動是水文相鄰；海路、傳送門或地下水交換要各有明示自然連接，不能沿每條商路傳洪水。

## 工程與自然反應

勘查／提案 → 驗權與環境前提 → 配料排工 → 分段實際改造 → 驗收／維護。政治管土地與水權，工作管工時材料，環境唯一寫入地形／通量約束；缺權可另走明示違法行動，不冒稱合法工程。

挖出土石交物資或棄土位置，不消失；半完工溝渠可以已有水文影響，但效應只讀完成部分。取消不填回已挖地，潰壩不返還建材。堵水若蓄滿，必須依已選規則溢流／滲漏／破壞或拒絕超容量入帳，不能吞掉多餘水。

地形改變使建物失去基礎、人物受困或路線失效時，交各領域處理，不重生整張骨架將其搬走。改道可行性、影響範圍與重新驗證成本待定；未裁定前不能承諾任意挖穿整個大陸。

## 三層、時間、AI 與保存

Region 管流域骨架、自然外部輸入和跨 Site 通量；Site 管水庫、渠道與地表分布；Local 展開積水、井、溝渠與可互動地形。粗層扣除詳算份額，地方水量不另加回一遍。動態自然推進不是地圖生成階段，不因此放寬 Site／Local 生成器的成本限制。

天氣來源與合法時間線固定，雨勢造成橋不可通行時須在旅行依賴前提交，不能只在旬末歸約。粗細步長下累計水量守恆；洪峰／水位近似容差另定，不能拿旬均流量證明短時不會淹水。

AI 依可知水位、季節估計、預警與資源選取水／灌溉／修堤，不讀未探地下水或未來降雨真值。保存自然存量、地形差額、邊界版本、通量游標、天氣來源及必要重建資訊；單存初始 seed 不足以恢復已發生的改造。

## 驗收與待裁定

夾具以同一水量單位：期初 100、入流 30、降水 10、蒸散 5、淨取用 20、出流 40，期末 75；出流 40 只能計入下游或在途一次。再測同時兩渠各要 50，不能都從剩餘 75 全額取走。

負向情境：下游未生成、邊界換版途中保存、四角共同地形改造、雪融雙加水、稀釋消污染、洪峰跨旬漏算、重載回填玩家溝渠。待裁定：量化單位、外部庫、通量延遲、取水仲裁、地下層粒度、河道改道與粗細誤差。
