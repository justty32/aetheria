使用者再次要求繼續大地圖勢力變化、中地圖軍隊調度與城區發展、小地圖人物行為。前輪「完整」只表示各領域有接手者，不能推定行為規劃已充分，更不能直接轉玩家體驗。

目前以「河谷新商路開通、鄰國調兵、地方缺工」作共同推演背景，展開四塊：各方為什麼選某個方案、哪些消息或結果讓它改變主意、代價如何傳到其他層，以及不同選擇怎麼留下不同世界後果。例子不是固定劇本，不用單一國力、忠誠或繁榮數值代替。

四塊行為已有河谷合作／對峙／收縮與和平發展／衰退重組兩組推演，從共用入口進入。另補軍隊縮編後去向協商，人物不因撤軍就自動成為土匪。

主動合作與人物長期方向已補：經歷能讓人維持、改分工或轉向，地方按真缺口選留才、培訓、合作與縮減。相關入口在人物／地方行為，不用職涯等級樹。

多勢力與地方互動已補雙方主動提案、本地反提案與履約後再調整；通行、駐軍、投資和政治控制分開。案例接在河谷行為推演，勢力篇保留對對方目的的暫時判斷。

接敵後行為已補守點、試探、側翼、預備、撤退與追擊的判斷；Local 發現／拒令交到有權軍官改令，傳令途中仍有效的舊令與現場避險分開。沒有選出手序或傷害公式。

奇幻手段也已接成行為差異：有限傳送、感知、治療、召喚及造糧會改變運輸、部署、服務與分工；各方依所知回應，術者本身能拒絕或改安排，來源遭針對時要重議。

長期安排已補三種改案尺度：目的、安排與下一步分開；沿護路、卸貨建設、學染布推演小延誤、連續受阻及完成退出。保存時保留方向與已嘗試的經歷，不因換層或讀檔重置。

並行安排已補護路、農忙與建設爭車的協商：由持有人回覆可用部分，地方可促成改期與分工；分到部分仍要看能否完成關鍵步驟。共用資源仲裁不越過不同持有人的權利，軍事急件不直接變成徵用。

權力交接已補候選人、地方官、軍官與家戶各自的支持、觀望和拒從；同一河城例子比較承諾履行與落空後的守備、合作及實控變化。支持可只限某事，爭位宣言不直接成立新國家。

野外互動已補拓林遇到原有居民的觀察、交涉、改路、阻擋及離開；生態篇補驅離獸群後對鄰村的影響。土地爭議保留各自主張，居民能主動交涉，協議不直接約束普通野獸。

整體審閱見 [行為核對](spec-behavior-review.md)：分開查選擇理由、結果及帳目。已修整合 C 停火生效／前線知情的表述，政體補空窗無權承諾時的限期未履約出口；沒有強加萬能代理。家庭主動形成與下一代接續另在人物層補鏈，不再只有既存家庭與出生資料。

複合變故已在行為核對串起歉收、家庭照護、缺車及權力空缺：既有有效工作不因增援未准全部停擺，缺乏替補則留下真短缺。修正旅行篇把受阻稱為安全狀態的表述，停下仍受暴露與消耗影響；新任只能據收到的進度改案，不能免費查遠方真值。

矛盾消息已補查證、維持、分批試做與迫近期限時的冒險選擇，並以渡口傳聞推演誤導與更正。系統真實來源鏈和人物能辨認的來源分開，匿名轉述可使人誤信；新消息不強制每人改案。

教團變故已補失去治療神術後的查因、普通照護合作、縮減服務與轉送；信念、會員與實際服務分開。能力失效不讓所有信徒立即得知原因，也不自動改宗；地方、軍隊依收到的容量變化改案。

原需求範圍已核對十二系統框架、M0–M11 覆蓋與世界情境；補上戰爭原目的消失後，決定者重議、改令與前線接令的流程。內容追加、分檔、歷史與故事未發現新的高層缺口；這不代表實作或整體行為已驗證完成。

2026-09-10 使用者建議先以《勇者鬥惡龍》作背景，見 [背景草案](spec-world-background.md)。下一步用自主冒險隊與魔王勢力串村鎮、旅途和地方危機，檢查各自如何開始、改案與收尾；不預定玩家是勇者，不先訂完整劇情或職業表。保持大白話與彈性，只補有證據的缺口。目前不需人工 compact。

- 純 C++ 玩法與 Godot 呈現分工不變；現在不改程式、API、存檔版本或開實作任務。
- 無人類命令不等於全世界逐人常駐，也不等於重做 observer；既有粗細責任與校準要求仍在。
- mark／獨特物件與 root 成長仍擱置；M10 全 def 追加、M11 腳本追加邊界保留。
- 各文件不超過 8 KB，沿既有層級，不另外搬檔；共用進度只動實作者區塊，不碰規劃者區塊。
