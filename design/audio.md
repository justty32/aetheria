# 音效與音樂

> 三層地圖各有音景，而且**切層是玩家最常做的操作**——音訊的接縫比畫面更容易穿幫。
> 通用原則見 [principles.md](principles.md)；用詞以 [glossary.md](glossary.md) 為準。

## 四類音訊

| 類 | 例 | 觸發者 |
|---|---|---|
| **BGM** | 各層的主題、戰鬥曲、劇情曲 | 駐留層 + 情境 |
| **環境音** | 風、雨、市集喧鬧、地城滴水 | 所在 zone 的地形與時辰 |
| **事件音** | 刀劍、法術、建造完成、城破 | core 吐出的事件 |
| **UI** | 點擊、確認、取消、警示 | 前端自己 |

前三類**由 core 的事件驅動**，UI 完全歸 Godot——
這與 [tech-stack.md](tech-stack.md) 的邊界一致：core 吐事件，Godot 演出。
**core 不認識任何音檔**，它只吐 `EventDefId`，Godot 端查表播放。

## 三層的音景

| 層 | BGM 性格 | 環境音 |
|---|---|---|
| **L1 Region** | 恢弘、緩慢、地理感。一個文明一個主題 | 風、遠處的鳥、季節（冬季更靜） |
| **L2 Site** | 中距離、有生活感或緊張感 | 市集人聲、鐵匠敲打、戰場的號角與腳步 |
| **L3 Local** | 內斂、留白多。**地城幾乎無 BGM** | 腳步、環境細節、地城的滴水與遠處聲響 |

**L3 的留白是刻意的。** 探索與潛行需要玩家聽得見環境——
[lowmap.md](lowmap.md) 的潛行機制裡「聲響」是一個維度，
BGM 蓋掉它就等於廢掉那條玩法。

## 切層的接縫

玩家在三層之間上提下沉（[player-residence.md](player-residence.md)），
音訊必須跟著轉而不能硬切。

作法：**分層混音 + 交叉淡入**

```
上提（Local → Site → Region）：細節層淡出，寬景層淡入
下沉：反向
```

三層的 BGM 若共用**同一組主題動機**（motif），切層就會像是
「同一首曲子換了編制」而不是「換了一首歌」。這是一條省力又有效的做法：
一個文明的主題，在 Region 是全編制、Site 是小編制、Local 是單樂器。

## 動態音樂：接到既有機制

不另發明一套音樂狀態機，**直接吃現有的訊號**：

| 訊號 | 來源 | 音樂反應 |
|---|---|---|
| 駐留層 | [player-residence.md](player-residence.md) | 換編制 |
| 是否交戰 | [events.md](events.md) 的主場層事件 | 切戰鬥層 |
| 事件重要性 | [significance.md](significance.md) | `Region` 級以上事件 → 加強奏 |
| 季節、時辰 | [outline.md](outline.md) 的曆法 | 換色彩層 |
| 場強 | [observer.md](observer.md) | 玩家 mark 的對象出事 → 提示動機 |

最後一條特別值得做：**被 mark 的角色遭遇危險時，
音樂裡浮出他的動機**——玩家不必看 UI 就知道有事。
這讓 [unique-objects.md](unique-objects.md) 的獨特物件有了聽覺存在感。

## 素材量與生成

音訊同樣會用 AI 生成，問題與美術同構（[art-pipeline.md](art-pipeline.md)）：
**單段好聽容易，整套一致難**。

| 類 | 量級 | 一致性風險 |
|---|---|---|
| BGM | 20～40 段（含各層編制） | **高**——調性、配器、混音要一致 |
| 環境音 | 30～50 段循環 | 中——音量與頻譜要平衡 |
| 事件音 | 150～300 個短音 | 低——但數量大 |

對策照搬美術那套四道閘：

1. **錨定**：先定調性中心、配器組、響度標準（LUFS）
2. **生成**：一次一類，記錄參數
3. **後處理（確定性）**：響度正規化、EQ 統一、循環點對齊、淡入淡出
4. **驗收**：連續播放整組聽差異，腳本檢查響度與格式

**響度正規化是音訊版的「色盤量化」**——它解決最刺眼（刺耳）的那類不一致，
而且完全可自動化。

## 技術約定

| 項目 | 約定 |
|---|---|
| 格式 | BGM 用 Ogg Vorbis；短音效用 WAV（免解碼延遲） |
| 響度 | 統一到同一個 LUFS 目標，各類之間再定相對偏移 |
| 循環 | 環境音與 BGM 必須無縫循環，循環點在後處理對齊 |
| 命名 | 同美術：**def id 的點換斜線就是路徑**（[art-specs.md](art-specs.md)） |
| 缺檔 | 開發模式播提示音 + console 警告；正式版拒絕啟動 |
| 混音匯流排 | Master / BGM / SFX / Ambient / UI / Voice，各自可調 |

## 語音

**初版不做全語音。** 中世紀奇幻 + 日式表現會讓人想做角色配音，
但那是內容量的黑洞，而且與程序生成的世界（多數角色沒有名字）根本不相容。

折衷：**關鍵劇情角色的少量語音 + 通用的情緒短音**（受擊、驚呼、應答）。
通用短音依種族與性別分組，任何角色都能用——
這與 [unique-objects.md](unique-objects.md) 的「標籤型 vs 獨特型」是同一條線。
