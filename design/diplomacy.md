# 外交與戰爭

> 勢力之間的關係怎麼表達、怎麼變化、怎麼影響 Region 模擬。
> AI 的決策模型見 [faction-ai.md](faction-ai.md)。
> 通用原則見 [principles.md](principles.md)；用詞以 [glossary.md](glossary.md) 為準。

## 關係是有向的

```
relation[A][B] ≠ relation[B][A]
```

A 可以恨 B 而 B 對 A 無感。單向關係讓「一廂情願的仇恨」「單方面的仰慕」
成為可能，敘事空間大得多，成本只是一個矩陣而非三角陣。

勢力數是個位到十幾個，所以**存整個矩陣就好**，不必稀疏化。

## 關係的組成

不是一個數字，是幾個分量：

| 分量 | 變化速度 | 說明 |
|---|---|---|
| **好感** | 快 | 近期行為的累積，會隨時間回歸中性 |
| **信任** | 慢 | 守約與背約的長期紀錄。**背約一次，數十旬才補得回來** |
| **恐懼** | 中 | 對方國力與軍事姿態的函數 |
| **積怨** | 極慢 | 戰爭、屠城、領土喪失留下的。幾乎不消退 |

分開的價值：一個勢力可以**又怕又恨**（會結盟對抗你），
也可以**信任但無好感**（會守約但不會幫你）。單一數字表達不了這些。

## 條約是資料

`TreatyDef`（[definitions.md](definitions.md)）。初版：

停戰、和約、通行權、貿易協定、防禦同盟、附庸、聯姻。

每個條約帶：期限、條件、違約後果、可否續約。
**加一種條約 = 加一筆資料**，不改程式。

## 宣戰理由

不能無理由開戰——那會讓外交系統失去意義。
`CasusBelliDef`：領土主張、王位繼承、宗教（見 [rules-magic-faith.md](rules-magic-faith.md)）、
報復、解放附庸。

- 無理由開戰**可以**，但代價很重：所有第三方的信任大跌
- 理由**會過期**，逼玩家與 AI 在窗口內行動——這是戰爭爆發的節奏來源

## 情報不對稱

外交建立在**你以為對方是什麼樣**之上，不是對方真正的樣子。

- 每個勢力對他國的國力估計帶誤差（[faction-ai.md](faction-ai.md)）
- 條約談判用的是估計值
- 間諜、使節、商隊降低誤差

這也接上 [unique-objects.md](unique-objects.md) 的「不知道確切位置」：
情報是一種可以主動取得的資源。

## 戰爭在 Region 層是什麼

戰爭**不是一個布林值**，是一個持續事件（[events.md](events.md)）：

```
戰爭 = { 參戰方, 起因, 開戰時間, 戰果累計, 厭戰值 }
```

| 欄位 | 作用 |
|---|---|
| 戰果累計 | 佔領、會戰勝負、掠奪的加總，決定和談籌碼 |
| **厭戰值** | 隨時間與傷亡上升，壓低士氣與稅收，逼向和談 |

**厭戰值是戰爭會結束的原因。** 沒有它，AI 會打到一方滅亡，
世界很快變成一兩個巨獸。有了它，多數戰爭會在僵持後和談——
這才是中世紀戰爭的樣子。

## 和談

當雙方的「繼續打的期望收益」都低於「現在收手」時觸發：

```
和談籌碼 = f(戰果累計, 雙方厭戰值, 第三方壓力)
```

條件從籌碼推導：割地、賠款、附庸化、單純停戰。
**玩家與 AI 用同一條公式**——同 [combat-formula.md](combat-formula.md) 的原則，
玩家能算出來的，AI 也只用那一套。

## 第三方

外交的樂趣多半來自第三方：

| 機制 | 效果 |
|---|---|
| **均勢** | 勢力會傾向對抗最強者。這自動產生反霸權同盟，不必特別寫 |
| **連鎖參戰** | 同盟被攻擊時的參戰義務；不履行 → 信任重挫 |
| **調停** | 強權可以壓迫交戰方和談，換取好感或利益 |

「均勢」那條特別划算：它只是效用函式裡的一項，
卻讓玩家坐大時自動面對聯合圍剿——一個機制產生一整條戲劇曲線。
