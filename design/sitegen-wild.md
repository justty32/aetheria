# L2 生成：荒野、廢墟與海域

> Region 的一格若沒有城市，放大之後是什麼樣子。64×64、一格 125 m。
> **預算 < 30 毫秒**。城區見 [sitegen-city.md](sitegen-city.md)；邊界對齊見 [edge-consistency.md](edge-consistency.md)。
> 通用原則見 [principles.md](principles.md)；用詞以 [glossary.md](glossary.md) 為準。

## 荒野比城區更常見

Region 有 12288 格，其中有城市的大概幾十格。**絕大多數 Site 是荒野**。
所以荒野生成器的兩個設計目標與城區不同：

1. **更便宜**——它會被呼叫幾百倍多的次數
2. **持久層極小**——荒野幾乎沒有玩家蓋的東西，所以卸載成本極低，
   是 [interface-lifecycle.md](interface-lifecycle.md) 的 LOD 機制最常運作的地方
   （`N` 初值只有 2 旬）

## 管線

```
W1 地形底層 → W2 水系 → W3 道路 → W4 植被 → W5 遭遇與採集 → W6 L3 入口
```

沒有骨架／填充的兩階段分離——荒野的一切都由慢變數決定，快變數只影響 W5。

## W1 地形底層

從四條邊的 `BoundaryProfile` 內插高度，疊上 `site_seed` 的噪聲，
振幅由 Region tile 的 `relief` 決定：

| Region 的 `relief` | Site 內的樣子 |
|---|---|
| 平原 | 幾乎平坦，微起伏 |
| 丘陵 | 連綿緩坡，視野會被擋 |
| 山地 | 大落差，多數格子不可通行，只有谷地能走 |
| 高山 | 幾乎全不可通行，只有隘道 |

`ground` 由 Region 的 `base` 決定基調（草原→草地、沙漠→沙、凍原→凍土），
再依 Site 內的局部高度與濕度做變化。

**山地 Site 的可通行格很少，這是刻意的**——它讓大地圖上的山脈在下鑽之後
仍然是屏障，而不是「放大看發現隨便走」。

## W2 水系

河流從邊界的 `Crossing` 進來，必須從另一條邊的 `Crossing` 出去（或在本格內匯入湖泊）。

- 進出點都是既定的，中間的河道用**梯度下降**連起來：從入口沿最低路徑走到出口
- 河道兩側刻出河谷（降低高度），這一步要在 W4 之前，因為河谷會影響植被
- 河寬由 `Crossing.width` 決定，沿途可漸變
- 若 Region 的 `feature` 是沼澤，就把低窪處全部改成淺水

**入口與出口不對稱時**（一條大河進、一條小溪出）表示這裡有分流或滲漏，
交給資料檔的規則決定要不要放湖泊。

## W3 道路

同理：道路從 `Crossing` 進、從 `Crossing` 出，中間用 A* 連（偏好平緩、避水）。
遇到河道就在交會處放橋或渡口——**種類由 Region 的複合 `EdgeDef` 早就決定了**
（見 [worldgen-civ.md](worldgen-civ.md) 的渡河與橋一節），Site 只是把它畫出來。

道路兩側可放路邊設施：里程碑、廢棄的驛站、路邊神龕。密度很低，但玩家會注意到。

## W4 植被與地物

用**藍噪聲散布**（抖動網格：規則網格 + 每點在格內隨機偏移），
密度由 Region 的 `feature` 與 Site 內的局部濕度決定。

| Region 的 `feature` | Site 內的密度 |
|---|---|
| 無 | 零星幾叢 |
| 疏林 | 30%，成小片群落 |
| 密林 | 70%，大片連續，視線受阻 |
| 礦脈 | 岩石露頭 + 一個可採集的礦點 |

藍噪聲而不是純隨機：純隨機會產生明顯的團塊與空洞，看起來像壞掉。
抖動網格是 O(n) 的，成本可忽略。

## W5 遭遇點與採集點

這是唯一讀快變數的一步。

| 東西 | 密度隨什麼變 |
|---|---|
| 採集點（藥草、木材、獵物） | Region 的 `feature` 與季節 |
| 遭遇點（野獸、盜匪） | 該區域的治安（來自 `owner` 的控制力與鄰近勢力衝突程度） |
| 旅人、商隊 | 該格是否有道路、道路等級 |

**遭遇點是位置而不是實體**：實際生出什麼，等玩家踏上去的當下才依重要性機制決定
（見 [significance.md](significance.md)）。多數遭遇的參與者是 `Ambient` 級，
不生名字、不進持久層。

治安低的無主荒野會自然變得危險——這讓「勢力控制力」這個 Region 層的抽象數字，
在下鑽之後有了具體的體感。

## W6 通往 L3 的入口

`Portal` 實體，位置由 `site_seed` 抽定，密度依 Site 種類：

| Site 種類 | L3 入口密度 |
|---|---|
| `Wilderness` | 低。洞穴口、獸巢 |
| `Ruin` | **高**。這是廢墟存在的理由——地下遺跡、封閉的塔、墓室 |
| 山地 | 中。礦坑、山洞 |

垂直層（地下／地面／天空）收在**同一個 zone** 的 z 鍵裡（見 [outline.md](outline.md)），
所以「入口」在資料上是「某格的 z 方向可通行」，不是跨 zone 的傳送。

## 廢墟（`Ruin`）

荒野生成器的參數化變體，額外多兩步：

- **殘存結構**：用 [sitegen-city.md](sitegen-city.md) 的街廓演算法跑一遍，
  但只保留 20～40% 的街廓，其餘改成瓦礫與植被侵蝕的痕跡。
  規模對應該廢墟當年的等級（由 [worldgen-civ.md](worldgen-civ.md) 的歷史層決定）。
- **古道接入**：歷史層留下的古道從邊界進來，通向廢墟的中心。

複用城區演算法而不是另寫一套，是這裡最划算的決定：
玩家會看出「這曾經是一座城」，因為它真的是用蓋城的邏輯蓋出來、再拆掉的。

## 海域（`Sea`）

最便宜的一種：

- 全部是水，深度由 Region 的 `elevation`（負值）與到岸距離決定
- 航道從 `Crossing` 進出（海路也是 `EdgeDef`）
- 淺灘、暗礁、海流由 `site_seed` 散布；海流影響航行成本
- 遭遇：海獸、海盜、商船

## 待細化

- `Ruin` 的保留比例與侵蝕表現
- 季節對植被與採集點的實際修正
