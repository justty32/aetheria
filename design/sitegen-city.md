# L2 生成：城區

> Region 的一格若是城市，放大之後是什麼樣子。64×64、一格 125 m。
> **預算 < 30 毫秒**——玩家進城的當下生成，不能卡。
> 共通規矩見 [gen-pipeline.md](gen-pipeline.md)；邊界對齊見 [edge-consistency.md](edge-consistency.md)。
> 通用原則見 [principles.md](principles.md)；用詞以 [glossary.md](glossary.md) 為準。

## 「有序的隨機」

城區不能像荒野那樣純噪聲，也不能是規則網格。作法是**骨架先行、隨機在填充**：

```
骨架（決定秩序）：主幹道 → 次級街道 → 街廓
填充（決定變化）：分區 → 建築 → 城牆 → 地標
```

骨架讓城市有結構（路通向該通的地方、街廓有大有小），
填充讓每座城不一樣。兩者的分工同時對應**慢／快變數的分離**。

## 骨架階段（只准讀慢變數）

### S1 地形底層

從四條邊的剖面內插出高度場，疊上 `site_seed` 驅動的低頻噪聲，
再依 Region tile 的 `relief` 調整起伏幅度。水體從邊界的 `water_depth` 延伸進來。

一次線性內插 + 一層噪聲，4096 格，微秒級。

### S2 主幹道

主幹道**不是憑空生成的，是從邊界的 crossing 長進來的**：

1. 取四條邊上所有道路類的 `Crossing`（通常 2～4 個）
2. 定出**城心**：地形最平緩、離水源近、離各 crossing 的加權距離最小的點
3. 每個 crossing 用 A* 連到城心，成本函數偏好平緩、避開水體
4. 路徑重用既有路段（成本大減），讓幹道自然收束成幾條主軸

結果是「幾條路從城門進來，在城中心的廣場交會」——
而那些城門的位置，正好對得上大地圖上那幾條路進來的方向。

### S3 次級街道與街廓

用**遞迴二分**切出街廓（block）：

```
split(rect, depth):
  if rect 夠小 or depth 到頂: 收成一個 block
  沿長邊挑一個切點（由 site_seed 抽，偏向黃金比例附近而非正中）
  在切點畫一條街道
  遞迴切兩半
```

- 深度上限 4～5 層，產出 30～60 個街廓
- 切點偏離正中是關鍵：正中切會產生棋盤，偏移切會產生有大有小的街廓
- 主幹道切出的區域各自遞迴，所以街廓天然順著主幹道的走向

**O(街廓數)，沒有迭代、沒有回溯**——這是守住 30 ms 的原因。

### S4 可建地標記

標出哪些格能蓋東西：排除水體、陡坡、街道本身。
這張遮罩是骨架的最後產物，**持久層物件的座標合法性就是對照它驗證的**。

## 填充階段（可以讀快變數）

### F1 分區配額

依建設等級與人口決定各分區占多少街廓：

| 分區 | 配比隨什麼變化 | 位置偏好 |
|---|---|---|
| 住宅 | 人口 | 中距離環帶 |
| 商業 | 建設等級、是否港口 | 貼主幹道、近城心 |
| 工坊 | 生產力 | 近水（水力）、城市下風處 |
| 軍事 | 防禦值 | 近城門、近城牆 |
| 農地 | 糧食產出 | 城牆外、地力高處 |
| 空地／野外 | 剩餘 | 邊緣 |

每個街廓算一組分數（城心距離、幹道可達性、地形、水源），
**按分區的偏好做加權配對**——不是隨機灑。

小城市的配額表算出來就是「幾條街 + 一片農地」，大城市才有完整分區。
**同一套程式碼服務村莊到大都會，差別只在配額。**

### F2 街廓內填建築

每個街廓依分區類型，從資料檔的建築表裡挑 def 填入：

1. 沿街廓的臨街邊排建築（背對背，中間留內院）——中世紀城市的實際形態
2. 用 `BuildingDef` 的尺寸做貪婪 packing，填不滿的剩餘空間變內院或空地
3. 建築密度由建設等級決定：低等級留大量空地，高等級擠滿

**相鄰加成在這一步就已經成立**：工坊街廓挨著礦場入口、住宅街廓挨著廣場。
生成器不必特別處理，因為位置偏好已經把它們放到該在的地方。

### F3 城牆

依防禦值決定圈住的範圍：

1. 取要保護的街廓集合（依重要性排序，取前 N）
2. 沿街廓外緣圍出一條閉合路徑（走格子邊，不走格心——牆是**邊屬性**）
3. **城門開在主幹道穿過牆的地方**，數量等於主幹道條數
4. 依防禦值加塔樓（沿牆等距）、加護城河（外圈一環的水體邊）

防禦值為 0 就沒有牆。防禦值很高的城會有內外兩重牆（重複跑一次，圈住更小的核心）。

### F4 地標

宮殿、大神殿、市集廣場、公會大廳——從 `owner` 勢力的風格表挑，
放在城心附近分數最高的街廓。這些是玩家記得住這座城的原因，值得單獨處理。

### F5 損毀

依 Region 的 `damage` 把一定比例的建築改成瓦礫或焚毀狀態，
優先選靠近城牆缺口與城門的——攻城的痕跡應該在它該在的地方。

## 持久層疊加

骨架與填充跑完得到的是**底稿**。最後一步把 `SiteDigest` 的持久層蓋上去：
玩家蓋過的建築回到原座標，狀態依當前快變數重算（運作中／閒置／荒廢／傾頹）。

底稿與持久層衝突時，**持久層永遠優先**——玩家的決定不會被程序生成覆蓋。
完整規則見 [interface-world-mid.md](interface-world-mid.md)。

## 守住 30 毫秒

| 禁止 | 因為 |
|---|---|
| 迭代式鬆弛、物理模擬 | 成本不可預測 |
| 回溯搜尋、wave function collapse | 最壞情況無上界 |
| 全圖 A*（超過幾條） | 主幹道最多 4 條，可接受；再多就要改用預算式搜尋 |
| 任何「收斂為止」的迴圈 | 同時破壞預算與決定論 |

超出預算的退路是**背景預生成**：玩家的部隊還在路上時就先把目的地的 Site 生出來。
生成器是純函數，所以搬到背景執行緒是安全的。
