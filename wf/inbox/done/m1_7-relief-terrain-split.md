## 我從圖上讀到的因果鏈

`data/biomes.toml` 是一份**有序 first-match 規則清單**，而且它**同時決定 terrain 與 relief**：

```toml
[[rules]]                      # 規則 2
max_moisture = 12500
terrain = "terrain.desert"
relief  = "relief.plain"       # ← 順手把地貌也決定了
```

濕度圖顯示陸地濕度幾乎是**單一值**，而且落在 12500 以下。
所以規則 2 在約 **97% 的陸地上命中**——而它排在規則 3（mountain）與規則 5（hills）**之前**。

推論：**只要乾燥，地貌就被抹成平原。而這張圖到處都乾燥。**
所以這張地圖幾乎沒有山、沒有丘陵，全是平的。

這一件事解釋了我這幾輪一直在追的**四個看似無關的症狀**：

| 症狀 | 從哪來 |
|---|---|
| 全是沙漠（你看到的） | 規則 2 到處命中 |
| **國界不沿地形長**（3.04 vs 2.975，只差 2%） | 沒有地形可沿——全是平原，移動成本幾乎均一 |
| **可通行邊界上完全沒有山地**（M1.6.1 你回報的） | 同上，山被抹掉了 |
| 交通瓶頸評分沒什麼可算（M1.4 的「兵家必爭之地」） | 同上 |

四個症狀、一個根因。這是**只有看圖才找得到的東西**——十二階段的雜湊全都是綠的。

## 裁定：relief 與 terrain 是兩個正交的軸，必須分開裁決

- **relief（plain／hills／mountain）＝ 地貌。** 只由 `elevation` 與 `ruggedness` 決定。
  **`moisture` 與 `temperature` 不得參與。** 一座山不會因為沒下雨就變平地。
- **terrain（desert／grassland／tundra／swamp）＝ 群系。** 由 `temperature` 與 `moisture` 決定
  （swamp 那條可以繼續看 elevation）。

一份有序清單同時決定兩個正交的軸，**先命中的那條就把另一軸抹平**。
這是結構問題，不是調參問題。
