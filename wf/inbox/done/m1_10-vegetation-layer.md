## 裁定：seed 之間的差異是**特徵，不是缺陷**

```text
沙漠：15.22% / 4.86% / 47.42%
沼澤：15.14% / 0 / 0
```

你說「同一門檻無法讓三張各自都落在目標區間」——對，**而且不該讓它們都落在同一區間。**

`worldgen-terrain.md` 末段：同一個世界的所有 Region **共用同一組 def 與 biome 判定表**，
只有 `region_seed` 與緯度位置不同。世界有 3～5 個 Region。
**一片綠色群島和一片沙漠大陸，正是世界該有的多樣性。**

本來就該濕；大陸內部本來就該乾。**所以不做 per-Region 正規化，門檻維持全域絕對值。**

## 但「單張圖內部單調」仍然是問題，而缺的軸設計裡早就有了

seed 62208000 是 **95% 草原**——跨 seed 有變化，單張圖內部還是單色。

解法**不是**再去調地形門檻。`worldgen-terrain.md` 第 7 節寫著：

> 森林（疏林／密林／雨林）：密度 = **f(temperature, moisture)**，用藍噪聲散布避免整片糊成一塊

**森林是地物層，不是地形層。** 地形只有 4 種是刻意的骨架；讓地圖活起來的是植被。

### 而植被層現在幾乎確定是壞的

地物階段的參數（`forest_density_scale = 42000`、`oasis_chance`…）是對著
**壞掉的舊 moisture** 校準的——當時全圖不是 900 就是 0。所以：

- 森林密度 `f(temperature, moisture)` 吃到的 moisture 幾乎恆為 0 → **森林應該一直接近零**
- 綠洲規則是「沙漠中有地下水的格」，而當時**到處都是沙漠** → 綠洲應該到處都是

這正好對上檢視器第一次回報的那句：**「地物層被大量綠洲標記主導」**。

**moisture 現在修好了，地物層應該完全變了。去量。**
