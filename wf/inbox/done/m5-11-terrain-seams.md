## 這輪不調地形

使用者裁定：**地形生成之後會單開一個 session 專門處理，這邊先放下、預留函數接口。**

所以這輪**一個數值都不要調**。目標只有一個：
**讓那個未來的 session 能插進來，而不必先把管線拆一遍。**

⚠ 不要順手「順便修一下濕度」——那正是要留給那個 session 的事。

## 已知的病灶（留給那個 session，本輪只記錄不處理）

`moisture` **壓在 `uint16` 天花板上**，三個參考 seed 的 `p95` 與 `max` 都是 65535：

```
515151   9420 / 58757 / 65535 / 65535      (min/median/p95/max)
12345   10903 / 44098 / 65535 / 65535
424242   7666 / 48231 / 65535 / 65535
```

因此 M5.10 的 swamp 只能靠把 `moisture_scale` 收到 8000 壓到 **49.457%**——
**離 50% 的 guard 只剩 0.54% 餘裕**，同一張圖 tundra 只有 1.139%。

> 這是同一族群的第四次：前三次是**門檻落在分布之外**，
> 這次是**分布本身壓在天花板上**。結果一樣——分類規則失去鑑別力。

## 要留的接口

### ① 分布重整的插入點（高度與濕度各一）

在**量化成 tile 欄位之前**留一個具名的重整步驟，**預設是恆等函數**：

```
raw field  ──►  redistribute(field, params)  ──►  quantize  ──►  tile
                        ▲
                   預設 identity，未來的 session 從這裡插入
```

⚠ **預設必須是恆等**，而且落地時**所有現有雜湊不得改變**——
這是本輪最重要的驗收條件：**留了接口，但世界一個位元都沒變。**

⚠ 若未來要放 rank remap，**用整數 LUT，不要 `pow`**（你 M5.9 自己寫的，跨平台浮點不決定性）。

### ② 把散落的地形常數收進 config

warp 波長／幅度、海平面比例、各 biome 的 target／scale——
現在散在 `stage_height.cpp`／`stage_plates.cpp`／`data/biomes.toml`。
**收攏到既有的 `region_config.h` 或資料檔**，讓調參不必改程式碼。

⚠ 收攏就好，**值一律照抄現況**，不要順手改。

### ③ 量測工具留成可重複呼叫的入口

你這幾輪自己寫的直方圖、碎形度、板塊重合率、飽和格比例——
**做成 `aetheria_sim` 的子命令**，不要是一次性腳本。
那個 session 第一件事就是量測，工具在手上它就不必重寫一遍。
