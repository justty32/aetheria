## 這份任務要證明什麼

**證明生成管線的骨架與決定論機制成立。地形好不好看完全不重要。**

M1.1 只做 **管線骨架 + 決定論驗證 + 前三階段（板塊 → 高度場 → 侵蝕）**。
氣候／河流／biome／地物是 M1.2。

選前三階段是因為它們產出 `elevation`，那足以壓到**這條管線唯一真正危險的東西**：
浮點量化點。其餘四階段是同一套骨架的重複。

## 範圍

### 1. 管線骨架

照 [`gen-pipeline.md`](../../../design/gen-pipeline.md)：**階段即純函數**。
三條硬性要求（無副作用、可獨立測試、**可獨立視覺化**）一條都不能省。

`build_skeleton` 與 `populate` 的分離**用函式簽章擋死**——`build_skeleton`
拿不到快變數。M1.1 還沒有快變數，但**簽章現在就要對**，否則之後補是改所有呼叫點。

### 2. 種子衍生

```
stage_seed  = splitmix64(world_seed ^ STAGE_ID)
region_seed = splitmix64(world_seed ^ REGION_SALT ^ region_id)
```

**每階段拿自己的子種子，絕不共用一條 RNG 串流。** 階段內部有多個子系統的，各自再衍生。

這條的價值在驗收條件裡（見下「階段隔離」）——它不是潔癖，是內容製作期的體驗差異。

### 3. 前三階段

照 [`worldgen-terrain.md`](../../../design/worldgen-terrain.md)：

- **板塊**：Voronoi 撒 8～16 個種子，每塊帶 `is_oceanic`／`drift`／`base_elevation`；
  邊界依相對運動分收斂／張裂／錯動。
- **高度場**：`plate_base + boundary_effect + fbm`；海平面二分調整到陸地占比 30%±5%；
  連通性修補（清掉太小的孤島、確保主大陸單一連通塊）。
- **侵蝕**：簡化熱力侵蝕，**固定迭代次數，不准「收斂為止」**——收斂判定會引入不確定性。

**數值全部待校準**，設計裡的板塊數、octave 數、迭代次數都是起點不是定論。
挑能跑的值，在回信說你用了什麼。

### 4. ⚠ 量化點 —— 本任務的核心風險

`gen-pipeline.md` 說：

> 生成階段的中間計算可以用浮點（噪聲、梯度），但**寫進世界狀態前必須量化成整數**，
> 且量化必須在**明確的一點**發生，不能散落各處。

這是「遊戲狀態不用浮點數」那條約定的**真正理由**——浮點的求值順序、
`-ffast-math`、超越函式的實作差異都會讓跨平台結果分岔。

**你要指出那一點在哪，並讓它可被測試。** 散落各處的量化等於沒有量化。

### 5. `aetheria_sim` 的除錯出口

```bash
aetheria_sim gen region --seed 12345 --dump-stages out/
aetheria_sim gen verify --seed 12345 --iterations 100
```

dump 格式你定（PGM／PNG／原始灰階都行，能看就好）。
**這個不是加分項**——設計原話是「除錯地形生成器沒有這個等於瞎子摸象」。

## Done when

- [ ] **同 seed 逐位元相同**：同一 seed 生成兩次，所有欄位雜湊相同
- [ ] **階段隔離（最重要的一條）**：改動階段 3 的參數，**階段 1、2 的輸出雜湊必須不變**。
      這條會直接否證「子種子有沒有真的隔離」——如果共用了 RNG 串流，它必然失敗。
      **貼出改參數前後的兩組雜湊**
- [ ] **量化點單一且明確**：指出它在程式碼哪一行，並有測試證明
      「世界狀態欄位裡沒有任何值來自未經該點的浮點運算」（怎麼證你設計，說明你的方法）
- [ ] **編譯期擋住浮點進世界狀態**：`RegionTiles` 的欄位型別本來就是整數，
      但要有一個測試或 static_assert 讓「有人加了 `std::vector<float>` 欄位」會失敗
- [ ] `build_skeleton` **在型別上拿不到快變數**（貼簽章）
- [ ] 三階段各有可 dump 的中間產物，`--dump-stages` 真的生出檔案
- [ ] **效能預算**：一個 Region < 3 秒，貼實測數字
- [ ] 陸地占比落在 30%±5%，主大陸單一連通塊（貼實測）
- [ ] 生成器**吃 `const Ruleset&`**，用字串 id 查一次下標；查不到 → fail-fast
- [ ] 四個 target 零警告、CTest 全綠、`aetheria_core` 仍零 godot-cpp
- [ ] commit 到 `main`（不 push）
