## 這輪補的是你自己指出的缺口

M6.2 的回報最後一節寫著：

> 本輪任務未要求把外交世界狀態接進 zone 存檔；
> 因此**沒有外交狀態跨存檔往返證據**。

誠實指出來很好，這輪把它補上。外交狀態（關係矩陣、條約實例、宣戰理由的取得時間、
進行中的戰爭與厭戰值）**全部是持久層**——它們是慢變數，重算不出來。

## ⚠ 這一輪最容易假通過，四個陷阱都適用

`interface-verification.md` 與 `verification-detection-power.md` 列的假通過，
**這輪四個全部踩得到**：

| 陷阱 | 在這輪的長相 |
|---|---|
| **沒冷載入** | 往返測試用的是還在記憶體裡的物件，不是真的從檔案解碼回來 |
| **值停在預設** | 關係四分量全是 0、沒有進行中的戰爭——存什麼都會過 |
| **只比頭尾** | 只比對矩陣的第一個與最後一個元素 |
| ⚠ **空的層必然通過** | **沒有任何條約、沒有任何戰爭時，往返當然一致** |

**所以硬性要求**：往返測試的初始狀態**必須非空且非預設**——

- 關係矩陣：至少三個勢力，且**四個分量都不是 0**，且**有向不對稱**
  （`relation[A][B] != relation[B][A]`，這是 M6.2 的核心性質，往返後必須還在）
- 至少 2 筆有效期不同的條約實例
- 至少 1 筆**已取得但尚未過期**的宣戰理由（附剩餘旬數）
- 至少 1 場**進行中**的戰爭，厭戰值**不是 0**、戰果累計**不是 0**

**回報要附上這些初始值的實際數字**，讓我能看出它真的非空。

## ⚠ 不能用 byte 相等

M4 就裁定過：**EnTT snapshot 只對同一段建構歷史決定性**，
不同建構歷史產生的位元流不同但語意相同。
所以往返判準是**正規化狀態雜湊**（`aetheria_sim verify world-hash` 那一套），
不是 `memcmp`。

## ⚠ `load` ≠ `rematerialize`

另一條 M4 的裁定：`load` 只解碼持久層，程序層是空的。
**拿 `load` 當「重新展開」，往返測試照樣通過。**

外交狀態全部是持久層，所以這輪 `load` 是對的路徑——
但**測試要明確斷言走的是哪一條**，不要讓後人以為它證明了 rematerialize。

## 版本遷移

外交狀態是新欄位，存檔格式要進版（目前 v14）。
- 舊存檔讀進來時，外交狀態要有**明確定義的預設**（不是未初始化記憶體）
- ⚠ **但預設值不可以是「看起來像有效資料」的東西**——
  「沒有外交關係」與「關係全部中性」是兩件不同的事，
  存檔要分得出來（這是 `0 與缺席看起來一樣但意義相反` 那條）
- 寫一個測試：讀一個 v14 舊存檔，確認外交狀態是「缺席」而非「全中性」

## 驗收

| 判準 | 怎麼量 |
|---|---|
| 初始狀態非空 | 附上述四類的實際數字 |
| 往返一致 | 正規化雜湊相同，**不是 byte 相等** |
| 有向性存活 | 往返後 `relation[A][B] != relation[B][A]` 仍成立，附兩組數字 |
| 冷載入 | 測試真的從檔案解碼，附證據（例如中間有 destroy／重建） |
| 舊版遷移 | v14 存檔讀進來是「缺席」不是「全中性」 |
| 決定性 | 同輸入同雜湊 |

**負向控制**：讓序列化**漏掉積怨這一個分量**（最慢、最不容易被注意到的那個）→
往返測試必須紅。⚠ 挑積怨是刻意的：**漏掉快變數會很快被別的測試抓到，
漏掉極慢變數可能幾十旬都看不出來**。把紅的數字寫出來。
