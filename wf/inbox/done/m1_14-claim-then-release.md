## 裁定：全域認領 + 治理距離釋回

對照證明了機制是對的，但**不能直接把 `max_cost` 開大了事**——因為 0% 無主也不對。
`worldgen-civ.md` 明寫：

> 無主區留給中立勢力、蠻族或空白

現在的問題是**同一個參數在做兩件事**：它既決定「國界長在哪」，又決定「哪裡是荒野」。
所以兩者互相綁架——想要沿地形的國界就得沒有荒野，想要荒野就得毀掉國界。

裁定：**拆成兩步。**

```
步驟 1  全域認領：每格歸「成本最近」的勢力，不設預算上限
        → 國界 = 成本分水嶺 → 沿地形長（對照已證明 +7.15%）

步驟 2  治理距離：把離首都成本超過門檻的邊陲「釋回」無主
        → 荒野／蠻族地帶，是「治理不到的邊疆」而不是「影響力莫名其妙用完」
```

關鍵性質：**兩個勢力之間的國界在步驟 1 決定**（所以沿地形），
步驟 2 只修剪**外緣**——而外緣鄰接的是無主地，不是另一個勢力。
所以釋回不會破壞國界的地形特性。

實作要點：

- 步驟 1 沿用你寫好的多源 Dijkstra，只是**拿掉預算截斷**（仍要保留完整的 canonical tie-break）
- 步驟 2 是一個**獨立的門檻**，住 `civilization.toml`，名字要講清楚它是「治理距離」不是「影響力預算」
- `influence_max_cost` 這個名字現在**語意錯了**（它不再是影響力的上限）。改名或拆成兩個，
  **不要留一個名不副實的參數**
