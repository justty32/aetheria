## M5 的真正判準，不是「Local 能生出來」

`outline.md` 對 M5 只寫了「Local 串流與探索」，太薄。設計文件自己給了更硬的判準——
[`lowmap.md`](../../design/lowmap.md) 末段與 [`localgen.md`](../../design/localgen.md)：

> **這是驗證抽象是否真的通用的地方。若 L2↔L3 需要新機制，
> 那表示 L1↔L2 的抽象抽錯了。**

所以 M5 是對前面四個里程碑的**回頭檢驗**。你這輪每要求加一個新機制，
都是在對那個抽象投反對票——**那不是壞事，我要你如實投**。但要說清楚是哪一條抽象不夠。

### ⚠ 這輪最大的陷阱：兩層的寬度剛好相同

`core/site/site_projection.h:17` — `kSiteWidth = 64`。而 Local 也是 64×64。

**這代表「真的複用同一份實作」與「複製一份改參數」會產生完全相同的測試結果。**
兩邊都會綠。這正是今天已經抓到三次的那種假通過：**測試沒有偵測力**。

所以複用性**不能用測試通過來證明**，要用結構證據。我要的負向控制是：

> **把共用的那份實作故意改壞（例如 `corner_id` 的雜湊改一個常數），
> 重跑全部測試 → Site 層與 Local 層的接邊測試必須「同時」變紅。**
> **只紅一邊，就證明它被複製了，不是被複用。**

這條請實際跑一次，把兩邊各紅了幾個測試寫進回報。跑完把改壞的還原。

## 這輪的範圍：只做「最便宜的那條路線」

`localgen.md` 三條路線裡，**路線 B（開放地表）**佔絕大多數 Local 且幾乎免費。
這輪**只做 B**，因為它足以撐起 M5.1 的串流，而 A（建築內外）是純工作量。

### 要做的

1. **`LocalTiles` 資料模型** — 照 `lowmap.md` 的欄位：
   `ground`／`overlay`／`occupant`／`edges`／`light`，每個 z 層一份。
   **牆與門是邊屬性**，沿用既有 `EdgeDef`，不要發明「牆佔一格」。
2. **`local_seed = splitmix64(site_seed ^ (y<<16|x))`** — 照 `localgen.md` 的輸入表。
3. **邊界剖面複用** — `canonical_edge_id`／`canonical_corner_id` 的公式不變，
   只是 `w = 64`、`region_seed → site_seed`。目前這套埋在
   `core/site/site_wilderness_boundary*.cpp`；**把它提到兩層都能用的位置**。
4. **路線 B 的四步**（B1 地形／B2 水與路／B3 散布／B4 零星物件）。
   單趟、無迭代。
5. **展開入口**：`Site tile → Local`，簽章比照 L1↔L2 那一套。
   ⚠ **`load` 與 `rematerialize` 必須是兩個不同入口**——這條在 L3 一樣成立。

### 不要做（這輪不碰，之後另發）

路線 A／C、垂直層、串流協調器、FOV／潛行、`peek_tile`／`peek_edge`、
`migrate_entity`、持久層疊加、歸約回 Site。**看到相關的坑就記下來寫進回報，不要順手做。**

## 驗收

| 判準 | 怎麼量 |
|---|---|
| **接邊一致性** | 同一組測試換一組參數（`w=64`、`site_seed`）。含**共用性負向控制**（上節） |
| **骨架只讀慢變數** | 用簽章擋，不靠自律——快變數不得出現在骨架函式的參數裡 |
| **生成預算 < 10 ms** | 見下方量測規約 |
| **決定性** | 同輸入同輸出；正規化雜湊，**不要用 byte 相等** |
| **牆可壓在 zone 邊界上** | `localgen.md` 明寫這是合法的。要有一個橫跨兩個 Local 的牆的測試 |

### 量測規約（沿用 M3.3 的裁定）

**所有效能斷言一律「暖機後取 N≥5 次的最小值」。** 單次牆鐘取樣會被 CPU 競爭汙染。
**禁止「重試到過為止」**——那是無界迴圈，同時破壞預算與決定論。

### ⚠ 每個量測都要同時吐出「路徑真的跑過」的證據

今天抓到三次假通過，**沒有一次是算錯**，三次都是**輸入讓待測程式碼根本沒執行**：
沒跑過的路徑耗時 0 ms、誤差 0，兩個數字都很漂亮。

所以 <10 ms 的回報要附**這趟實際做了什麼**的計數（生成了幾格、鋪了幾條路、散布幾個物件）。
計數為 0 的量測不算通過。
