## 關係是有向的

```
relation[A][B] ≠ relation[B][A]
```

勢力數是個位到十幾個，**存整個矩陣就好**，不必稀疏化、不必三角陣。

**負向控制**：把矩陣改成對稱（寫 `[A][B]` 時同步寫 `[B][A]`）→
「A 恨 B 而 B 對 A 無感」的測試必須紅。把紅的數值差寫出來。

## 四個分量，變化速度必須真的不同

| 分量 | 變化速度 | 說明 |
|---|---|---|
| **好感** | 快 | 近期行為的累積，會隨時間回歸中性 |
| **信任** | 慢 | 守約與背約的長期紀錄。**背約一次，數十旬才補得回來** |
| **恐懼** | 中 | 對方國力與軍事姿態的函數 |
| **積怨** | 極慢 | 戰爭、屠城、領土喪失留下的。幾乎不消退 |

⚠ **測試要斷言「關係」而不是「當下值」。**
M5.8 那輪我裁過同一件事：斷言 `A == 96` 這種硬值，
一改參數就假紅，而且證不了任何設計意圖。這裡要斷言的是：

```
同樣一次衝擊後，經過 K 旬：
  好感的回歸量 > 恐懼的回歸量 > 信任的回歸量 > 積怨的回歸量
```

四個速率**全部從資料檔讀**（新增 `data/diplomacy.toml`），一個都不准寫死。

**⚠ 一定要避開的假通過**：若四個分量的速率參數在資料檔裡碰巧設成一樣，
上面那條斷言會退化成 `0 > 0 > 0 > 0` 而恆假、或全等而恆真——
**回報要附四個實際回歸量的數字**，讓我能看出它們真的分開了。

## 條約與宣戰理由都是資料

- `TreatyDef`：停戰、和約、通行權、貿易協定、防禦同盟、附庸、聯姻
  - 每個帶：期限、條件、違約後果、可否續約
  - **加一種條約 = 加一筆資料，不改程式**。實測加一種並附證據。
- `CasusBelliDef`：領土主張、王位繼承、宗教、報復、解放附庸
  - 無理由開戰**可以**，但代價很重：所有第三方的信任大跌
  - 理由**會過期**——這是戰爭爆發的節奏來源，過期邏輯要實作

## 戰爭不是布林值

```
戰爭 = { 參戰方, 起因, 開戰時間, 戰果累計, 厭戰值 }
```

它是一個**持續事件**（[`events.md`](../../design/events.md)），不是一個旗標。

| 欄位 | 作用 |
|---|---|
| 戰果累計 | 佔領、會戰勝負、掠奪的加總，決定和談籌碼 |
| **厭戰值** | 隨時間與傷亡上升，壓低士氣與稅收，逼向和談 |

⚠ **厭戰值是戰爭會結束的原因。** 沒有它，世界很快只剩一兩個巨獸。
**驗收要測到這件事**：跑一場不會結束的戰爭 N 旬，厭戰值必須單調逼近和談門檻，
並寫出跨過門檻用了幾旬。**若答案是「永遠不會」或「三旬就到」，都是有問題的，如實回報。**

## 和談籌碼

```
和談籌碼 = f(戰果累計, 雙方厭戰值, 第三方壓力)
```

條件從籌碼推導：割地、賠款、附庸化、單純停戰。
⚠ **玩家與 AI 用同一條公式**，沒有隱藏勝率表——這條是策略遊戲公平感的來源，
所以這個函式必須是**公開的純函式**，不准藏在 AI 的私有實作裡。

## 情報不對稱：用型別擋，不用約定擋

設計文件指名了作法：

> AI 的評分函式**只准吃該勢力的知識視圖**，不准直接讀世界狀態。
> 用型別擋（`FactionView` 而非 `World&`）。

這輪你要建的是 `FactionView` 這個型別本身 + 從世界狀態產生它的函式。
**它必須在型別上不可能拿到別的勢力的真值**——不是靠註解、不是靠 code review。

我們在 M5.12 用過同一個手法（把 worldgen 拆成只帶特定 include 路徑的 OBJECT library，
編譯期擋住 `core/runtime/`）。**照那個做**：若 `FactionView` 能被繞過，就不算完成。

**負向控制**：寫一個「AI 直接讀真值」的 `compile_fail` 測試，
確認它**編不過**（`tests/compile_fail/` 已有既有機制，照既有慣例加）。

## 驗收

| 判準 | 怎麼量 |
|---|---|
| 有向 | 對稱化後測試紅，附數值差 |
| 四速率分開 | 附四個實際回歸量 |
| 條約是資料 | 加一種只改資料檔，附證據 |
| 宣戰理由會過期 | 附過期前後的可用性 |
| 厭戰值逼向和談 | 附跨過門檻用了幾旬 |
| 和談公式公開 | 玩家路徑與 AI 路徑呼叫**同一個函式**，附證據 |
| 情報隔離 | `compile_fail` 測試真的編不過，附錯誤訊息 |
| 決定性 | 同 seed 同結果；整數，**不准 `double`／`std::pow`** |
