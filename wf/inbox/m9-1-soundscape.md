## 這一輪要達到的一句話

**關掉 core 重開，音景完全一致**——因為音景不是被記住的，是被**重新算出來**的。

M9 的第一條判準是「關掉 core 重開，畫面與音景完全一致」。
它真正在測的是 `tech-stack.md` 的鐵律：**Godot 端不得持有玩法狀態**。
音訊最容易違反這條——「現在播到哪一段」很自然會被存在前端。

## 要做的

### 1. core 只吐 id，Godot 查表

`audio.md`：**core 不認識任何音檔**，只吐 `EventDefId`，Godot 端查表播放。
BGM／環境音／事件音三類由 core 事件驅動，**UI 音完全歸 Godot**。

### 2. 音景決策必須是 core 狀態的純函數

這是這輪的核心可驗證命題。要有一個**可傾印的音景決策狀態**：
駐留層、是否交戰、最高事件重要性、季節與時辰 → 決定
（BGM 層與編制、環境音組、各匯流排音量、交叉淡入的目標）。

⚠ **不准把「現在播到哪一段」當成決策輸入。** 播放位置是呈現層的細節，
一旦它回饋進決策，重開就不可能一致。

### 3. 分層混音 + 交叉淡入

匯流排：`Master / BGM / SFX / Ambient / UI / Voice`。
上提（Local→Site→Region）細節層淡出、寬景層淡入，下沉反向。**不准硬切。**

三層共用同一組動機（motif）：Region 全編制、Site 小編制、Local 單樂器。

⚠ **L3 的留白是刻意的**：地城幾乎無 BGM。`lowmap.md` 的潛行把「聲響」當一個維度，
BGM 蓋掉它等於廢掉那條玩法。**不要為了熱鬧給地城加 BGM。**

### 4. 缺檔行為

開發模式：播提示音 + console 警告並繼續。正式版：**拒絕啟動**。

## ⚠ 沒有真素材，這輪照樣要能全驗

真的 BGM／環境音／事件音都還不存在（`audio.md` 的量級是 20～40／30～50／150～300）。
所以：**用腳本確定性生成的佔位音**（純音、可辨識、檔名看得出是佔位）。
⚠ 不要自己生成「像樣的」音樂當成專案素材——那會被後面整批重生成推翻。
真素材與調性中心、LUFS 目標都是**待使用者**。

## 驗收（每一條都要在回報裡附數字）

| 項目 | 標準 |
|---|---|
| **關掉 core 重開音景一致** | 同一世界狀態，傾印音景決策 → **關掉 core、重開、重載** → 再傾印，**逐欄相同**，附兩次傾印 |
| **前端不持有狀態的反證** | 在 core 未載入時，音景決策必須**拿不到值**（不是拿到上一次的殘留），附輸出 |
| 三層各自不同 | 三層各傾印一次，附差異（L3 地城的 BGM 必須是無／極低） |
| 切層不硬切 | 附交叉淡入的目標值序列，證明有中間值 |
| 匯流排 | 六條都在，各自可調，附一次調整前後的值 |
| 缺檔 | 開發模式：提示音 + 警告文字；正式模式：**非 0 退出**，附兩者輸出 |
| Godot headless | 主場景 exit 0 |
| ctest | 全綠，附 N 與新增數 |
| 文件 | `find . -name '*.md' -size +8k` 為空 |

### 負向控制（一次只改一條，取得紅燈後還原）

| # | 注入 | 必須紅 |
|---|---|---|
| 1 | 把「當前 BGM 段」存進 Godot 端並回饋進決策 | 重開一致性那條 |
| 2 | 切層改成硬切 | 交叉淡入的中間值那條 |
| 3 | 給地城加 BGM | L3 留白那條 |

⚠ **無效注入不算通過**：若某條注入下來全綠，**如實寫進回報說這條測不到**。

⚠ **「空的層必然通過」**：若某一層的音景決策其實全是預設值，那條比對等於沒測。
回報要附各層**非預設欄位的數量**。

## 不要做的事

| 不要 | 理由 |
|---|---|
| 做語音 | `audio.md` 明定初版不做全語音 |
| 碰 mark／獨特物件的動機提示 | mark 擱置中，要做之前先問使用者 |
| 定案調性中心／LUFS 目標 | 待使用者 |
| 讓 core 認識音檔路徑 | 違反 `audio.md` 與 tech-stack 鐵律 |
| 動 `kSaveFormatVersion` | 音景是純函數，不該進存檔 |
| push | 一律要使用者點頭 |
| fan-out 自我審查子 agent | 禁止 |
