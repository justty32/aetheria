## 為什麼這輪必須做

M6.7 的回報寫著：

> 現有 main 尚無 Site 方陣／Local 逐單位戰鬥迴圈……
> 本輪落地的是 **Region 權威配額 + 下層高方差展開 + 有界個人偏離**。
> 它提供未來真戰鬥器的校準契約與 CI，**不冒充尚未存在的戰技模擬**。

⚠ **它說得對，而且它用 `.ask` 通道當場講了，沒有藏到回報最後。**
但後果是：**三層校準目前是「Region 對 Region 加雜訊」**，
`E[Site] ≈ E[Region]` 恆真，因為 Site 根本就是 Region 算的。

**這輪把真的 Site 層做出來，M6.7 的校準才有東西可校。**

## ⚠ 我自己注入時量到的第二件事

M6.7 的期望一致測試唯一的守門是 `|error| < 5%`。
我注入 **Site 系統性 +3%** → **測試全綠**；注入 +10% → 才紅
（signed errors `+0.0999 / −0.0909`）。

但 M6.7 任務書明寫過：**誤差若系統性同向就是可刷的漏洞，不管它多小。**
它回報了正負號卻**沒有為正負號寫斷言**。

**這輪要補上**：除了 `|error| < 5%`，再加一條
**「三組比對的正負號不得全部同向」**的斷言，並附實測。
⚠ 有了真的 Site 模擬之後這條才有意義——現在恆為 0 是構造出來的。

## Site 層戰鬥要有什麼

Site 的一回合平時 1 小時、**交戰時 15 分鐘**（`outline.md` 已定）。
15 分鐘是推演出來的：一小時的回合裡保持陣型的部隊能走 12 格，
一兩回合就穿過整個戰場，**機動完全失去意義**。

| 要素 | 說明 |
|---|---|
| **方陣** | 部隊是 cohort，不是個體。有陣型、朝向、正面／側背 |
| **地形站位** | 丘陵、渡口、城牆後的加成走既有 `terrain` 修正 |
| **兵種相剋** | ⚠ **只在 Site 層有意義**（設計已裁定），且**必須帶條件** |
| **具名指揮官** | 屬性進 M6.3 的 `command` 修正 |

### ⚠ 相剋必須帶條件，不能是無條件的石頭剪刀布

| 剋制 | 條件 |
|---|---|
| 長槍 → 騎兵 | **正面接敵且陣型完整** |
| 騎兵 → 弓手 | **側背接敵** |
| 弓手 → 長槍 | **保持距離** |
| 攻城器械 → 城牆 | **靜止且有掩護** |

> **條件是重點。無條件的石頭剪刀布會讓戰術退化成查表；
> 帶條件的相剋逼玩家去創造那個條件，那才是戰術。**

**驗收**：每一組相剋都要有**條件成立**與**條件不成立**兩組數字，
且兩者必須有明顯差距。⚠ **若條件不成立時仍有剋制加成，那就是無條件相剋**，如實回報。

## 與 Region 的關係：Region 仍是權威

⚠ **不要讓 Site 變成新的基準。** 校準順序固定：Region 是基準，Site 追它。

- Site 模擬完一場戰役後，**歸約回 Region 的等效戰力損失**
- 走既有歸約通道（`interface-world-mid.md`），**不要另開寫入路徑**
- ⚠ **不算兩次**：主場在 Site 時，Region 面孔的損傷寫入次數必須 = 0
  （M6.7 已有這條測試，**確認它在真 Site 模擬下仍然成立**）

## 驗收

| 判準 | 怎麼量 |
|---|---|
| 15 分鐘 stride | 一回合的移動格數，證明機動有意義（附格數） |
| 相剋帶條件 | 四組各附「條件成立／不成立」兩個數字 |
| 期望值追上 Region | 同情境 N=1000，`E[Site]` vs `E[Region]` 相對誤差 <5% |
| ⚠ **正負號不得全同向** | 附三組比對的正負號 |
| 方差比 Region 大 | 附兩個方差 |
| 不算兩次 | `region_face_damage_writes == 0` |
| 歸約走既有通道 | 附歸約寫入計數 |
| 決定性 | 同 seed 同結果 |
| 效能 | 一場 Site 戰役的耗時，**暖機後 N≥5 取最小** |

### ⚠ 假通過

1. **拿懸殊戰力測期望一致**——結果都是完勝，三層當然一致。
   **取樣要涵蓋勢均力敵區間**，附 `R` 分布（M6.7 的做法可以照抄）。
2. **相剋條件若從沒不成立過**，那組數字證明不了帶條件。附條件不成立的樣本數。
3. ⚠ **若你為了讓誤差 <5% 而去調 Region 的參數，那是把基準搬走了。**
   Region 這輪**不准改**，如實回報你調了什麼。
