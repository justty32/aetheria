## 你 M5.4 讀到的那條是重點

> `~/repo/moddings/rimworld/.../BiomeWorker_*.cs`：
> **不是 first-match，是每個 biome 算分數、取最高分。**

**first-match 是今天三次事故的共同結構**：

| | 症狀 |
|---|---|
| M1 地形 | 單一有序列表，`沙漠+平原` 先命中，吃掉 97% 陸地並抹平所有 relief |
| M5.4 tundra | `temperature<=20` 三個 seed 全 0% 命中 |
| M5.4 swamp | `elevation<=4500` 兩個 seed 0% 命中 |

後兩者**沒有任何測試變紅**，是靠畫圖 + 直方圖才看見的。

## 三件事

### ① 計分競爭取代 first-match

每個 biome 給一個分數（依 temperature／moisture／elevation 的距離或隸屬度），取最高分。
好處是**交界會自然形成過渡**，而不是硬邊 —— 你自己也看出「白色凍原直接貼著綠、沒有過渡」。

⚠ **決定性優先於一切**：同分時要有穩定的 tie-break（依 def 下標，不要依 map 迭代順序）。
⚠ 不准引入浮點不決定性；若用浮點，比較要有明確 epsilon 與固定順序。

### ② 死規則要大聲失敗（**這條最重要**）

> **裁定：命中率為 0 的分類規則等於不存在，而「不存在」必須是紅的，不是靜默的。**

加一個回歸測試：固定的參考 seed 集合上，**每個 biome def 的命中率都必須 > 0**，
否則測試失敗並指名是哪一條。

理由：門檻落在分布之外這件事發生了三次，三次都零測試變紅。
**這是本專案至今最會重犯的錯誤**，要有結構性的攔截，不能靠每次都記得畫圖。

### ③ 補生態帶內容

目前只有 4 種陸地 TerrainId（含 ocean 共 5），所以「至少 5 種各佔 >3%」在不加內容時
**不可能達成** —— 你 M5.4 指出這點是對的。

> **裁定：加。** 至少補 taiga／boreal（高緯 100% tundra 太單一）與一個乾濕之間的過渡帶。

⚠ **`RulesetLoader` 那個「固定地形數量」的測試是錯的，改掉它。**
它把「剛好有 N 種地形」寫死，**直接違反本專案「種類一律不寫死成 enum」的鐵律**
（見 [definitions.md](../../design/definitions.md)）。你 M5.4 撤回 taiga 是對的紀律，
但擋住你的是那個測試，不是 taiga。測試要改成驗**性質**（每種都載入成功、id 不重複），
不是驗數量。

⚠ 勢力邊界校準會跟著變，那是預期的。若數字動了，**報數字給我裁定，不要為了讓測試綠而回頭改地形**。

## 驗收

| 判準 | 怎麼量 |
|---|---|
| 死規則攔截 | **故意把一條門檻改到分布外，新測試必須紅並指名那條**（負向控制，要真的紅） |
| 直方圖 | 最大陸地類型 < 50%；至少 5 種陸地各 > 3%（三個 seed） |
| 交界過渡 | 改前／改後同 seed 對照圖，硬邊要看得出變少 |
| 高緯 | 不再是 100% 單一地形 |
| 決定性 | 同 seed 同正規化雜湊，連跑兩次 |

**以圖為準。指標好看而圖難看是失敗。**
