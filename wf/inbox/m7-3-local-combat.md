## 這輪之後，M6.7 的三層校準才是真的

M6.7 落地的是「Region 加零均值雜訊」冒充三層；M7.2 做了真的 Site。
**這輪做真的 Local，然後那條 `E[Region] ≈ E[Site] ≈ E[Local]` 才有意義。**

⚠ **校準順序不可顛倒**：Region 是基準 → Site 追 Region → **Local 追 Site**。
Region 與 Site 的參數這輪**都不准改**。若你發現非改不可，如實回報，不要偷偷改。

## Local 層長什麼樣

| | |
|---|---|
| 回合 | **6 秒**（戰鬥 stride；DnD 的 round，「一個人做一個動作」的自然尺度） |
| 戰場 | 該 Local 的 64×64，一格約 2 m |
| 單位 | 個別士兵、玩家角色 |
| 一回合移動 | 約 **5 格**（10 m） |

**視野、移動、尋路 M5 已經做好了**（`local_fov`、`local_movement`、`local_path`）——
⚠ **用既有的，不要重寫**。檢定用 M6.1 的 d100，**不要另立擲骰**。

## ⚠ 敵人從哪個邊緣進來，由 Site 層決定

> Site 說部隊 B 在戰場東側 → Local 的邊界條件就是「敵方單位從東邊緣進入」。
>
> **上層永遠負責給下層邊界條件。** 空間上這叫 `BoundaryProfile`，
> 因果上就是事件投放點。**同一條原則。**

**負向控制**：讓 Local 自己決定入口邊緣 → 「上層給邊界條件」的測試必須紅。
附紅的是什麼。⚠ 這條是八條原則裡「同層不直接溝通、權威在高層」的直接落地，
弄錯了整個抽象就破了。

## δ：玩家能偏離統計多少

```
最終結果 = 統計期望值 + clamp( 個人貢獻 , −δ , +δ )
```

M6.7 已經把 δ 做好了（五級、配額守恆），**這輪用既有的，不要重做**。
但要證明它在**真的逐單位戰鬥**裡仍然成立：

- `World` 級劍聖可隻身破陣
- **同樣數值的無名士兵不行**——這是機制，不只是數值

⚠ **驗收**：附「同樣屬性、只有 significance 不同」的兩個個體，
在同一場戰鬥裡的最終影響。**兩個數字都要。**

## ⚠ 撤退、追擊、潰散：三層都要表達得出來

> 否則會出現「**在下層逃掉了，上層卻顯示被殲滅**」。

| 事件 | Local | Site | Region |
|---|---|---|---|
| 撤退 | 玩家往地圖邊緣跑 | 方陣脫離接觸 | 部隊移到鄰格，交戰結束 |
| 追擊 | 敵單位緊咬不放 | 勝方追擊，撤退方持續掉人 | 撤退時額外損傷 |
| 潰散 | 周圍友軍四散奔逃 | 方陣解體，士氣歸零 | 部隊消失，殘兵併入最近友軍 |

**驗收**：在 Local 撤退成功後，**Region 層必須看到「撤退」而不是「殲滅」**。
附兩層的實際狀態。⚠ 這條是本輪最容易漏、後果最明顯的一條。

**潰散的殘兵是一個 Cohort**，可能變成流民團或盜匪——
接上「聚合提升重要性」：一支潰散的軍隊會變成大地圖上的一個新問題。
⚠ 但**不要跟戰鬥位階混淆**（`power-tiers.md` 末段點名的混淆點）：
提升的是「被個別計算的資格」，不是戰鬥位階。

## 士氣是三層共用的量

Local 的個體事件（**指揮官陣亡、旗幟被奪**）向上聚合成 Site 的方陣士氣，
再聚合成 Region 的部隊士氣。

**驗收**：在 Local 殺掉指揮官，Site 的方陣士氣與 Region 的部隊士氣**都要動**，
附三層的前後數字。⚠ 若只有 Local 動，那三層士氣就不是同一個量。

## 驗收

| 判準 | 怎麼量 |
|---|---|
| 6 秒 stride | 一回合移動約 5 格，附實測 |
| 復用 M5 的 FOV／移動／尋路 | 改壞其中一個，Local 戰鬥要跟著紅 |
| 邊界條件由上層給 | 負向控制紅了 |
| δ 真的分級 | 同屬性不同 significance 的兩個數字 |
| 撤退不變殲滅 | Local 撤退後 Region 的狀態 |
| 士氣三層連動 | 三層前後數字 |
| **期望值追上 Site** | N=1000，`E[Local]` vs `E[Site]` 相對誤差 <5% |
| ⚠ **正負號不得全同向** | 附三組比對的正負號 |
| 方差比 Site 大 | 附兩個方差 |
| 決定性 | 同 seed 同結果 |
| 效能 | 逐回合 < 2 ms，**暖機後 N≥5 取最小** |

### ⚠ 假通過

1. **懸殊戰力**——三層當然一致。取樣要涵蓋勢均力敵區間，附 `R` 分布。
2. **`Ambient` 的 δ=0 恆真**——要證的是**非零等級真的偏離了**。
3. **「復用 M5」若只是 include 了標頭**，證明不了復用。
   **要能改壞 M5 的碼讓這輪的測試紅**（M5 的 `64 == 64` 教訓）。
