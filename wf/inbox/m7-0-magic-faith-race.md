## M7 的判準跟 M6 不一樣

M6 之前問「機制成不成立」，M7 開始問「**玩起來對不對**」。這輪的判準是：

> **三條位階來源在同一場戰鬥裡可比，且各自有不可替代的用法。**

⚠ **若魔法只是「另一種傷害型別」，那它就不該是獨立系統。**
所以驗收不是「法術能施放」，是**證明三者不可互相取代**——見下。

## 共同形狀：三者是同一個接法

```
提供 tier 加成 + 特殊能力 + 屬性修正 + 可被剝奪的條件
```

差別只在**取得與失去的方式**：

| 來源 | 怎麼得到 | 怎麼失去 |
|---|---|---|
| 魔法 | 學習、研究、傳承 | 失去媒介、精神受創 |
| 信仰 | 神祇眷顧 | ⚠ **被剝奪**（違背教義、神祇隕落） |
| 血統 | 出生 | 幾乎不會 |

⚠ **共用接法要是真的共用**：三者若各寫一套 tier 加成邏輯，就是複製不是設計。
**負向控制：改壞那個共用接法，三條來源的測試要同時紅。**
（這條 M5 用過：`64 == 64` 的巧合讓複製與複用測起來一樣，只有結構性證據算數。）

## 魔法

- `SchoolDef`（資料）：元素、召喚、幻術、死靈、變化、預言
- 施法：`消耗魔力 → 心 vs 法術難度檢定 → 效果`，走 M6.1 的 d100，**不要另立擲骰**
- ⚠ **失敗必須有代價**（反噬、魔力浪費、暴走），否則法師會無限重試。
  驗收：附「無代價時的最佳策略是無限重試」的量化證據（例如期望收益隨嘗試次數單調上升）

### ⚠ 三層都要有表現，這是最容易漏的一點

**只做 Local 層的法術，魔法在戰略上就不存在。**

| 層 | 魔法長什麼樣 | 接到哪 |
|---|---|---|
| L1 | 戰略魔法：改天氣、降瘟疫、傳送軍隊、詛咒土地 | 改 Region 快變數，或成為 M6.3 戰鬥公式的修正項 |
| L2 | 戰術魔法：範圍傷害、增益、召喚、破城 | 方陣修正項與陣型 |
| L3 | 個體法術：逐次檢定 | M6.1 |

⚠ **戰略魔法必須貴且慢**（耗時數旬、需要儀式、多名施法者）。
它應該是「一場戰役的轉折點」，**不是每旬按一次的按鈕**。
驗收：附戰略魔法的實際成本與冷卻，以及「每旬都放」在資源上為何不可行的數字。

**魔素**是 Region 資源，分布不均是刻意的——這讓魔法接上 4X 的資源競爭。

## 信仰

- `DeityDef`：神格、領域、教義、敵對神祇。神祇是 **`World` 級實體，住在 root zone**
- 教義是 `TenetDef`，**可以互相衝突**——同時侍奉戰神與和平之神要有代價
- ⚠ **違背教義 → 剝奪，位階立刻下降**。「一個聖騎士可以在一夜之間掉兩階」
- ⚠ **神祇會死**。隕落是 `World` 級事件，**所有信徒同時掉階**

**驗收**：神祇隕落後，所有信徒的 tier 真的同時下降，附受影響人數與掉階幅度。
⚠ 這條要跟 M6.4 的**配額守恆**對得上——大量掉階會改變等效戰力，
若它讓 Region 的統計層與個體層出現兩個真相，如實回報。

⚠ **神祇不直接干預世界**，只透過信徒與事件作用（神在 root，世界在 zone，中間要有中介）。
**負向控制**：讓神祇直接寫 Region 狀態 → 中介測試要紅。

## 種族

`RaceDef` 影響三件事：屬性基礎值、**位階上限**、壽命。

⚠ **位階上限是種族最重要的欄位**（血統影響上限而非起點）：

| 種族類 | 上限 |
|---|---|
| 大多數人族 | `Region`（3 英傑）|
| 精英血統、龍裔、半神 | `World`（4 傳奇）|
| 普通獸群 | `Local`（1 精銳）|

**這條讓「為什麼傳奇這麼稀少」有機制上的答案**，不靠數值硬壓。
驗收：把一個上限 `Local` 的個體用盡一切手段推高，**它就是上不了 `Site`**，附證據。

長壽種族**平均位階較高，但上限不必然更高**——
人類天才可在四十年內達到精靈四百年的高度。驗收要能表達這句話。

## ⚠ 反面清單：以下刻意不做

| 不做 | 理由 |
|---|---|
| 職業系統 | 四屬性 + 三種來源已天然產生原型 |
| 經驗值與等級 | 位階是身分的改變，不是經驗條 |
| 法術書與記憶術式（Vancian） | 與三層縮放不合 |
| 魔法與科技的對立軸 | 本作沒有科技革命 |

## 驗收：三者不可互相取代

⚠ **這是本輪的核心判準，其餘都是前提。**

設計一組情境，證明**每一條來源都有另外兩條做不到的事**，各附一個實測：

- 魔法能做而信仰／血統不能的
- 信仰能做而魔法／血統不能的（**「可被剝奪」本身就是一種戲**）
- 血統能做而魔法／信仰不能的（**位階上限**）

若你發現其中一條**其實可以被另一條取代**，那就是設計問題——
⚠ **如實回報，不要硬湊一個情境糊過去。** 這比做完更有價值。

## 不要做的事

| 不要 | 理由 |
|---|---|
| 另立擲骰 | 用 M6.1 的 d100 |
| 另立 tier 加成邏輯 | 三者共用同一個接法 |
| 寫具體的神祇／學派／種族內容 | 那是使用者的內容決策；你只出資料檔的第一版骨架 |
| 為了讓情境成立而反覆試值 | 試了幾個值也如實寫進回信 |
| 改 `design/` | 有設計異議寫進回報，我裁定 |
