## M8.1 打通了一條路，但只有一條

M8.1 做到的是：開局 → 選軍 → 移動 → 推旬 → 遭遇 → 二選一 → 戰報 → 世界改變。
**那是一條垂直切片，不是整個迴圈。**

core 裡還有一大批東西**從遊戲裡碰不到**：

| 已在 core | 能不能玩到 |
|---|---|
| 城建循環（M3） | ❌ |
| 進 Site 看城區／荒野（M2） | ❌ |
| 進 Local 探索、FOV、開門（M5） | ❌ |
| 地城：深度、機關、Boss（M7.1） | ❌ |
| 湧現任務（M6.6） | ❌ 只看得到事件文字 |
| 外交與條約（M6.2） | ❌ |

**這輪把它們接上。** 一樣不做美術，沿用 M8.1 的簡陋 UI 風格。

## 範圍：三層都要進得去，且回得來

```
Region 地圖 → 點一格 → 進 Site（城區或荒野）
Site → 點一格 → 進 Local
Local → 找到地城入口 → 下負 z 層
每一層都能退回上一層，且世界狀態不漂移
```

⚠ **「進得去」不等於「接通了」。** 驗收要證明**下層的改變會回到上層**：

| 在哪做 | 上層要看到 |
|---|---|
| 城建蓋一棟建築 | Region 的建設等級變 |
| Local 清剿盜匪 | Region 的治安變（M6.6b 的第五列） |
| 地城清空 | `cleared` 進持久層，重進密度降 |
| 接一個湧現任務並完成 | 該需求真的消失 |

**每一條都要附前後數字。**

## ⚠ 進出三層最容易壞的地方

1. **`load` ≠ `rematerialize`**（M4 的裁定）：從 UI 進一個卸載過的 Site，
   走的必須是 `ZoneManager::acquire`，不是 `load`。
   **負向控制**：讓它退化成 load-only，確認 `tile_count == 0` 的斷言變紅。
2. **來回三次不漂移**（M2 的判準）：同一格 Site 進出三次，
   **正規化世界雜湊必須相同**。附三次的雜湊值。
3. **Godot 端不准持有玩法狀態**：每一層都要能 free 後從 core 重建。
   M8.1 做過一次，**這輪對每一層各做一次**。

## ⚠ 順手修掉一個「測試綠燈但東西是壞的」

M8-INT-6 實測到：按下「free 後重建」時 Godot 警告
`Object ... was freed or unreferenced while a signal is being emitted from it`。

根因是 `_view.free()` **從那個按鈕自己的 signal handler 裡呼叫**，
等於在物件正在發 signal 的當下把它砍掉。這次只是警告 + 進程存活，**但那是運氣**——
同一個形狀在別的節點樹深度或別的 Godot 版本就是 use-after-free。

⚠ **它不會有任何測試變紅**：重建後逐像素相同（實測 ImageMagick AE=0），功能面完全正確。

**改成 `queue_free()` 或 `call_deferred("free")`**，讓釋放發生在 signal 發完之後。
驗收：重建仍然逐像素相同，**且 Godot 輸出裡沒有那行警告**。附兩者的證據。

## 玩家駐留層

[`player-residence.md`](../../design/player-residence.md) 的核心：
**玩家選擇要親自做多少**，其餘交給同一套系統。

所以每一層的入口都要有「親自去」與「交給系統」兩個選項，
⚠ 而且**兩者的期望結果必須一致**（M6.7／M7.2／M7.3 已經校準過戰鬥那條，
這輪要確認城建與探索也不會因為「親自做比較賺」而逼玩家微操）。

**驗收**：挑一個非戰鬥的活動（例如一旬的城建產出），
量出「親自操作」與「交給系統」各 N=100 的期望值，相對誤差 <5%，**並附正負號**。
⚠ 若「親自做」系統性比較好，那就是逼玩家微操的設計錯誤，如實回報。

## 驗收

| 判準 | 怎麼量 |
|---|---|
| 三層都進得去、回得來 | 操作腳本 + 每層一張截圖 |
| 下層改變回到上層 | 上表四條各附前後數字 |
| `acquire` 不是 `load` | 負向控制紅了 |
| 來回三次不漂移 | 三個雜湊值 |
| 每層都能 free 後重建 | 三次比對 |
| 親自 vs 系統期望一致 | N=100 的誤差**與正負號** |
| 全套綠 | `ctest` 數字 |

⚠ **操作腳本一樣是最重要的產出**（M8 的判準是「只用滑鼠鍵盤」）。
沒有腳本與截圖就是沒做完。
