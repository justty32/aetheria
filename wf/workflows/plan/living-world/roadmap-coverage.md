## 原有需求不能在重排時消失

這張表追蹤需求去向，不表示目前已完成。未來的 R 輪次見總覽，M 編號保留作歷史追溯。

| 原有需求 | 新規劃歸屬 | 必須保留的驗收 |
|---|---|---|
| M0 純核心／Godot 分工 | 模擬契約、呈現；貫穿所有輪次 | 核心可獨立運行；畫面只查詢與轉發命令 |
| M1 世界、移動、回合、存檔 | 世界環境、旅行、內容；R0／R1 | 地圖可達、持續行軍、時間推進、讀檔接續 |
| M2／M4 展開收回、離場補算 | 模擬契約；R0／R4 | 身分與配額一致，不重算，近似誤差有界且無偏 |
| M3 城建與中層 | 經濟、生活、戰爭；R2 | 中層配置影響產出與防禦，小層工作扣同一份帳 |
| M5 Local 串流探索 | 旅行、生活；R3／R4 | 地圖接邊、視野、門、地下層、持久改動與離场接續 |
| M6／M7 戰鬥、AI、力量、地城 | 戰爭、AI、力量、旅行；R1～R4 | 在正式遊玩中可用；魔法／信仰／種族有不同作用 |
| M8 可操作迴圈 | 呈現；每輪 | 遊戲畫面上能下命令並看到世界後果 |
| M9 主線、美術、音景 | 故事、呈現；R5／R6 | 一條主線走完；重建畫面與音景；同歷史續玩一致 |
| M10.0～3a 存檔、角色與歷史 | 內容、模擬契約；R0 | 重用已存在模組；補多角色與拒絕命令等已知語意缺口 |
| M10.3b 全 def 追加 | 內容；R1 起，R5 完整收束 | 不移動既有 ID、先整批驗證、回合尾生效，全類型有使用端 |
| M10.4 新勢力 | 政治、AI、內容；R1 | 土地、外交、查詢與世界歷史一起成立，首例仍是開拓 |
| M10.5 兵種／建築／AI 資料化 | 內容＋對應系統；R1～R3 | 新種類不是新增硬編碼分支；載入與實際行為都驗 |
| M10.6 人物／文明文化／物品 | 人物、政治、力量、內容；R1～R3 | 真正的世界實體與引用；原有人物與物品不因追加失效 |
| M10.7 外部檔案入口 | 內容；R1 起 | 可在進行中的世界加入，錯誤有原因且不半套用 |
| M10.8 全鏈驗收 | 內容；R5 | 全 def 矩陣、新勢力／具名人物／物品、改全域資料不壞舊檔、雙角色不干擾、存讀重放一致 |
| M11 劇情注入方向 | 故事、內容；R5 | 劇情也是舊世界可加入的內容；腳本狀態與效果可保存及重放 |
| 分裂／成長型新勢力 | 政治、人物、內容；R3 後整合 | 接人物與制度條件；不以新增開拓勢力冒充全部來源 |
| mark／獨特物件、root 成長軸 | 框架、人物、故事、模擬契約 | 可規劃用途；先前實作擱置沒有在本次被偷偷解除 |

M10 的原始範圍以 [既有總覽](../runtime-injection.md) 與 [裁定](../runtime-injection-decisions.md) 為準。版本號由實際整合決定，不因為重排就先改存檔格式。整個 M10 是一份完整承諾，先做一類內容不等於完成。

## 願景如何落到系統

| 使用者要的世界感 | 規劃中的具體支撐 |
|---|---|
| 能走進去生活的奇幻世界 | 人物、生活、旅行、力量、呈現；場所能互動、人物有經歷、規則有代價 |
| 能帶隊介入大勢 | 大局 AI、戰爭、政治、三層駐留；上層軍隊就是下層的參與者 |
| 文明會經營、競爭與興衰 | 經濟、政治、知識、地理、生態、外交；每條發展都有資源與制度條件 |
| 細節能自然產生故事 | 生活、人物、歷史；工作、傷病、關係、地方改動形成長期因果 |
| 世界可持續加入新內容 | 內容、模擬契約；文明、人物、物品、地方、劇情進同一歷史 |
| 粗到細都保持同一世界 | 時間、身分、配額與事件主場；每個系統都明列三層分工 |

## 不直接採納的原作做法

不是刪掉玩法，而是避免移植時破壞本案的三層結構：不把 Endless 的省份當 Region；不直接搬 VCMI 七槽或 Wesnoth 六角；不讓 RimWorld 的全圖即時 tick 取代回合；不因 Elin 早期分析寫了某 API 就當它已複驗；不拿 LDE3 或 ToME Erebus 的推測當現成架構；不讓 CK2 的頭銜模型取消本案獨立勢力身分。

可改的政策保留方案與理由。例如中層出手順序、繼承方式、工作預約、遠方精度、法術副作用都能大膽設計；已定的三層邊界與存檔承諾不能靠換詞省掉。
