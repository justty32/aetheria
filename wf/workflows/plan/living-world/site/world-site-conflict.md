# 中層細則：同一地方的平戰轉換

[本層入口](README.md)｜← [戰爭](../systems/world-systems-war.md)｜[地方運作](world-site-operations.md)｜[原則](../../../../../design/principles.md)｜[術語](../../../../../design/glossary.md)

## 方案與完成判準

城鎮不在開戰時換成另一張乾淨戰場。原有道路、工事、居民、庫存、工作與產權繼續存在，戰事改變它們的可用性。依 [原案](../../../../../design/simulation/combat-scaling.md) 展開；以下為規劃建議，不開始實作。

**Done when：**預警、動員、圍城、交戰、停戰、占領與恢復可在同一地方連續推演；每次轉變交代觸發、寫入者、工作處置、時間與三層結果。不是把列出的全部政策當成已裁定數值。

## 不用單一「戰爭模式」控制一切

分開四種狀態：安全威脅、通路／封鎖、政治控制、各區實際交戰。城市可能已被包圍但工坊仍運轉，也可能外交尚未宣戰就出現突襲；城門失守不等於全城已歸順。

| 轉變 | 觸發與授權 | 地方實際改變 |
|---|---|---|
| 日常→警戒 | 收到可信警報；行政／軍事權限核准措施 | 巡邏、關門、盤點糧食、準備避難；不直接停全城 |
| 警戒→動員 | 有合法徵募／徵用命令 | 勞工轉為民兵、物資轉保管、私人財產記補償或侵害 |
| 通行→圍困 | 敵軍實際控制道路、渡口與出口 | 外運延遲、偷渡風險、缺糧與救援需求；不是一鍵全封 |
| 局部→交戰 | 交戰事件在此生效 | 受威脅區改工作安排；時距按既有戰鬥 stride |
| 交戰→脫離／停火 | 接觸解除或停火條件成立 | 停攻不自動修城、補兵、治傷或恢復貿易 |
| 控制爭奪→占領 | 戰果與政治條件通過領域驗證 | 管理權、駐軍、法律與對外關係變更，保留民間資產爭議 |
| 危機→恢復 | 威脅、通路與服務逐步改善 | 清障、安葬、救治、返鄉與重建，各有工作與成本 |

政治控制由政治規則改動，戰鬥只提供證據。原案破城的即時後果在共同合法提交點通知，不能拖到旬末；與回合尾端的結構變更分開，不借此任意重設事件與實體。

## 開戰時每項活動怎麼辦

| 活動 | 建議處置 | 不能發生的事 |
|---|---|---|
| 農作、採礦 | 安全區繼續，危險區暫停或撤離 | 全城工人瞬間消失／瞬移入城 |
| 工坊、施工 | 檢查人力、材料與道路；可改軍需但需換線成本 | 民用品在製品直接變成武器 |
| 運輸、交易 | 已在途貨物等待、改道、退回或被奪 | 封鎖後仍從全球池直接到貨 |
| 消防、醫療、供水 | 依可達性與安全排序，必要時配護衛 | 因交戰就把火災與疾病暫停 |
| 教育、祭儀、娛樂 | 依政策停辦、縮減或支援安定 | 取消就返還所有已耗時間 |
| 警備、疏散 | 調度可用人員、出口、載具與收容容量 | 同一居民同時當民兵和被疏散人口 |

各區安全度與指令影響工作優先序，不另造一套戰時工作引擎。平時步長切成交戰步長後，所有生產、消耗、治療與疲勞按秒時距換算，不能因回合變多就加速生產。

## 圍城與城市內部

包圍的有效性取決於兵力、路網、地形、監視與運能。缺口可供突圍或走私，但有時間、容量與風險；空運、地下路與傳送若存在，也須有明確通道和代價，不能套普通封鎖直接無視。

圍城期間可以修築工事、挖掘、斷水、談判、交換俘虜、救援與突圍。攻方也要吃糧與承受疾病。城內糧食不是平均扣減：公共配給、私人囤積、徵用與黑市受法律及執行能力影響，會留下關係與政治後果。

突襲和起火未必升成全城會戰。由事件影響範圍與既有 observer 機制決定詳算範圍，沒有新增「戰爭專用 LOD 開關」。

## 玩家親自下場

Site 守住北門的命令可展開為 Local 修門、救工匠、拆器械或護送居民。領出的兵力、材料、門的受損狀態都有來源；其他街區繼續按交出的範圍以外粗算。

門修好只改那一道門與可用通路，不直接宣告圍城結束；燒糧只扣實際燒掉的庫存，不另外施加一筆無來源糧食懲罰。若進一步影響士氣／談判，由所屬規則讀取已確認事實。

玩家離場後，救火、攻門與撤離仍可完成或失敗。重新進入不能復活死者、重生戰利品、刷新彈藥或把火勢重抽。

## 戰後不是重置

逐項交代死者、傷者、俘虜、失蹤者、逃兵與難民；轉移人群要有來源與目的地。廢墟保留原資產與損毀差量，搜刮需實際庫存及所有權後果；重建從清障、材料、工時與安全開始。

占領軍可徵用倉庫，但國家控制權、建築所有權、貨物保管和人物效忠不是同一欄。地方可以表面服從、行政癱瘓、居民外逃；復產與政治穩定分開衡量。停戰後運輸恢復仍取決於道路、條約與安全。

## 保存與驗收

持久資料包含封鎖通路、控制與爭議、損毀、火災／工程進度、未完工作、資源預約、人口去向、已確認戰果及生效時間。依 [共同契約](../world-simulation-contracts.md) 移交，戰場場景銷毀不刪這些後果。

完整案例：港城收到敵情 → 民兵抽走碼頭工人，卸貨變慢 → 敵軍封橋，商隊等待 → 北門開戰，麵包坊仍供安全區 → 玩家救工匠並修門 → 援軍逼退敵人 → 救治、返鄉、補償與復產。粗算與詳算比較相同條件下的成本及後果，不只比較勝敗。

反例必查：警戒反覆切換不刷新預約；停火不自動釋放所有俘虜；跨旬不雙扣口糧；玩家滯留屋內時外牆仍可能失守；存讀後重送同一戰果不再改控制權。
