# 中層細則：一個地方如何生活與運轉

## 方案與邊界

中層是地方配置與組織調度，不只是等待戰鬥的畫面。沿用 [原案城建](../../../../../design/maps/midmap.md)；以下是規劃建議，未新增實作授權。尺度與步長只引用 [大綱](../../../../../design/outline.md)。

**Done when：**同一聚落的需求能形成工作、取得物資與人力、交付服務，遭遇短缺或戰事後有可追查的替代結果；三層、離場與存讀不重算。數值表與完整建築內容庫不在本輪。

## 地方不只一種

| 地方 | 平時主要活動 | 與世界的實際連結 |
|---|---|---|
| 城市／村鎮 | 住宅、農業、工坊、市場、教育、照護、行政 | 稅收、人口、供貨與需求 |
| 要塞／軍營 | 操練、修械、儲糧、巡防與輪值 | 防線、駐軍與補給節點 |
| 港口／驛站 | 裝卸、倉儲、修繕、轉運、住宿 | 受通路、泊位與運力限制的物流 |
| 荒野／礦區 | 採集、狩獵、伐木、採礦、勘察、紮營 | 資源再生、環境破壞、運出成本 |
| 遺跡／修道院 | 探索支援、保存、研究、儀式與接待 | 知識、信仰、旅人與地方衝突 |

這些是用途組合，不另建五套城市引擎；既有 Site 種類由上層投影，港口等先作設施與用途，是否新增 def 留內容規格。大城仍以主 Site 與鄰接衛星 Site 關聯，不擴張單張地圖。

## 玩家在這裡做什麼

先看缺口與原因，再選政策、配置空間、下工作單、指定負責人與預算，最後看實際交付。沒有任職的旅人可拜訪、交易、承接工作、帶隊穿行，但不能因為縮放到 Site 就取得市長權限。

領主可以委任行政官，商人可以管理自己的倉庫，軍官可以調度授權部隊。**鏡頭尺度、人物身分、資產所有權與指揮權分開**；非法徵用可作有後果的行動，不能繞過政治規則當免費材料。

## 空間為什麼重要

- 道路與門連出實際可達路網；相鄰加成不能穿過封閉城牆或不可通行水域。
- 倉庫有容量、保管者與可用庫存；工坊有設備、勞動與原料需求。離市場近不代表原料已到貨。
- 水源、住宅、污物處理、醫療與消防共同決定服務覆蓋。Local 展開具體井、床與房間，Site 使用可核對的容量摘要。
- 住宅容量不等於人口；有空屋不會自動生成居民。工作空缺不會生成工人，必須招聘、遷入或轉職。
- 私人產業、公共工程與組織設施共用工作規則，資產與收支仍分帳。停產不等於建築消失，戰損不抹掉原地權。

## 一張工作單的生命週期

建議共用狀態：提案 → 核准 → 等待條件 → 領料／執行 → 驗收交付；另有暫停、失敗、取消。這是規則語意，不先定 C++ 型別。

| 階段 | 必須保存／確認 | 不成立時 |
|---|---|---|
| 提案與核准 | 發起者、受益者、地點、授權、目標、期限、預算 | 拒絕並給原因；不能先扣錢 |
| 等待條件 | 原料、工人、工具、運能與地點的預約 | 缺貨、缺工、路斷分開顯示 |
| 領料與執行 | 已耗料、在製品、已花工時、承辦者、進度 | 中斷保留已發生的代價，不全額退款 |
| 驗收與交付 | 實際數量、品質、去向、薪資、服務啟用時點 | 次品可返工或降級，不能領兩次成果 |
| 取消與接手 | 釋放未耗預約、在製品保管、接替者 | 失聯／死亡也能由授權者收回工作 |

勞動預算包含移動、休息、訓練與照護；不能把同一批人同時排滿採礦、運輸和守城。Local 接手的是這張工作單的一部分，不另造平行產線。普通搬運由粗算吞吐處理，重要阻塞或玩家介入才展開具體人。

## 服務與委任

地方需求分為生存、維護、公共安全與發展。政策決定優先順序，不偷偷以全知「最優」代替人物價值：行政官可能保稅源、祭司保聖所、居民要求救火。衝突需記為具名決策與後果。

委任需有權限範圍、支出上限、保底庫存、禁止事項與回報條件；AI 以自己的情報提出正常命令。預設只在缺料、逾期、超支、危險等例外打擾玩家，畫面可查「誰負責、卡在哪裡、如何恢復」。離場不撤銷委任。

## 三層與續存

Region 提供人口、對外物流、環境與政治約束；Site 計算地方配置、配額與服務；Local 詳算領出的工作與物資。各領域寫入權依 [權責表](../world-state-ownership.md)，生效時點依 [模擬契約](../world-simulation-contracts.md)。

保存工程進度、在製品、預約、資產改造與履約紀錄；可重建路徑不必永久存。卸載時移交未完工作與下一到期點，不能以「不在場」取消工期或保鮮。圖外地方仍會產出、失敗、改派與到貨。

## 推演與下一層規格

驗收案例：礦村接修橋委託 → 石材被另一工程預約 → 官員調低非必要建設優先級 → 車隊送材 → Local 工匠受傷，別人接手 → 橋在合法時點恢復運能 → Region 商路重新可用。取消工程時，已建橋墩與已付工資不消失。

反例：重複切層不能補發產物；撤掉倉庫不是清空他人所有權；玩家不在場也能完工；單城的缺糧不能直接扣另一城糧庫。
